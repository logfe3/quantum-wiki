## ᪎ 㾷

半导体异质结门控量子点，在目前试图实现量子计算的各种方案中，是一个有力的竞争者。同时也是研究量子输运过程一个优秀平台。本文针对这两个方面，在极低温环境下展开了一些工作：1 研究了半导体平行串联双量子点 (单比特) 上的光子辅助隧穿过程；在此基础上，进一步研究了电容耦合四量子点(两比特)的比特间耦合强度，为进一步完成受控非门量子操作打下了基础。2在电容耦合四量子点上，探索了近藤效应这一量子输运过程。

本文主要包括以下内容：

1介绍了关于半导体量子点上实现量子计算的基本概念以及原理。

2 介绍了从晶圆开始，完成半导体量子点样品的整个微纳加工工艺流程，包括一些技巧和经验。以及搭建一个实验所需要的极低温平台。

3 从一个串联双量子点上的光子辅助隧穿实验出发，介绍了基本的测量方法和原理。最高我们观察到了 14 阶光子的过程，并从干涉图样证明了这是一个Landau-Zener-Stükerlberg(LZS) 过程。

4 介绍了半导体门控量子点上实现量子受控门的基本原理。我们设计了量两比特的实现结构，将双量子点扩展到电容耦合四量子点。我们实现了其中非常重要的参数，两组量子点之间的电容偶和强度J的测量。数值在20GHz左右。结合之前测得的双量子点间的隧穿耦合强度来看，完全有希望在这个系统上实现一个受控非门操作。

5 介绍了半导体门控量子点上近藤效应的一些主要进展，包括单量子点上的单磁性杂质近藤效应和双量子点上的双磁性杂质近藤效应。我们进一步研究了四量子点上的近藤效应。通过一组双量子点来调制另一组双量子点，我们发现了一种新的近藤效应电导图样。

本文的主要创新点有：

1 在较高的电子温度 (3-4K) 下，观察到了阶数非常高 (14 阶) 的光子辅助隧穿过程。并进一步证明了 LZS 干涉过程的存在。这为在双量子点上完成一个单比特操作提供了一个重要保证。

2 在半导体门控量子点体系上，两比特实验研究的数目非常少。文中详细描述了一个电容耦合四量子点结构，并测量出了这个系统哈密尔顿量中的最重要参数。这为在四量子点上完成一个两比特操作提供了一个重要保证。

3 在半导体门控四量子点体系上，从未有过关于近藤过程的实验研究。本文首次对一组双量子点受到另一组双量子点耦合调制情况下的近藤效应进行了研究，发现了一些从未报道过的全新现象。

关键字：半导体量子点，量子比特，光子辅助隧穿，电容耦合四量子点，近藤效应

In current various plans for quantum computation, semiconductor heterostructure gate controlled quantum dot is a strong candidate. The main content in this thesis is: 1 We introduce some basic concepts about the realization of quantum computation based on semiconductor quantum dots. 2 We introduce all the nanoscale manufacture process from semiconductor wafer to quantum dots, including some tricks and experience. We observed up to 14-order photons process, and proved it as a Landau-Zener-Stükerlberg(LZS) process based on the interference pattern. 4 We introduce the basic concept about the controlled quantum gates based ont the semiconductor dots. Under the condition of relative high electron temperature(3-4K), we observed a rather high order(14-order) PAT process and proved the existence of LZS interference process. It provided a steady promising for the single qubit operation.

2 The experiment about two qubits on semiconductor quantum dots is very rear. We introduced a capacitive coupled quadruple dots and measure the key parameter in the Hamiltonian of this system. It provide a steady promising for the controlled quantum gate.

3 There is never a Kondo effect study in experiment on the semiconductor quadruple dots before. We start some investigation about the Kondo effect in one set of double quantum dots under the modulations of the other one and found some novel phenomenons which are never reported before.

## 1.1 本文的结构

量子计算机这一概念正在吸引越来越多人的关注，原因在于人类期待它能够带来更快更强大的计算能力。理论上，人们提出了量子傅里叶算法，使得未来的量子计算机能够在大数分解算法（Shor 算法）或者搜索算法（Grover 算法）上展现自己远超经典计算机的可能性 [1]。但是在实验上或者工程技术上，一切美好的愿望，距离实现依然非常遥远。如果以大厦建设作为比喻，不必讳言，目前大概还在挖掘地基的过程中。不仅如此，最终建起量子计算机大厦的方案也没有完全确定，核磁共振（NMR）[2; 3]，量子光学（Quantum Optics）[4; 5]，超导体约瑟夫森结（Superconductor Josephson）[6–8]，纳米线 (nanowire)[9; 10]，基于拓扑量子计算（topological quantum computing）[11] 的其它材料等等。诸如此类，都是有力的竞争者。

本人研究生期间的工作是在竞争者之一：半导体砷化镓异质结量子點（GaAs semiconductor heterostructure quantum dot）上展开的。全文包括以下几个部分：

第 1 章，研究的背景：主要介绍一些关于半导体量子点上实现量子计算的基本概念以及原理。还包括一些主要进展。

第 2 章，实验所需要的基本硬件条件：主要介绍半导体量子点样品的微纳加工工艺流程，还有如何搭建一个实验所需要的极低温平台。

第 3 章，介绍了一个双量子点结构中的工作：光子辅助隧穿（PhotonAssisted Tunneling）过程。我们最高观察到高达 14 光子的过程。同时还介绍了一些量子点体系基本参数的测量技术。

第 4 章，基于电荷量子比特的两比特工作：制作了一个电容耦合的两比特（四量子点）结构样品，成功测出了两个比特之间的耦合强度，为接下来的量子受控非门奠定了基础。

第 5 章，基于电容耦合四量子点结构的近藤效应：虽然量子计算是我们一直追求的目标，但是量子点同样也是展现一些基本物理现象的优秀平台。我们在四量子点结构上观察到了一些全新的近藤效应过程。

## 1.2 半导体上的二维电子气

在 GaAs/AlGaAs 半导体异质结上，我们可以实现门控量子点。原因在于异质结中存在一个二维电子气层 (2-dimensional electron gas,2DEG)。一个典型的GaAs 异质结的半导体层结构如图（1.1）所示。半导体异质结是通过分子束外延（MBE）技术，按某个方向依次生长的GaAs层和AlGaAs层形成的。其中的AlGaAs 的制备可以通过用 Al 离子来替代 GaAs 中的 Ga 离子来实现。分子束外延技术可以形成相当纯净的一层 GaAs 或是 AlGaAs 层，如果需要的话，生长过程中也可以进行掺杂。

![](images/b81afecfc6a46e422c5cf042909c4541f721d8d1e6007c320d079ad804ee0232.jpg)  
图1.1 典型的GaAs半导体异质结能带示意图，二维电子气（2DEG层）就是形成量子点的地方，图片来自 [12]。

通过用 Al 原子来替代 GaAs 中的 Ga 原子，我们可以获得 $A l _ { x } G a _ { 1 - x } A s .$ GaAs 的导带和价带之间的带宽 $E _ { g }$ 为 1.42V，而 $A l _ { x } G a _ { 1 - x } A s  ~ ( x = 0 . 3 $ 时）的导带和价带之间的带宽为 1.79eV。故要大于 GaAs。因此，如果我们将 GaAs 和AlGaAs 粘合为一个异质结，在两种材料的交界处会出现能带不匹配现象，具体的形状如图（1.1）。当我们向 $A l _ { x } G a _ { 1 - x } A s$ 中掺入Si离子（通常为厚度65nm的$A l _ { x } G a _ { 1 - x } A s$ 中掺杂度为 $1 0 ^ { 1 8 } / c m ^ { 3 } )$ , 自由电子会聚集在结合处形成的三角势阱中，通常距离材料表面 90-100nm左右，并在生长方向被强烈地束缚住，形成分离的态。这一层中的电子只能在垂直生长方向的平面上移动，因而就形成了所谓的二维电子气。

二维电子气（2DEG）通常用一层未掺杂的“空白”层来与掺杂的n-AlGaAs层分离开，相距约 20nm，因此极大地减少了与 Si 施主离子的散射，故而这种分离导致了二维电子气具有相当高的迁移率，使得 GaAs 可以用在高于 250GHz的场合。

## 1.3 一个全电控量子点

一般来说，材料上表面安装的金属门电极上，施加的电压大小与金属和半导体的化学势相关，即 $e V _ { g } = \mu _ { s } - \mu _ { m } , ( V _ { g }$ 为金属门电极上的电压)。金属门电极与半导体材料之间存在一个肖特基势垒，从而保证了不会有电流从金属门电极上漏到半导体材料中。金属门电极与半导体材料的交界面上比较陡峭的电势形状，是由表面态的高电荷密度造成的；这些电荷需要掺杂施主离子来平衡，而且大多数施主离子需要来中和肖特基势垒；只有一小部分会对二维电子其中的电子有贡献。

如果金属门电极上加的电压太大，或者n-AlGaAs层太厚，又或者n-AlGaAs层掺杂度太高，都可能会导致 n-AlGaAs 层的导带的最小值落到费米面以下，从而在 n-AlGaAs 中出现一个电子聚集区域。这种情况被称为平行导通或者双子带。这会严重影响到金属电极对量子点的控制，因为电极产生的电势会被n-AlGaAs中新产生的电子层屏蔽。判断是否出现平行导通的方法，如图（1.2），可以先利用半导体晶圆制作一块霍尔棒（Hall bar），增加霍尔棒上顶电极（topgate）上负电压，电导会逐渐降低。如果电阻先升高，突然降低，并再次升高[如图 (1.2 b) 中箭头位置所示]，则可以判断是该晶圆出现了平行导通，很可能不适合用来制作全电控量子点。当然，通过观察量子霍尔效应，霍尔棒还可以告诉我们二维电子气中电子密度和迁移率的结果。许多教科书都给出了一般过程，这里不再赘言。我们希望的样品，应当是尽量低掺杂，高迁移率的样品。

半导体物理的基本知识告诉我们，0 维量子点中的能态分布是一些列分立的能级，因而量子点也被称为人造原子（artifical atom）。通过多年来经验和技术的积累，人类已经能通过改变电极上的电压，一个一个的排出量子点中的电子直至最后一个。这一点可以通过观察点量子点的库伦阻塞效应（CoulombBlockade effect）来证明。

库伦阻塞：图 (1.3 b) 是一个量子点中的能级示意图。其中 $\mu _ { 1 }$ 和 $\mu _ { 2 }$ 是量子点两边的化学势； $E _ { N }$ 是到导带底的单电子能量； $\varphi _ { N }$ 是静电势能。量子点中电子的化学势为 $\mu _ { N } = E _ { N } + \varphi _ { N }$ 。量子点和中的电子和外界源漏极的电子库（resovior）之间存在如图的一个势垒。假定两边电化学势高度相同， $\mu _ { 1 } = \mu _ { 2 } ,$ 则对于 N 1 能级位置的电子，不能穿越势垒跳出所在的势阱（尽管量子力学告诉我们存在跳出势阱的可能，但能极差较大时，可能性无疑是非常小的）。这就是所谓的阻塞。如果我们通过在电极上施加负电压来使得电子获得更大的静电势能，电子的能量越来越靠近化学势所在的位置。当二者非常接近（以致对齐，这时候跃迁概率最大）的时候，电子就可以离开势阱，跳到左边或者右边的电子库中，电子库中的电子也可以跃迁到势阱中的电子能级上。这里无疑产生了一个电流。如图 (1.3) 我们可以观察到这个电流。继续抬高静电势能，第N个电子的能级开始远离化学势位置，因此，第N-1 个电子的库伦阻塞开始了。

如果两个化学势的位置不相同，显然，如图 (1.4) 所示的窗口区域（源漏化学势的差值），都能够出现电子和电子库之间的跃迁。因此，以化学势差为纵轴，静电能量（电压）为横轴，出现了一个典型的图样：库伦菱形（CoulombDiamond）。不仅仅电子中的数目，一些其他的表征系统状态的参数也可以从库伦菱形图中得出。我们将在后面的第三章详细谈到。

## 1.4 如何实现一台量子计算机（Divicenzo五条判据）

David Divincenzo 等人于 1998 年，基于半导体量子点上自旋量子比特，提出了实现一个量子计算机需要的五条基本判据 [18](有时候也称为 7 条，表述的具体内容也略有不同，但基本意思都是一样)。不仅仅是半导体，对于其它体系，这个判据也是适用的。这五条判据是：

1系统的基本单元是量子比特，能够制备一个量子比特；

2系统能够实现一个任意的幺正变换（门操作）；

3 能够实现对系统量子状态的测量；

4有足够的相干时间，以便系统完成足够多的幺正变换（门操作）；

5量子比特之间可以交换信息，比特数目可以扩展；

任何普适量子计算机（universal quantum computor）都应该满足这五个条件。下面我们将按照这五条，依次介绍基于电荷量子比特 (charge qubit) 的半导体门控量子点量子计算，同时也兼顾介绍一下其他相近似的体系。

## 1.4.1 实现一个量子比特

两能级体系（two-level system）是量子力学教科书中的经典范例，也是实现量子比特的基础。我们能够实现一个两能级体系，则可以定义一个量子比特。

电荷量子比 (charge qubit) 如图（1.5 a）所示，这是一个典型的平行串联半导体门控双量子点。各个电极的名称和用处, 以及其他物理细节，我们等到第三章，描述一个实验实例的时候再介绍。双量子点可以看成是两个单量子点 (图 1.3 a) 组合在一起。(图 1.3 a) 中虚线用来大致描画二维电子气中，因为表面电极施加电压而形成的势阱形状。理想的情况，每个量子点中要么约束了一个电子，要么电子全部排空。习惯上，我们可以称呼每个虚线范围为一个量子点。左右两个量子点里的电子一共有四种电荷 （charge）状态，我们标记为：（0,0），（0,1）（1,0）（1,1）。其中（0,1）指左边量子点排空，右边量子点包含有一个电子。其余类似。如果（0,1）和（1,0）两个电荷态之间存在耦合，那么我们得到了一个两能级体系。如图（1.6），定义 $| 0 \rangle \equiv ( 1 , 0 )$ 9$| 1 \rangle \equiv ( 0 , 1 )$ ，我们得到了一个量子比特，它可以是 0 或者 1 或者是某个中间态 $| \psi \rangle = c o s ( \theta / 2 ) | 0 \rangle + s i n ( \theta / 2 ) e ^ { i \phi } | 1 \rangle$ 。如图 (1.6 b), 我们可以用 Bloch 球来很方便地表示这个态。

电荷量子比特通常可以由这样一个二能级体系的 Hamiltonian(2  2) 来描述：

$$
H _ { d q d } = \frac { 1 } { 2 } \epsilon ( t ) \sigma _ { z } + \Delta \sigma _ { x }\tag{1.1}
$$

其中 $\epsilon$ 是两能级体系失谐量（detunning）， $\Delta$ 是两个量子点中电子之间的耦合能。 $\sigma$ 是 Pauli 矩阵。

这里我们进一步说明一下电荷量子比特：电荷量子比特的一个好处就在于，由于我们读出的信息就是电荷在两个量子点中的分布情况（具体的读出方法会在第三章实例中介绍），因此定义的同时也就完成了读出。如果是自旋量子比特，需要先实现自旋阻塞（spin blockade）[22; 23] 过程来完成自旋 $( S _ { 0 }$ 或者$T _ { 0 } )$ ）状态的读出。

## 1.4.2 实现一个任意的幺正变换（门操作）

对于定义在 GaAs 半导体门控双量子点上的电荷量子比特来说，单个量子比特的操作中，最重要的无疑就是量子非（Quantum Not）操作。也就是完成0 到 1 （或相反）的反转过程。实现这个过程通常可利用拉比振荡（RabiOscillation）或者 Landau-Zener-Stükerlberg 过程（LZS）过程来实现。

Rabi Oscillation: 假设如图（1.7）的布洛赫球。南北两极分别是 0 和 1 ，假如我们能驱动电子在 0 和 1 翻转（以 x 轴为轴心），那么这就是 RabiOscillation。为了实现这一点，我们在量子点样品的表面电极上加上一个高频调制信号，也就是一个脉冲信号（pulse）。通常这个信号是 GHz 宽度的方形脉冲，脉冲时长为 $\mathrm { T }$ （考虑到真实脉冲需要从外界一路沿着高频信号线，通过许多接口、PCB板印刷电路，bonding铝线等等，所以真正到达的样品上的可能是三角波或其他无法预知的形状）。

假如我们有这样一种测量工具，能够通过测量某个物理量 I 来知道系统内量子比特的情况。当系统处于量子比特 1 时， $I = I _ { m a x } ,$ ，当系统处于量子比特0 时， $I = I _ { m i n } \circ$ 。当然，测量是某个态向布洛赫球上 $\sigma _ { z }$ 方向投影，总归要落在$I = I _ { m a x }$ 和 $I = I _ { m i n }$ 之间。这时我们再有一个时间为 $T _ { 0 }$ 的脉冲信号，它使得位于某个失谐位置 ϵ 的态 0 ，移动到 $\epsilon = 0$ 的位置开始演化 [因为如方程 (1.1) 所示 $\sigma _ { z }$ 项等于零，因此也就是态矢量绕着 $\sigma _ { x }$ 旋转] 并且 $T _ { 0 }$ 的时间正好使得这个态演化到 1 。假如一切都成功了，那我们完成了一次量子态的翻转，并且通过测量物理量I 读出了这个翻转。

理想情况下，旋转的周期 $T _ { 1 }$ 被两能级的耦合强度 ∆ 所决定 ( 1/∆)。所以连续变化方形脉冲宽度（时长T），我们应当能看到一种 0 和 1 的周期性的振荡。振荡幅度发生在 $I = I _ { m a x }$ 和 $I = I _ { m i n }$ 之间。这种振荡就是 Rabi Oscillation。从概念上来说，这样一个单比特操作无疑是最简单的。

Landau-Zener-Stükerlberg 过程: 硬件条件有时候会限制我们，使得理论上最简单清晰的 Rabi 振荡很难观察到。比如样品感受到的真实脉冲是个三角波，这样 $\epsilon = 0$ 位置处根本就没有那么理想的演化了；或者脉冲的最高点位置根本不在 $\epsilon = 0$ 位置处。如图 (1.8) 在三角形脉冲作用下，某个态穿过了 $\epsilon = 0$ 的位置，继续进入 $\epsilon > 0$ ，演化了一段时间后，再次穿过 $\epsilon = 0$ 的位置，回到 $\epsilon < 0$ 的区域。光学分束器给了我们一个非常好的类比。一束光在路径 1 和路径 2 中积累了不同的相位，正如在 $\epsilon > 0$ 区域的两个态之间会积累不同的相位。

## 1.4.3 实现对系统量子状态的测量

对电荷量子比特来说，测量是相对简单的事情，因为 0 和 1 两个量子态直接与电荷分布相关。考虑只有一个电子的情况，量子比特为 0 的时候，一个电子在左边；反之电子在右边。通常我们用一种叫做量子点接触（quantumpoint contact，QPC）通道的结构来探测量子点中的电荷分布情况 [28–31]。如图(1.9)。其原理非常简单，电子在左边，由于离QPC通道近，通过库伦相互作用，对 QPC 通道里电子斥力大，电流小。反之，电子在右边则电流大。因此我们通过读出QPC 通道中的电流大小就可以知道量子点中电荷分布的情况了。

H _ { d q d } = \frac { 1 } { 2 } J ( \epsilon ) \sigma _ { z } + B _ { n u c l e a r } \sigma _ { x }\tag{1.4}
$$

其中 $B _ { n u c l e a r }$ 是表征量子点中的电子与周围原子核自旋的耦合。通常，一个电子大约与 $1 0 ^ { 6 }$ 个原子核通过超精细作用耦合起来。核自旋磁场 $B _ { n u c l e a r }$ 大约在在 1-5mT 左右。 $J ( \epsilon )$ 表征了自选单态 S 和自旋三态 $T _ { 0 }$ 之间的能极差。当$\epsilon \ll 0$ 时， $J ( \epsilon ) \approx 0 , S _ { 0 } ( 1 , 1 )$ 和 $T _ { 0 } ( 1 , 1 )$ 这两个能级几乎简并。当 $\epsilon > 0$ 时，J将增大。S 和 T 之间不再简并。由于更低的能级是 $S _ { 0 } ( 0 , 2 )$ ，所以 $S _ { 0 } ( 1 , 1 )$ 可以变成 $S _ { 0 } ( 0 , 2 )$ ；同时 $T _ { 0 } ( 1 , 1 )$ 由于自旋阻塞，却不能变成 $S _ { 0 } ( 1 , 2 )$ 。注意到，这里尽管依然是自旋单态 S，但是却处在不同的电荷态。因此和电荷量子比特一样，我们能够通过测量知道一开始到底是 $S _ { 0 } ( 1 , 1 )$ 态还是 $T _ { 0 } ( 1 , 1 )$ 态，因为施加测量手段（增大ϵ）之后，两个自旋态却呈现不同的电荷分布。

## 1.4.4 退相干时间

量子比特显然不是一个孤立系统，它与环境的耦合促使量子比特退相干，因而降低了门操作的保真度。相对其它系统，比如超导约瑟夫森结或者 NV 色芯来说，电荷量子比特的相干时间很难令人满意。我们必须使用极低温设备，在几十 mK 的温度水平，才能使得共振隧穿或者电声相互作用之类与温度相关的过程尽可能收到压制。同时，外界电路设备可能带入高频噪声，特别是 GHz量级的噪声显然会影响到操作过程（因为对电荷量子比特的操作频率也在这个水平上），从而降低门操作保真度。另一方面，低频的 1/f噪声也是影响量子比特退相干的重要因素，而且对 1/f噪声的来源至今仍然不是非常清楚（可能是来源于衬底中被杂质束缚住的电子）。总的来说，GaAs 半导体上电荷量子比特的退相干时间只能保持在 100ps 量级，这是非常难以令人满意的。在退相干时间内，目前只来得及做十个左右操作。离一般期待的退相干时间内完成 $1 0 ^ { 5 }$ 个操作还非常远。

作为一种延长退相干时间的手段，我们可以用动态解耦和 （dynamic decou-ple）技术来尽量消除环境和量子比特之间的耦合 [32–36]。这种技术的基本思想称作回声（Echo）。如图 (1.10) 原本在 $T = 0$ 时刻处在 0 位置的 qubit，受到外界影响，可能在 $T = T _ { 0 }$ 时间内沿 x 轴转动了一定角度 θ, 如果我们对 qubit 做一个操作，目标是使得 qubit 快速地沿 z 轴转动 π 角度，则它在下一个 $T = T _ { 0 }$ 时间内继续转动θ，则又重新回到 0。

对于自旋量子比特来说，电荷噪声造成的影响要相对小一些。主要的退相干因素是原子核自旋影响，因为核自旋仍然有一定的抖动。相对电荷量子比特，自旋量子比特退相干时间会略微长一些，达到百纳秒量级。但是相应的，自旋量子比特的操作速度差多不多在几十纳秒量级。从退相干时间内可以完成的操作数目来看，在 GaAs 材料里，自旋量子比特尽管略好一点，但也并没有特别的优势。目前世界上报道的最好的结果是哈佛的Yacoby实验组。他们经过echo操作，退相干时间可以延长到数微秒，但退相干时间内依然不够完成一个保真度足够高的操作(他们的保真度大约只有0.7)。

为了改善这个情况，基于 GeSi 半导体异质结材料的量子点最近正在兴起。威斯康星大学的 Esillion 实验组最近实现了一个 GeSi 量子点上的电荷量子比特，但是退相干时间依然只略高于 1ns。所以 GeSi 上的主要优势还在本底核自旋没有高阶磁矩，从而提高了自旋量子比特的相干时间。澳大利亚悉尼大学的Maune 等人在 GeSi 量子点上成功制备和操作来了一个自旋量子比特，最大相干时间达到了几十微秒量级[37]。这是目前半导体量子点上的最好水平。

## 1.4.5 扩展比特数的扩展

如何让更多的量子比特参与进来。对于半导体量子点来说依然是一个严峻的挑战。如前面小节所示，我们用电容耦合的方式来实现两个量子比特之间的耦合。但试图推进到更多比特的时候无疑是困难的，特别是电极几何排列中的限制。如 Yacoby 小组设计的串行排列的四量子点（两比特）结构，假如试图扩展到三比特，则需要串行排列六个量子点。在作者个人看来，一个显而易见的问题是，没法给中间的一组双量子点设计一个 QPC 测量通道。也许我们能通过直接测量中间源漏通道的电信号来知道中间比特的状态，但依然有其他问题，比如最左侧的比特和最右侧的比特之间存在耦合。三个比特中间任意两个都有耦合，整个 Hamiltonian 会非常复杂，很难期待两个比特的门操作保真度不会被第三个比特的状态影响。事实上，荷兰 Delft 大学的 Vandersypen 实验组最近完成了一个实验，恰恰说明了一串量子点的两个端点可以通过中间的量子点耦合起来 [38]。

一个可能的解决办法是模仿在超导量子比特系统里的方案。人们使用高品质因数的固态微波腔来实现两个超导量子比特之间信息的交换 [39–45]。这大大扩展了量子比特数目。在半导体量子点上，人们做了类似的尝试。一个最近的例子是法国的 Delbecq[46] 等人将两组量子点通过微博腔连接在一起。但是他们的实验并未观察到量子点之间的耦合，而仅仅只有两组相距较远的量子点的电极之间通过腔实现的电容耦合。尽管如此，在作者看来，固态微波腔依然是目前最值得尝试的办法。

## 1.5 其他量子计算机实验方案

## 超导量子比特（superconductor quantum qubit）

超导约瑟夫森结同样是一种基于固态系统的量子比特方案。超导约瑟夫森结是一种超导体 - 绝缘体 -超导体的三明治结构，通过微纳加工的办法，可以制作库伯对盒子（cooper pair box），一对库伯对束缚在 cooper pair box 中或跳出cooper pair box，可以在定义电荷量子比特。除了 charge qubit 以外，还可以制作超导环路电路，环路电路中正向流动的电流和反向流动的电流可以产生方向相反的磁通量。基于磁通量，可以定义磁通量子比特 (flux qubit)。超导量子比特的操作和读出与半导体量子点非常类似。

离子阱量子比特 (ion trap qubit) 离子阱系统利将离子约束在一定的电磁场空间内。利用激光冷却，将离子冷却到极低温度。这里的两能级体系，可以通过离子的超精细能级结构中，光学跃迁的基态和激发态来定义一个量子比特。而对量子比特的操作是通过电磁辐射来实现的。对量子比特的测量和读出，则通过观测离子荧光的方式。离子阱量子比特的扩展，则通过离子的集体作用作为量子数据总线。离子阱系统已经实现了多比特纠缠和高保真度的门操作。

NV 色芯量子比特 (N-V center qubit) 如果金刚石材料中存在氮空位，则氮空位中心可能存在电子。这种电子有非常稳定的自旋，而且周围的自旋背景非常纯净，相干时间极高。量子比特的定义是通过电子的自旋。量子比特的操作则通过外界微波场或者激光。量子比特的测量和读出则通过激光扫描。NV 色芯单个量子比特的实现非常好，但是比特纠缠还未得到实现。

## 1.6 本章小结

本章中，我们介绍了基于半导体异质结门控量子点的量子计算方案的基本概念。包括什么是半导体量子点，如何定义一个量子比特。进一步，我们介绍了 Divincenzo 的五条基本判据，并基于五条判据，逐一介绍了在目前电荷量子比特的现状。在有了这些基本概念之后，下面我们将介绍如何制作这样一个量子点系统，以及它需要什么样的测量环境。

## ㅢ 2 章 半导体全电控量子点工㢰和极低温技术

1947 年，AT&T 的 Bell 实验室 John Bardeen，Walter Brattain 和 Willam Shock-ley 制作了世界上第一块半导体点接触型晶体管。自此以后，随着微纳加工技术的发展，晶体管的集成度越来越高。现在，半导体技术极大地改变了世界。不必多言，我们身边无处不体现着半导体工业技术的一系列成果。

为什么我们要在半导体上实现一个量子点，并将它作为未来量子计算的一个有力候选者？尽管如第一章介绍，在单个比特和最基本的门操作上，基于半导体量子点方案量子计算相对于其他物理体系，并没有什么优势，反而略输一筹。但半导体量子点一个巨大优势就在于：样品的加工完全可以通过工业上已经成熟的平面加工处理技术完成。可以说，就样品的制备技术而言，除了一些技巧之外，实验室甚至未来的工厂中几乎不需要什么新设备和新技术，一切都已经非常成熟。同时，现代半导体集成化电路的成功强烈暗示了未来量子门电路的集成化成功，这一点是相当吸引人的。

在我们的实验室中，用到的典型的加工技术包括：化学清洗和等离子体清洗、光刻技术、电子束曝光技术、金属沉积技术。其它技术：如等离子体刻蚀、原子力显微镜局域氧化、原子沉积生长等，在各种不同的半导体材料量子点加工上（GaAs或者GeSi，掺杂或非掺杂），也可能使用到。[47–57]这里我们主要介绍掺杂型 GaAs 异质结半导体上量子点的加工工艺。完全可以将它视作加工工艺的基本形式，其它材料上更复杂的工艺可以视为它的变体。

## 2.1 制作一个全电控量子点1（切割和清洗）

整个工艺开始，我们得到的是一块通过分子束外延（MBE）生长的晶圆（wafer）。这是我们通过商业购买的形式获得的。晶圆尺寸通常为 3 英寸或 4 英寸。首先在整片晶圆上甩上一层保护胶 (通常用光刻胶就可以了) 并烤干 (后面会介绍)。然后沿着与晶圆切口标记平行和垂直的方向，用玻璃刀将晶圆切割为1cm 见方的方片。每个切片大约可以做 9 （3x3）或 12 （3x4）个量子点样品。一个量子点样品尺寸大约在 2-3mm 左右。切片不宜更大，否则使用普通镊子时夹取困难，光刻时对准也不宜，而且制作中如果产生失误则损失很大。

清洗的目的，在于除去晶圆表面的离子的、有机的或者金属杂质。我们采用的清洗包括以下五个标准步骤：

1将切片放入三氯乙烯（TCE）溶液中，超声清洗50s；

2将切片从三氯乙烯转移到丙酮（ACE）溶液中，超声清洗 50s；

3将切片从丙酮转移到异丙醇（IPA）中，超声清洗50s；

4将切片从异丙醇转移到去离子水（DI，）中，超声清洗50s；

5将切片从去离子水中转移到无尘纸上，用高纯氮气吹干表面。

有时如果有必要，还可以使用表面等离子体清洗。如果感觉有碎裂的危险（作者个人的经验表明，清洗次数太多，清洗中可能突然碎裂。尽管不能作为一个一般性的证据，但是显微镜下如果发现晶圆边缘破损严重，超声中碎裂的可能性就很大。特别是使用镊子时，希望夹紧而过于用力，会对晶圆切片边缘造成很大损伤。），可以把超声清洗改为浸泡5min。

清洗原理十分简单，但非常重要，需要反复的练习才能熟练做出表面清洁的样品。样品表面清洁与否，经常成为量子点质量的关键。特别是在电子束曝光前或者整个制作完毕后，光学显微镜下观看电子束曝光电极部分，表面如果有大量的脏污，实际经验发现这样的量子点工作很可能失败。又如，在切割完毕后的第一道清洗工序时，因为几乎无法分辨晶圆正反面，所以万万要注意不能出现在转移过程中把晶圆切片正反弄错的情况。

如果确实发生了无法确定正反面这样的问题，应当将晶圆切片转移到有IPA 或者其他有机溶剂的培养皿 (或其他易于在显微镜下观察的容器) 中，在显微镜下观察晶圆边缘，有明显切割痕迹的，基本是正面。

## 2.2 制作一个全电控量子点2（光刻，镀膜和刻蚀）

以我们的半导体双量子点为例，清洗完毕的晶圆切片，首先制作台阶（mesa）。Mesa 是半导体表面一块高地。高地以下的半导体，其包含二维电子部分已经被刻蚀掉。只剩下高地上的半导体中还存在二维电子气。接下来光刻技术完成的部分包括：1 欧姆接触电极（Ohmic Contact gate）2 表面电极（surface gate）。我们是用的光刻设备是 Karl Suss MJB-3，极限在 1µm。首先介绍一下光刻。

光刻： 光刻技术是现代半导体工业技术的核心之一。通过复杂的紫外光、深紫外曝光等技术，光刻曝光的分辨率已经可以达到 20nm 以下。但实验室由于设备的限制，通常利用光刻曝光完成微米或百纳米量级的加工。更高精度的电极交给电子束曝光来解决。

6 对准和曝光。利用光刻版上的对准标记，与切片上的对准标记，来确定光刻版上图样和切片上预定曝光位置之间的对准。举例而言，做完 mesa 后，半导体表面会留下如图 (2.2 a) 中箭头所示小图案。下一步我们制作欧姆接触时，需要将光刻版上欧姆接触部分相应的图案与半导体晶圆上已经存在的图案对齐，这样确定欧姆接触图案的曝光位置。完毕后，使用曝光机曝光。我们使用的是Karl Suss 公司生产的 MJB-3 型曝光机。曝光精确度可以到达 1µm。我们使用的光刻胶为 AZ5214E。这种胶根据处理的不同，可以在正胶和反胶之间转变。基于反版的基础上，如果使用正胶，需要曝光 6s 并显影；如果使用反胶，曝光 6s后，在 $1 8 0 \mathrm { { } ^ { \circ } C }$ 条件下烘烤 2min，然后直接暴露在曝光灯下60s。

7 显影。将曝光后的切片放入显影剂中进行显影。我们使用的显影剂为AZ400K 混合 DI （1:6），显影时间为 30-40s。具体时间可以灵活掌握，显影的结果一般肉眼可见。

8烘烤。目的是使光刻胶变硬。

在 Mesa 上，我们要制作欧姆接触电极（Ohmic Contact Gate）。欧姆电极将进入二维电子气层，从而使得二维电子气能够连接到外部电路。制作金属电极的一个重要步骤是镀膜。常见的镀膜方法有磁控溅射镀膜，热蒸发镀膜和电子束镀膜。这里，我们使用的是电子束镀膜。其基本原理为高压系统提供的高电压将加速电子束轰击坩埚中的金属，使金属蒸发。蒸发的金属气体会扩散到整个腔室，遇到样品表面会遇冷后均匀地沉积下来。

## 这里的基本步骤是：

1光刻，做出欧姆接触图样。

## 2.3 制作一个全电控量子点3（电子束曝光）

受到光波长的限制和实际购买的光刻机的工作能力，我们组内通常只能达到最小 1 微米精度。更细微的结构（几十纳米），我们需要波长更小的电子束曝光法。电子束曝光不需要制作掩膜板，而是预先写入 CAD 图形，由软件控制光阑开关来实现。电子束曝光需要相应的电子束光刻胶，基本原理与普通光刻没有什么区别。这里的基本步骤是：

1 清洗。这一步清洗需要确保最中心约 $1 0 \times 1 0 \mu m ^ { 2 }$ 的区域非常清洁。否则更精细的电极可能在污损处断裂。

2甩胶。这里我们使用的光刻胶是聚甲基丙烯酸甲酯（Polymethylmethacry-late PMMA，950 A2）。需要甩两层。第一层：用 500r/m 条件下 3s，然后在180◦ 条件下烘烤 5min。第二层：4000r/m 条件下 40s，然后在 180◦ 条件下烘烤10min。硬化后等待曝光。两次甩胶结束后，总厚度约在120nm。

3镍粉标记。曝光图样时，我们需要电子束聚焦在半导体表面。但是电子束一旦照射到光刻胶上，曝光也就开始了。所以不能直接将电子束移动到曝光区域观察，而是需要一个确定焦距的手段。镍粉就起到这个作用。我们用异丙醇混合镍粉，利用牙签或其他物品尖端蘸取一点液体沾在样品的四个角上（不要触碰到电极）。聚焦一个待曝光区域四角的镍粉，调整到 100 万倍率下焦距和相散最优处，记录下此时的焦距。依次完成四角，以焦距平均值为中心区域焦距。

利用镍粉确定焦距之前还有一些细微而繁琐的调整工作，例如测量电子束电流强度，以便确定最终的曝光时间等等。这里就不再一一介绍。

4曝光开始。按照事先编写的CAD 图样完成曝光。

5 显影。这里的显影剂是 MIBK：IPA=1:4。显影 45s，异丙醇中冲洗 15s，吹干。MIBK气味具有很强的刺激性，注意做好防护。

6 镀膜。

7 金属剥离。这里最细的电极只有 10nm 量级。需要在丙酮中浸泡一天，然后用塑料软移液管吹掉表面的金属薄膜。并用 IPA 反复冲洗吹干。此时切忌用超声清洗。

至此，电子数曝光流程结束。后续的两个基本步骤是:

1甩胶和烤胶。目的是将样品表面保护起来，并准备切割。

2将 3x3 的样品切割成独立样品。每个大小约3mm见方左右。

## 2.6 实现mK量级的极低温环境和测量1（稀释制冷机简介）

量子点需要很低的温度，量子效应才能够展现出来。所以通常我们需要极低温实验技术。

液态氦的沸点是 4.2K，利用 He-4 泵减压制冷，最低可以达到略高于 1K的温度。同样原理，如果制冷剂换做 He-4 的同位素 He3，最低可以达到略高于200mK 的温度。为了达到 10mK 水平的温度，现在通常使用的是稀释制冷技术。稀释制冷技术（稀释制冷机）的原理由 H.London 于 1951 年提出，十余年后制造成功。两种氦的同位素（He-3 和 He-4）混合后，降低到关键温度（约800mK）以下时，两种同位素分成不同的相。较轻的称为“集中相”，主要是He-3；较重的称为“稀释相”，主要是 He4 （“集中”与“稀释”相对 He3 而言）和 6-7% 的 He-3。利用 He-3 泵在稀释相自由表面（这个位置称为 still，温度约为 0.7K，此时 He-3 的蒸汽压约是 He-4 的 1000 倍）减压制冷，集中相的He-3 将向稀释相中扩散。He-3 在两种相中的熵不同，因此当 He-3 从集中相向稀释相“蒸发”的时候可以实现制冷。

## 2.7 实现mK量级的极低温环境和测量2（一个改装实例）

在量子计算实验物理学领域，特别是基于半导体或超导结构的物理实验中，需要探测的物理量都极其微弱。以电流为例，一般为几个到十几个 pA，因此对实验中的噪声要求极小，能否尽可能的降噪，是实验成败的一个关键要素。同时，随着两比特甚至更多比特实验的推进，对样品的测量需要更多的电极。以后文中我们将提到的 GaAs 半导体异质结两比特量子点为例，典型的样品已经需要 24 根引线（直流电控制和测量部分），由于极低温实验仪器价格昂贵，单个仪器的负载不能无限提高，因此日益增长的需求对实验设备的使用效率提出了挑战。

这里，至少有两个基本问题需要解决：

（1）样品所在环境温度和热噪声。 该领域对于极低温设备和极低温环境的需求非常高。由于极低温设备结构复杂且在实验室级别难以自制，通常实现这一条件的方法是购买商用极低温制冷机。目前一个先进的制冷机型号是 Oxford公司生产的 Triton 系列稀释制冷机。该型号核心参数为：混合室 (温度最低处)温度 10-20mK。该型号制冷机无需液氦作为制冷机，结构较以往产品更为简单，放置样品空间较大。但是价格昂贵，占用的空间也不小。故而当前在如上所述的试验中，一个基本的要求在于：希望实现对制冷机效率利用的最大化，在制冷机中放置更多的样品；同时，放置更多的样品意味着引入更多的控制/测量引线，所有引线的一端在样品上，另一端最终与室温相连。引线越多，稀释制冷机的热负载越大，对核心参数的偏离也越大。因此，需要解决的一个问题是，在于在对混合室温度无较大影响（温度升高不超过 10mK，不引入更大热噪声）的情况下，设计一种热沉（heatanchor）结构，实现对稀释制冷机制冷效率利用的最大化。

（2）电路噪声。测量和控制设备的输出端口、线路两端的温度梯度（室温- 接近绝对零度）、线路焊接处不同金属材料，都有可能带来电路噪声。其中高频噪声会使样品中电子温度升高，同时由于实验中需要施加高频信号（几到几十个 GHz）来进行操作，直接干扰了操作脉冲信号。考虑到该类实验需要的严格的信号质量，因此很有必要通过设计合适的滤波电路来降噪。同时，由于核心电极的宽度最小只有 20nm，因此在将样品从制作间向稀释制冷机转移安装的过程中, 轻微的脉冲放电或者电压源的突然掉电，完全可能将电极击穿，需要降噪电路同时起到保护电路的作用。

为了解决这两个问题，我们设计了一套结构, 包括三个部分：热沉部分，铜粉滤波部分，PCB板载滤波器部分。下面依次介绍这三个部分。

热沉部分：实验中，我们使用 Lakeshore SS1 微型同轴线作为控制和测量线。这是一种带屏蔽层的不锈钢同轴线，信号质量要比普通的漆包线更好，但也意味着更大的截面积和热负载。我们设计了一种夹板热沉。多层夹板之间可以像三明治一样夹起来，夹板之间设计了供线路穿过的线槽，信号/控制线可以来回反复穿过热沉中间的布线槽。夹板最后固定在稀释制冷机相应的冷板上。线从室温进入热沉部分，依次通过五层热沉至稀释制冷机混合室冷板。离开最后一级冷板后，焊接在 25Pin D 型接口上，D 型接口与铜粉滤波器 D 型接口入口相连。经过铜粉滤波器后，由铜粉滤波器 D 型接口出口离开，通过一段lakeshore SS1 线后，通过排针接口进入 PCB 板载滤波电路，并最后进入样品。热沉部分用以对测量/控制线路提供充分的热交换，使得该处的测量/控制线路的温度降低到与冷板温度一致，从而降低热噪声。热沉部分由 PT1 层，PT2 层，Still 层，100mK 层级，MC 层级五层极热沉组成。每层热沉通过多层夹板，延长热交换线路的长度。夹板全部镀金以增强平整度和热导，如图（2.10）。

铜粉滤波器部分：对于极低温下 GHz 水平高频信号滤波，铜粉滤波器是一种有效的工具 [58; 59]。测量和控制线路经过热沉到达稀释制冷机最下层（MC层）后，由于测量和控制设备的输出端口、线路两端的温度梯度（室温 - 接近绝对零度）、线路焊接处不同金属材料等影响因素，线路中仍然存在一定的噪声，直流信号必须进行滤波才可以保证纯净。传统 RC 滤波器和其他商用贴片滤波器，性质最优秀者也无法达到 3G 以上的滤波效果。而这个频率及之上的频率，正是半导体量子点进行高频操作时所使用的典型频率段。高频操作信号经由专门高频线路进入样品，因此直流部分中不应有高频噪声。在 GHz 波段，需用铜粉滤波器部分用以提供对直流线路中噪声信号进行压制。我们使用直径50um 的青铜粉末和环氧树脂粘合剂制作铜粉混合物作为填充物, 使用 25pin-D型接头作为线路进出口，如图（2.11）。

PCB 板载滤波器部分：PCB 板载滤波器用以两个用途：（1）PCB 板载滤波器是保护电路。在样品固定在紫铜底座，并通过 bonding 线与 PCB 板 bonding端连接后，有一段从微纳加工车间到稀释制冷机上转移的过程。该过程中轻微的脉冲放电，都有可能击毁样品。因此需要板载滤波器作为高频脉冲信号的保护电路。用以保证样品在转移过程中的完好。（2）由于铜粉滤波器的工作特性，1G 以下的低频噪声无法通过铜粉滤波器进行滤波。此时需要传统的 RC 滤波器和其他贴片滤波器配合来实现滤波效果。我们使用 DC-300MHz 低通 RC 贴片滤波器和 DC-1GHz 的铁氧体磁珠低通滤波器来覆盖 1GHz 一下的噪声，如图(2.12)。当然，我们承认，极低温下的滤波性质，无法和常温下的滤波参数一致，甚至可能有很大偏差。但是实际使用效果还是令人满意的。

## ㅢ 3 章 双量子点中的光子䖻ࣟ䳝サ

光子辅助隧穿（Photon-assisted-tunneling，PAT）是一种研究量子点中能谱的有力工具 [60–62]。通过向样品施加微波信号，我们在 GaAs 双量子点样品上完成了一个光子辅助隧穿实验。在电子温度（>1K）远大于晶格温度（250mK）时，我们观察到至多14阶光子过程。同时我们还观察到了LZS干涉的特征。另外一方面，我们测量了在大功率微波信号下，电子电荷态的弛豫时间 $T _ { 1 }$ 。结果约为8ns，这与之前人们观察到的一致。从而证明了在高功率，高电子温度下的弛豫时间 $T _ { 1 }$ 几乎不变。

## 3.1 实验的动机和准备

由静态电势阱定义的半导体量子点是研究二能级体系下的电荷和自旋量子比特的一种优秀的平台 [63–67]。再众多的操作技术中，微波信号激励下的输运谱测量，也就是光子辅助隧穿，是一种研究量子点中能谱和动态过程的常用工具。我们研究了双量子点中电荷态在非常大功率微波信号下的行为。在很强的激励（如这个实验中使用的 10dbm 或更高），电子温度已经远远超越了晶格温度，不再处于热平衡的状态。介观系统中非热平衡现象已经引起了许多的关注，这是因为现在的电子器件尺寸已经非常小，比较容易被外界引导到非热平衡状态。电子温度与晶格温度显著不同时，两能级体系的动力学过程（比如电荷态的弛豫过程）强烈地引起了我们的兴趣。

## 3.2 PAT 简介

在双量子点中，当电子能够以一定的速率，相干地从一个点隧穿到另一个点中时，系统的本征态就不再是非局域的，而是扩展到整个双量子点系统。一般来说，耦合双量子点中的电子是个多体问题，而多体问题常常是很难处理的。

因此，我们通常只考虑每个点中最高的占据态，而忽略更低的能态，从而将系统简化成一个两能级体系。例如一个（N+1，M）到（N，M+1）的电荷态转变过程，我们直接将其简化为（1,0），（0,1）。幸运的是，两能级体系模型确实很有效。

如果我们对这个二能级体系施加一个额外的随时间变化的项，也就是$\epsilon  \epsilon ( t ) = \epsilon + V _ { a c } \cos 2 \pi f t ,$ ，则电子与能量为 $h f$ 的微波光子交换能量时，会导致电子产生一个非弹性隧穿过程。这样一种因为交换离散的能量单位 $( h f )$ ，而发生的非弹性隧穿过程，被称为光子辅助隧穿（Photon Assisted Tunneling, PAT）。对于研究量子点中的能谱来说，光子辅助隧穿是一种强有力的工具。Stoof和Nazarov 等人于 1996 年对 PAT 过程进行了理论研究 [70; 71]。假设 Γ(E) 是能量未施加交流信号时，能量为 E 的电子的隧穿几率。那么当时加一个交流信号$V _ { a c } \cos 2 \pi f t$ 时，隧穿几率为：

$$
\Gamma ( \tilde { E } ) = \sum _ { + \infty } ^ { - \infty } J _ { n } ^ { 2 } ( \alpha ) \Gamma ( E + n h f )\tag{3.2}
$$

其中， $\mathrm { n } { = } _ { \dots , - 2 , - 1 , 0 , 1 , 2 , \dots } , J _ { n } ^ { 2 } ( \alpha )$ 是第一类 n 阶 Bessel 函数的平方， $a l p h a =$ $e V _ { a c } / h f$ ，它描述了电子吸收或者放出nhf 个电子的几率。因此我们可以这样理解，单个电子和微波场耦合的效果是，原能级 E 劈裂成一些列能级 E+nhf。这就是 PAT 是一个研究能谱的有力工具的原因：PAT 过程只在能极差是 hf的整数倍，也就是吸收或放出整数个微波光子的地方才发生。如图（3.9）。

我们考虑一个在一个振幅足够大的周期性势场中的两能级体系。在外界势场的驱动下，两能级体系中会发生连续不断的态的转变过程。在转变过程中，波函数会出现相位的积累 (也就是 Stückelberg 相位)，这会导致增强和消失的干涉图样。改变这个物理系统中的许多参数，都可能会导致这种干涉发生，这种干涉也称为 Landau-Zener-Stückelberg(LZS) 过程。它可以发生在多种物理体系中，比如在超导量子比特或半导体量子比特中 [74–76]。人们已经观察到了非常清晰地LZS 干涉过程。

2增加功率时，更多的峰会出现。

3峰之间的间距完全一致。

这些特征强烈地说明了即使在电子温度达到数 K 的情况下，依然能够观察到LZS 干涉图样。

本章主要描述了一个砷化镓半导体量子点上的实验实例：外界高功率微波信号驱动下，量子点中发生的PAT过程。

## ㅢ4 章 半导体量子点上的两比特系统

## 4.1 基于电荷量子比特的受控量子门

如前两章中所述，通过微纳加工的方法，我们在砷化镓半导体异质结上实现了一个双量子点结构。这种了量子器件提供了一种非常优秀的，可控性很好的两能级体系 [63; 64; 79; 66; 67]，这已经通过 PAT 实验得到了验证。这个在更加精细的脉冲波的控制下，我们可以进一步实现一个门操作。2013 年，我们组的曹刚、李海鸥博士完成了这一工作[25]。

GaAs 和 GeSi 材料上单比特上的成功 [80–84; 75; 37; 85; 86]，激励着我们继续走向更深远的量子计算。接下来的问题是，为了实现一个普适门操作，我们还需要一个两比特操作。既然一个两能级体系 (双量子点结构) 可以提供一个比特，那么最自然地想法就是在两个两能级体系，也就是四量子点结构上，完成一个两比特操作。如图（4.1）。目前最好的结果是Havard大学的Yacoby小组完成的受控相位门[27]。

这是一个很直观的结构。我们可以将它视为两个双量子点。而它们之间的耦合，则是因为它们之间的距离很近，可以直接实现电容耦合。在某个双量子点中，电子处在 (M+1,N) 或者 (M,N+1) 态时候，我们可以标记为 L (这里，我们依然遵从前一章的假定，只考虑单个量子点中能量最高的态)。因此对于四量子点，我们标记其中的电荷态为 mn ，其中 $\scriptstyle \mathrm { m = L , R } , 0 , 2 ,$ 。态 LL 表示上面的双量子点在 L 态，下面的双量子点也在 L 态。其余类推。m=0时候，表示一个电子都没有；m=2时表示两个量子点中各有一个电子。

为了简单起见，首先忽略退相干因素的存在。我们标记电荷态为 mn 的能量为 $E _ { m n }$ 。假如四量子点系统中只有 1 个电子那么它有四个可能的能量 $E _ { L 0 } ,$ $E _ { R 0 } , \ E _ { 0 L } , \ E _ { 0 R }$ 。对于有两个电子的状态 20 ，其能量为 $E _ { 2 0 } = E _ { L 0 } + E _ { R 0 } + U _ { 1 }$ 这里 $U _ { 1 }$ 代表两个电子之间的静电耦合能。类似的，我们可以得到 $E _ { L L } =$ $E _ { L 0 } + E _ { O L } + U _ { l l }$ 或者 $E _ { L T } = E _ { L 0 } + E _ { 0 R } + U _ { L R }$ 。其余类推。我们定义第一组双量子点中，两个量子点中的能极差 $\epsilon _ { 1 } \equiv E _ { L 0 } - E _ { R 0 }$ ，第二组中， $\epsilon _ { 2 } \equiv E _ { 0 L } - E _ { 0 R }$ o两组量子点之间的耦合 $\mathrm { J } = ( U _ { L L } + U _ { R R } - U _ { L R } - U _ { R L } ) / 4$ 。因此，我们可以将以下四个态的能量写为一个更简单的形式：

$$
E _ { L L } = \epsilon _ { 1 } + \epsilon _ { 2 } + J\tag{4.1}
$$

![](images/fcea38fa4bb2f0d189b6f882ed564fddc4c5233fbb6d358ffb7be6c1ce02c912.jpg)  
图4.1 (a)Ti/Au 电极 1-12 定义了一个典型的四量子点结构。在上下两组量子点共用横向电极 11 和 12 的基础上，电极 1-5 定义了一个典型的双量子点；电极 6-10 同样定义了一个典型的双量子点。电极 Q1-Q4 是四个 QPC 电极，用来形成四个 QPC 测量通道。白色箭头表示了测量电流流过的方向。红色的四个圆点表示了四个量子点的假想位置

$$
E _ { L R } = \epsilon _ { 1 } - \epsilon _ { 2 } - J\tag{4.2}
$$

$$
{ \cal E } _ { R L } = - \epsilon _ { 1 } + \epsilon _ { 2 } - J\tag{4.3}
$$

$$
E _ { R R } = - \epsilon _ { 1 } - \epsilon _ { 2 } + J\tag{4.4}
$$

量子点之间的跃迁，可以用 Hamiltonian 的非对角项来描述。因此整个Hamiltonian 可以写成：

$$
H _ { 2 q } = \sum _ { i = 1 } ^ { 2 } \frac { 1 } { 2 } ( \epsilon _ { i } \sigma _ { z i } + t _ { i } \sigma _ { x i } ) + J \sigma _ { z 1 } \sigma _ { z 2 }\tag{4.5}
$$

写成矩阵形式为：

$$
\left( \begin{array} { c c c c } { \epsilon _ { 1 } + \epsilon _ { 2 } + J } & { 0 } & { \Delta _ { 1 } } & { 0 } \\ { 0 } & { \epsilon _ { 1 } - \epsilon _ { 2 } + J } & { 0 } & { \Delta _ { 1 } } \\ { \Delta _ { 2 } } & { 0 } & { - \epsilon _ { 1 } + \epsilon _ { 2 } + J } & { 0 } \\ { 0 } & { \Delta _ { 2 } } & { 0 } & { - \epsilon _ { 1 } - \epsilon _ { 2 } - J } \end{array} \right)
$$

基于这个 Hamiltonian，我们可以构造一个受控旋转门 (Control RotationGate，CROT)。受控旋转门的意思是：当 qubit2(控制比特) 处在 R 时，给qubit1(目标比特) 施加某个驱动脉冲，qubit1 会在 RR 和 $| L R \rangle$ 之间旋转；当<sup>qubit2(控制比特)</sup> <sup>处在</sup> |<sup>L</sup>⟩ <sup>时，给</sup> <sup>qubit1(目标比特)</sup> <sup>施加同样的驱动脉冲，qubit1</sup>不会在 RR 和 LR 之间旋转。

为了求解方便，我们假设两组双量子点内两点之间的耦合强度 $t _ { 1 } = t _ { 2 }$ , 固定$\epsilon _ { 1 } = J / 2$ ，求解上面这个 Hamiltonian。它的本征态是：

$$
| C _ { + } ^ { \prime } \rangle \simeq \frac { 1 } { \sqrt { 2 } } [ | L R \rangle + | R R \rangle - \frac { \Delta } { 2 ( \epsilon _ { 2 } + J / 2 ) } | L L \rangle - \frac { \Delta } { 2 \epsilon _ { 2 } - J / 2 } | R L \rangle ]\tag{4.6}
$$

$$
| C _ { - } ^ { \prime } \rangle \simeq \frac { 1 } { \sqrt { 2 } } [ | L R \rangle - | R R \rangle - \frac { \Delta } { 2 ( \epsilon _ { 2 } + J / 2 ) } | L L \rangle - \frac { \Delta } { 2 \epsilon _ { 2 } - J / 2 } | R L \rangle ]\tag{4.7}
$$

$$
| R L ^ { \prime } \rangle \simeq | R L \rangle - \frac { \Delta } { 2 J } | L L \rangle + \frac { \Delta } { 2 \epsilon _ { 2 } - J / 2 } | R R \rangle\tag{4.8}
$$

$$
| L L ^ { \prime } \rangle \simeq | L L \rangle - \frac { \Delta } { 2 J } | L R \rangle + \frac { \Delta } { 2 \epsilon _ { 2 } + J / 2 } | R L \rangle\tag{4.9}
$$

相应的本征能量是：

$$
E _ { C _ { + } ^ { \prime } } \simeq - \frac { \epsilon _ { 2 } } { 2 } + \frac { \Delta } { 2 } - \frac { \epsilon _ { 2 } \Delta ^ { 2 } } { 4 \epsilon _ { 2 } ^ { 2 } - J ^ { 2 } }\tag{4.10}
$$

$$
E _ { C _ { - } ^ { \prime } } \simeq - { \frac { \epsilon _ { 2 } } { 2 } } - { \frac { \Delta } { 2 } } - { \frac { \epsilon _ { 2 } \Delta ^ { 2 } } { 4 \epsilon _ { 2 } ^ { 2 } - J ^ { 2 } } }\tag{4.11}
$$

$$
E _ { R L ^ { \prime } } \simeq \frac { \epsilon _ { 2 } } { 2 } - \frac { J } { 2 } - \frac { \Delta ^ { 2 } } { 4 J } + \frac { \Delta ^ { 2 } } { 4 \epsilon _ { 2 } - 2 J }\tag{4.12}
$$

$$
E _ { L L ^ { \prime } } \simeq \frac { \epsilon _ { 2 } } { 2 } + \frac { J } { 2 } + \frac { \Delta ^ { 2 } } { 4 J } + \frac { \Delta ^ { 2 } } { 4 \epsilon _ { 2 } + 2 J }\tag{4.13}
$$

如果 $\Delta \ll J$ ，我们可以发现，上述四个本征态都可以近似为 $\frac { 1 } { \sqrt { ( 2 ) } } | L R \rangle +$ $\begin{array} { r } { | R R \rangle , \frac { 1 } { \sqrt { ( 2 ) } } | L R \rangle - | R R \rangle , | L L \rangle , | R L \rangle } \end{array}$ 。正如单比特操作那样，如果我们施加频率为J 的脉冲并实现了一个很好的 Rabi 振荡，那么可以实现 $| L L \rangle$ 和 $| R L \rangle$ 之间的旋转。同时，另外两个能级之间能极差太小，则几乎不会在这个脉冲下旋转。这样我们就实现了一个受控旋转 (CROT 门)。受控非门 (Controlled Not Gate，CNOT) 则可以看做是旋转角度为 $\pi$ 的特例。有了受控非门，加上之前的单比特非门，理论上我们可以构造任意我们想要的量子门，后面困扰我们的是门的保真度问题。

## 5.1 半导体中量子点的Kondo效应

尽管半导体量子点作为各种量子计算方案的有力候选者之一，除了量子计算，在量子输运领域，半导体门控量子点同样是一种非常优秀的系统。特别是门控半导体量子点系统成熟的加工工艺，对于各种参数良好的可调性，都是它的巨大优势。

量子相变 (Quantum Phase Transition，QPT) 是凝聚态和量子场论中非常活跃的一个领域。在描述一个物理系统的 Hamiltonian 中，一些参数的改变，导致了不同特征之间的量子态基态之间的转变，这就是量子相变。Kondo 系统中有丰富的现象，是一个发生量子相变的很好的例子 [90; 91]。近年来，许多体系中的Kondo 效应，比如金属量子点 [92–94]，金属隧穿结 [95]，原子分子系统 [96–98]中，都有了很大的进展。

这一章，我们就围绕半导体量子点上的Kondo 效应来展开。

## 5.1.1 单自旋杂质的 Kondo 效应

降低温度，金属的电阻通常会减小。这很容易解释，因为金属原子的振动变小，电子受到的散射过程减少，更容易穿过金属。但是实验表明，对于有些金属，比如 Co，Au 等等，大约在温度到达 10K 左右，电阻饱和，不再随着温度变化。如果我们在其中参入微量的磁性杂质, 例如 Fe，Mn，形成的稀磁合金会在某个低温位置 (大多在 10K-20K) 达到电阻的极小值。这种反常的现象被日本科学家近藤（Kondo）于 1964 年给出了一个初步的解释：在这些金属中存在着磁性杂质，当电子被磁性杂质散射时，电子和杂质的自旋状态都会发生改变，这导致了所谓的近藤效应 (Kondo Effect)。

单自旋杂质的 Kondo 效应 (single spin impurity Kondo effect，1-IK)，是一种多体效应 (many-body effect)。它可以被一个多体能量标度来表征，这个标度就是Kondo 温度 (Kondo temperature)，或者说 Kondo 能量（ $( \mathrm { K o n d o e n e r g y } , T _ { k } = E _ { k } / k _ { B }$ 9$k _ { B }$ 是玻尔兹曼常数）。因此，电子温度 $T _ { e }$ 不同时，自旋杂质表现出不同的行为：当 $T _ { e } > T _ { K }$ 时，自旋杂质的行为更像一个自由自旋；当 $T _ { e } > T _ { K }$ 时，自旋杂质不再那么自由，开始出现了束缚共振(boundresonance)。

1964 年，Jun Kondo 提出 Hamiltonian 模型：

$$
H = \sum _ { k \sigma } \epsilon _ { k } c _ { k \sigma } ^ { \dagger } c _ { k \sigma } + J s _ { i m p } \cdot s _ { c o n d }\tag{5.1}
$$

这里， $\epsilon _ { k }$ 是导带 k-态的能量； $c _ { k \sigma } ^ { \dagger }$ 和 kσ 是 k- 态的产生 -湮灭算符； $s _ { i m p }$ 是杂质自旋； $s _ { c o n d }$ 是传导电子的自旋；J>0, 说明两种自旋是反铁磁耦合。基于这个Hamiltonnian，利用格林函数方法求解，Kondo 提出电阻与温度之间的关系：

$$
\rho ( T ) = \rho _ { 0 } + a T ^ { 2 } + b T ^ { 5 } + c J ^ { 2 } + J ^ { 3 } D ( E _ { F } ) l n ( E _ { B W } / T )\tag{5.2}
$$

这里， $\rho _ { 0 }$ 是温度 T=0 时候的非磁性静态缺陷产生的电阻； $a T ^ { 2 }$ 来自费米液体 (Fermi-liquid)； $b T ^ { 5 }$ 来自声子； $D ( E _ { F } )$ 是传导电子在费米能级附近的态密度；$E _ { B W }$ 是传导电子带宽。显然，在 T 接近 0 的时候，电阻出现了发散，这里可以使用重整化群方法 (renormalization method) 解决这个问题。重整化群方法给出了方程(1) 中耦合强度随着能量的具体形式：

$$
J ( E ) = E _ { B W } { \frac { 1 } { 1 - J D ( E _ { F } ) l n ( E / E _ { B W } ) } }\tag{5.3}
$$

显然，在 $E _ { K } = k T _ { K } = { \cal E } _ { B W } e x p [ - 1 / J D ( E _ { F } ) ]$ 时，J(E)项出现发散，说明杂质自旋和电子库中传导电子之间形成了 Kondo 自旋单态。这个标度只在能量大于 $E _ { K }$ 才正确。

在 Kondo 的 Hamiltonian 的基础上，进一步出现了 Anderson 的 s-d 混杂模型。这个模型加入了两点变化：1对于自旋杂质原子的d壳层电子，电子之间存在库伦相互作用U，这与自由原子形成的固有磁矩相似；2自旋杂质的d壳层轨道态不是严格的本征态，而是倾向于退局域化为 s 态，二者之间存在着电子的相互转移。

## 5.1.3 两自旋杂质的 Kondo 效应

在单自旋杂质的基础上，人们进一步发展了两自旋杂质下的 Kondo 效应(two-impurity Kondo effect，2-IK)。这里的基本图像是：在每个自旋杂质和电子库之间耦合的基础上，两个自旋杂质之间存在反铁磁耦合。这导致两自旋杂质体系里，不同基态中出现了一种竞争关系：一方面是单个自旋杂质与相应电子库中电子之间的耦合；另一方面，两个磁性杂质通过相互作用绑定在一起，能够形成自旋单态(singlet)，总自旋为 0，从而消除了杂质的自旋。

19 世纪 80 年代，Jones 等人首先研究了 2-IK 中的问题。他提出的 Hamilto-nian 为：

$$
H = \sum _ { k \sigma } \epsilon _ { k } c _ { k \sigma } ^ { \dagger } c _ { k \sigma } + J _ { 0 } [ s _ { c o n d 1 } \cdot s _ { i m p 1 } + s _ { c o n d 2 } \cdot s _ { i m p 2 } ] + J _ { 1 } s _ { i m p 1 } \cdot s _ { i m p 2 }\tag{5.10}
$$

这里 $s _ { c o n d 1 }$ 和 $s _ { i m p 1 }$ 描述一个自旋杂质和相应的电子库之间的自旋耦合，下标为 2 的描述了另一个。 $J _ { 0 }$ 描述了耦合强度大小。 $J _ { 1 }$ 是两个自旋杂质之间的耦合强度。σ 标记自旋。

如果我们仅仅考虑s波的耦合，这个Hamiltonian可以简化成一个1维模型，其中描述相互作用的项的具体形式为：

$$
\begin{array} { r l r } & { } & { H _ { i n t e r a c t i o n } = J _ { + } ( s _ { i m p 1 } + s _ { i m p 2 } ) \cdot \displaystyle \sum _ { k ^ { \prime } k } ( c _ { k ^ { \prime } e } ^ { \dagger } \sigma c _ { k e } + c _ { k ^ { \prime } o } ^ { \dagger } \sigma c _ { k o } ) + } \\ & { } & { J _ { - } ( s _ { i m p 1 } + s _ { i m p 2 } ) \cdot \displaystyle \sum _ { k ^ { \prime } k } ( c _ { k ^ { \prime } e } ^ { \dagger } \sigma c _ { k e } - c _ { k ^ { \prime } o } ^ { \dagger } \sigma c _ { k o } ) + } \\ & { } & { J _ { m } ( s _ { i m p 1 } - s _ { i m p 2 } ) \cdot \displaystyle \sum _ { k ^ { \prime } k } ( i c _ { k ^ { \prime } e } ^ { \dagger } \sigma c _ { k e } + h . c . ) + } \\ & { } & { J _ { k } ( s _ { i m p 1 } \cdot s _ { i m p 2 } ) \cdot \displaystyle \sum _ { k ^ { \prime } k } ( s _ { i m p 1 } \cdot s _ { i m p 2 } ) } \end{array}\tag{5.11}
$$

这里，产生算符 $c _ { k ^ { \prime } e } ^ { \dagger }$ 和 $c _ { k ^ { \prime } o ^ { \dag } }$ 从 $c _ { k ^ { \prime } \sigma } ^ { \dagger }$ 构造而来，其中 e 和 o 代表奇 (even) 和偶 (odd) 宇称。两个自旋杂质之间的交换耦合 (exchange coupling) 强度 ${ \cal J } _ { + , - } =$ $( J _ { e } \pm J _ { o } ) / 2 , J _ { m } = ( J _ { e } J _ { o } ) ^ { 1 / 2 }$ , 其中 $J _ { e , o } = ( J _ { o } / 2 ) ( 1 \pm s i n k _ { F } R / k _ { F } R )$ 。R 是两个杂质之间的距离，并且这里用费米波失 $k _ { F }$ 代替k。

在上面的耦合表达式中，前三项描述了局域化的自旋杂质和传导电子之间的交换耦合； $J _ { 1 }$ 描述了自旋杂质之间的耦合。这样， $J _ { + } , J _ { - } , J _ { m } , J _ { 1 }$ 构成了四个独立的参数。调节这些参数，可以描述从 $J \to - \infty$ (铁磁，ferromagnetic FM) 到$J \to + \infty$ （反铁磁，AF）的整个范围。

如上所述，两自旋杂质系统和但自旋杂质系统的最大的不同就在于两个自旋杂质之间存在反铁磁耦合 J，这导致了两种量子基态之间的竞争关系。当 J 强度比较弱，并且强度比单个杂质自旋和相应的传导电子之间的 Kondo 能量要弱时，整个系统表现地像单独的两个 Kondo 系统。这两套系统分别是一个杂质自旋和奇宇称通道耦合，另一个杂质自旋和偶宇称通道耦合。这里两种宇称通道指的是两侧传导电子和自旋杂质之间通道的线性叠加。另一方面，当 J 很强，两个单独的自旋杂质，它们每个都携带一个1/2自旋，会形成一个自旋单态。这样两个杂质作为一个整体，总自旋就为0，不会再再有Kondo 效应了。

如前所述，在一个双量子点中，每一个量子点都构成了一个自旋杂质，二者之间存在耦合。我们要在注意的是，如图 (5.3)，这里存在两种双量子点结构量子点：串联双量子点 (series coupled DQD) 和并联双量子点 (parallel coupledDQD)。在串联双点中，每个量子点和左右电极中的某一个耦合起来；在并联双点中，每个量子点和两个电极都和起来。这里同时存在两种耦和：隧穿耦合(tunneling coupling) 和电容耦合 (capacitive coupling)。前者存在两个电子之间的波函数的重叠，后者仅仅是库伦相互作用。

## 5.1.4 半导体双量子点中的 2-IK Kondo 问题

串联双量子点之间存在隧穿耦合，其Hamiltonian形式为：

$$
H = H _ { R } + H _ { L } + H _ { R - Q D } + H _ { L - Q D } + H _ { R - Q D } + H _ { R - I } + H _ { L - I } + H _ { D Q D }\tag{5.12}
$$

从左往右，各项依次表示：右侧传导电子；左侧传导电子；右侧量子点；左侧量子点；右侧传导电子 -自旋杂质耦合；左侧传导电子 -自旋杂质耦合；两个量子点之间的耦合。最后一项的表达形式为：

$$
{ \cal H } _ { D Q D } = t \sum _ { \sigma } [ d _ { U \sigma } ^ { \dagger } d _ { L \sigma } + h . c . ]\tag{5.13}
$$

每个量子点，到相应电极偶和强度为：

$$
\Gamma _ { R ( L ) } = \sum _ { k } | V _ { R ( L ) k } | ^ { 2 } \delta ( \epsilon _ { R ( L ) k } - E _ { F } )\tag{5.14}
$$

如果两个量子点之间的耦合足够小，套用式 (5.9)，可以得到两个量子点的各自的 Kondo 温度。假如我们的系统非常对称，也就是左右两边 (量子点) 内的充电能和杂质 -传到电子耦合强度都相等，那么当我们调节两个量子点之间的耦合 t 时候，耦合 t，反铁磁耦合 $J = 4 t ^ { 2 } / U$ 和 Γ 之间存在竞争关系。令人感到有趣的是，理论上[99]，这里存在两种相变过程，分别是atomicKondo（也就是两个单独的 Kondo）到 Conherent bonding Kondo Singlet；atomic Kondo 到 Singlet。如图5.4 显示了调节各个参数下的相变过程。

![](images/3f06191dbef84087dd22214693c2a259d7a1ef1de71c4545671171428e5042ba.jpg)  
图5.4 串联双量子点 2-IK 相图。这里， $j = J / T _ { K } = 4 t ^ { 2 } / U$ ，J 是两个量子点之间等效反铁磁耦合能，t 是两个量子点之间的隧穿耦合能。Γ 是量子点到源漏电极的隧穿速率。 $T _ { K }$ 是 Kondo 温度。这里假定了整个系统是完全对称的，不再区分左右不同。横纵坐标并不独立。电子充电能 U 不同的条件下，单独调节 t，在像图上走过的轨迹也不一样。相图的左下角，t 很小时，系统近似为两个独立的 Kondo 过程，称为 atomic Kondostate； $t > \Gamma$ 时，系统的基态是 coherent bonding Kondo 态；当 $t < \Gamma$ 时，如果 ${ \mathrm { j } } { > } 2 . 5$ ，则系统的基态是两个自旋杂质绑定成的 Singlet 态。图片摘自[99]。

当 $t < \Gamma$ 时，可以认为系统处在两自旋杂质情形。这里的关键参数 (criticalparameter) 是 $J / T _ { K }$ 。当 $J = 4 t ^ { 2 } / U \leqslant 2 . 5 T _ { K }$ 时，双量子点系统表现的像两个独立的自旋杂质，各自存在一个 Kondo 效应。当 $J > 2 . 5 T _ { K }$ 时，两个杂质自旋绑定成一个自旋单态，总自旋为0，不再显示出Kondo 效应。

当 $t > \Gamma$ 时，反铁磁偶和强度 J 不是那么重要了。两个量子点之间的隧穿导致每个量子点中 Kondo 态的相干叠加。这里形成了一个 Coherent Bonding KondoSinglet。

对于并联双量子点，如果我们只考虑反铁磁耦合，总的来说和串联双量子点的讨论非常相似。但是这里，单个自旋杂质和传导电子之间的耦合应当是$\Gamma = \Gamma _ { L } + \Gamma _ { R }$ 。但是从几何上可以看出来，如果 t 非常小，那么在串联双点钟，整个电导值必然会非常中。当 t=0 时，也就没有电流了。但对于并联双点，则不存在这种问题，因为每个量子点都独立形成了一个通道，那么不管它们之间的耦合如何，总归会有电流的。在关键点附近，串联双量子点中的电导理想值是 $2 e ^ { 2 } / h$ ，而并联双点的电导理想值是 $4 e ^ { 2 } / h$

尽管上面的理论给出了若干量子相变过程，但是在耦合双量子点系统中，量子点间隧穿矩阵 t 对关键参数来说是一个相对微扰，j 和 t、Γ 也不是独立的坐标，很难精确地实现这个相变过程。相对的，在交界处存在“两个单独的Kondo 态”，“Coherent Bonding Kondo 态”和“Singlet 态”的混合。在输运过程上，基于 slave-boson 平均场方法的数值据算表明:1 当 t 足够大，以至于系统处于 Coherent Bonding Kondo 态时；2 t 较小，但是 $J = 4 t ^ { 2 } / U$ 足够大，系统处于Singlet 态。这两种情况下，我们能够观察到随着源漏电压，原本的中央 Kondo峰的劈裂。这样，如果我们能调节两个量子点之间的耦合 t，那么我们显然应当能观察到单峰到双峰的转变过程。这个过程已经被 Jeong 和 A.Chang 等人在砷化镓半导体双量子点系统中观察到。在我们要介绍的四量子点系统中，同样可以观察到这一特征现象。

## 5.2 四量子点中的 Kondo 效应

在过去的十几年中，在操作半导体量子点上，人类取得了一些列进步，使得我们能够非常精确地调节系统中的参数 [100–103; 90; 91; 104–107]。在前文中，我们介绍了在半导体量子点上，Kondo 效应研究的一些基本进展。许多理论和实验工作，已经是我们对单量子点上 Kondo 效应有了非常坚实的认识[100; 99]; 进一步的，从单量子点到双量子点，更多丰富的物理过程出现了并在实验上被观察到了[103;90;91;107]。结合上一章的内容，非常自然地，在2-IK基础上，我们可以考虑两个耦合的 2-IK 系统，是否可能存在什么新的物理过程。也就是四量子点上的Kondo 效应。

这里，我们研究了一个四量子点系统个，它包括两组 (平行) 双量子点和三种相互作用：1 在某一组双量子点中，每个量子点和它相应的电子库中的传导电子之间的 Kondo 相互作用；2 在某一组双量子点中，两个量子点之间的Heisenberg 相互作用；3 在两组量子点之间的 Ising 相互作用。只含有 Ising 或者Heisenberg相互作用的情况，已经在实验上被报道过。但是到本文完成为止，我们并没有发现有实验上报道过一个同时含有这两种相互作用的系统中的 Kondo效应。

这里，我们是用的是电容耦合双量子点系统 (亦即四量子点)。这种系统已经被包括我们组在内的许多组所制作和研究过，工艺和物理参数描述上已经非常成熟[108; 109; 27]。接下来的内容，我们会介绍在这个系统上观察到的现象。

## 5.3 本章小结

本章主要关注了电容耦合双量子点上的Kondo 输运性质。

Kondo 效应来源于杂质电子和传导电子之间散射过程中自旋的交换。它首先发现于磁性金属，但是量子点也是一个观察 Kondo 效应的极好的体系。我们依次介绍了量子点中的 1-Ik和 2-IK过程。它们分别对应了单量子点和双量子点的情况。

非常自然地，我们引入了四量子点，并对其中的 Kondo 过程进行了研究并观察到了一些列全新的 Kondo 效应，它们的特征是：存在一个中央峰，同时每侧至少存在两个额外的 Kondo 峰。进一步，如果我们调节下面的双量子点，能够发现一个类似从 atomic Kondo 到 coherent singlet 的相变过程，并最终出现四个 Kondo 峰。

由于硬件条件上的一些限制，实验中存在一些缺陷，特别是不能通过施加磁场来确认多峰过程和自旋之间的关系。我们希望未来能够进一步深入地研究这个问题。

## ㅢ 6 章 全文ᙱ结

本文主要围绕着 GaAs/AlGaAs 半导体双量子点的量子控制和输运性质来展开。

第一章，我们对半导体异质结门控量子点的基本概念做了介绍: 包括二维电子气的概念，如何形成量子点，如何进行基本的控制和读出以及最基本的模型“常相互作用模型”。由于我们的目的是为了在半导体门控量子点上制作量子计算机，或者说一系列量子门，于是我们从 DiVincenzo 的五条判据出发，以电荷量子比特为基础，依次介绍了半导体门控量子点在这五条基本判据上的进展。同时简要涉及了一些其他实现体系。我们的目的，是对半导体量子点的优势和不足给出一个全面的介绍。

第二章，我们主要介绍完成实验所需要基本硬件条件，包括样品的制作过程和极低温微纳信号平台的建设。首先在制作过程中，我们完整地给出了样品制作中的所有步骤: 清洗，湿法刻蚀，紫外光刻，金属镀膜，退火，电子束刻蚀，wire-bonding，初步测量甄别等等，以及我们认为是一些技巧或者需要重点注意的地方。由于加工仪器的具体参数和操作步骤不同，这里没有涉及到具体加工仪器的使用。在极低温和微纳信号平台建设部分，我们以 Oxford 公司的Triton 300 无液氦稀释制冷机为基础，描述了一个改装的具体实例，包括我们自己设计和使用的线夹式热沉，铜粉滤波器以及 PCB 板载滤波器等等。这些技术是在参考国内外其他小组和继承本小组多年来技术积累的基础上，摸索和总结的一套方法。

第三章，我们以一个双量子点结构上真实的光子辅助隧穿 (PAT) 实验为出发点，介绍了一些实验用的各种基本技术，包括测量电子点温度，量子点之间的耦合强度，电极电压 -能量转换系数 (level arm) 等等。通过这些基本技术，我们能够在两能级系统这个模型上，建立起对量子点中物理系统的描述。这些技术也将在后面两章中继续出现。紧接着，我们描述了一个 PAT 实验的过程。在这个实验中，我们实现了一个远离热平衡条件下的电荷量子比特中的PAT过程。实验中观察到了最高 14 阶的 PAT 过程，同时在电子温度高于 2K的条件下，证明了存在一个LZS干涉过程。进一步，我们测量了电荷态弛豫时间T 约在8ns，与之前人们在稀释制冷机(更低的晶格温度) 上完成的实验结果基本一致。

第四章，在证明了对双量子点 (单比特) 量子操纵的能力之后，为了实现受控量子门操作，我们必须进步一开展两比特操作的实验。我们选择的实现方式是直接电容耦合双量子点 (四量子点)。首先我们以受控量子非门为基础，介绍了实现受控量子门的方法。这里的关键在于明确系统的所有参数，特别是两组双量子点之间的耦合强度 J。我们通过将上一章中的 PAT 技术应用到四量子点上，成功了测量了耦合强度J。这为我们实现两比特受控量子非门的操作奠定了坚实的基础。

第五章，在量子操作之外，量子点本身的输运性质一直也是人们关注的重点。特别是它具有参数可控性好这一优秀特点，使得本身成为了细致研究 Kondo 效应的有力工具。这一章中，我们首先介绍了单量子点上的单杂质Kondo 效应和双量子点上的双杂质 Kondo 相应。因此非常自然地，我们在四量子点系统上展开了对 Kondo 效应的研究，观察到了一些列全新的物理现象：存在一个中央峰，同时每侧至少存在两个额外的 Kondo 峰。调节其中一组双量子点，能够发现另一组双量子点中出现一个类似于从 atomic Kondo 到 coherentsinglet 的相变过程，并存在一个四峰的新特征。移除下面的双量子点，重复这个实验，我们发现四峰的特征消失，因此证明了这种新特征来源于两组量子点之间的耦合。
