## 摘要

门控量子点是各种可能的量子计算实现中一个兼容性比较好的方案。谐振腔可提供一个单频的光子谐振环境，用作将两个相距较远的量子比特耦合起来，实现量子计算系统中量子比特数目的扩展。本文从这两点出发，以实现量子点和谐振腔耦合为目标，逐步研究了谐振腔的结构、设计和测量方法，谐振腔与二维电子气的耦合，谐振腔与量子点的相互作用等问题。本文主要包括以下内容：

1. 研究背景和基本概念。介绍了量子计算的基本知识。重点讨论了门控量子点结构的基本理论框架和实验现象，以及量子点中电荷量子比特编码。

2. 微纳加工工艺。介绍半导体量子点的加工工艺流程，低温平台的改建和基本的量子点测量方法。

3. 谐振腔基本知识。介绍了集总谐振电路和分布式谐振电路的理论以及量子化描述。仔细讨论了透射式谐振腔、反射式谐振腔和3D谐振腔等3种微波谐振腔的设计，加工和测量表征的方法。

4. 反射式谐振腔及其调谐。详细介绍了一个实际的反射式微波谐振腔，包括具体的样品结构和测量方法。研究了利用二维电子气调谐谐振腔的设计，可大范围地调节谐振腔的品质因子。

5. 谐振腔测量量子点复导纳。详细介绍了使用反射式微波谐振腔来测量孤立量子点的实验方法。通过谐振腔的反射频谱的振幅和相位的移动，可以测量出孤立量子点的电阻电容并估计出隧穿率。

6. 腔量子电动力学。介绍了基本概念，量子点与谐振腔耦合的理论分析，并结合具体的实验讨论了样品参数的提取过程。

本文的主要创新点有：

1. 设计并实现了一种半波长反射式微波谐振腔，这种结构具有易于加工，便干耦合多个系统的特点。研究发现了一种使用二维电子气调谐谐振腔的方法，可通过调整门电极电压大范围地控制谐振腔的品质因子。

2 利用高品质因子谐振腔实现了对近似孤立量子点的复导纳的测量，提供了一种灵敏探测孤立量子点的新方法。通过谐振腔反射谱振幅和相位变化的蜂窝状相图确定了双量子点的存在，并可从变化大小计算出量子点的隧穿率。

3. 模拟实现了3D谐振腔结构，并系统地讨论了在3D谐振腔中添加直流引线的可能性以及实际的影响。并通过实验测试了实际的效果。

4. 研究了谐振腔和量子点的电偶极子耦合结构。在弱色散极限区测量到了量子点的相图，并从中拟合出耦合参数。

关键词：门控量子点，反射式谐振腔，复电导，谐振腔调谐，3D谐振腔，偶极耦合

## 第一章 研究背景介绍

## 1.1 量子计算的基本概念

可控核聚变技术，高温超导技术和量子信息技术是现代物理学应用和研究中的“三座大山”。量子信息技术主要包括量子通讯和量子计算两个方面。在本文中，我们将关注的焦点放在量子计算上。

量子计算研究最早的起源是为了解决经典计算中的能耗问题。Bennett研究发现，在经典计算中，由于逻辑操作的不可逆性，计算过程中必然产生能量消耗。Bennett证明了所有经典不可逆的计算机都可以改造为可逆计算机，而不影响其计算能力[1]。可逆计算意味着所有操作为幺正变化，所有行为都可以用量子力学语言表述出来。但这种量子可逆计算机并没有用到量子叠加性和相干性等量子力学区别于经典力学的本质特性。1995年，Shor提出了可在多项式时间内完成大数质因子分解的量子算法，其核心是应用了量子快速傅立叶变换[2]。这个算法利用了量子叠加来实现并行性，展现出量子计算超越经典计算的强大潜力，直接推动量子计算成为科研前沿和战略目标。1996年，Grover提出了另一个实用的量子计算算法：可实现平方加速的量子搜索算法[3]。

有了量子计算数学架构的伟大成功，人们开始研究如何在真实的物理体系中实现量子计算。2000年，IBM科学家Divincenzo提出了在真实物理体系中实现量子计算所必须满足的五个基本要求[4]：

1. 具有可控的量子比特，并且具有可扩展性。首先要能够实现量子比特，能将真实体系的物理参数编码到逻辑上的0和1量子比特。其次，多比特的量子计算才能和经典计算相比体现出优越性，因此物理上实现的量子比特数目要有一定的规模性，量子比特之间能互相分辨，即系统可扩展。

2. 能够将量子比特制备到初态。在进行量子计算之前，所有量子比特都需要初始化到我们已知的简单状态。如果需要量子纠错，则体系在计算过程中能够提供这种已知状态的空白比特。

3. 能够在较长的时间内保持量子相干性。量子体系与环境的耦合必然会造成量子相干性的丧失，因此体系需要有比较长的退相干时间，使得量子运算操作和测量得以完成。

4. 能够实现普适的量子逻辑门操作。任意的量子幺正操作都可以通过一组普适量子逻辑门来完成，因此实现了普适逻辑门原则上就可以完成任意的量子计算。

5. 能够进行量子逻辑门测量。即量子体系的末态能够被测量读出。

当然没有一个真实的物理体系能够完美的实现五条Divincenzo判据，因此科学界在多种可能的物理体系中进行了探索研究。其中比较典型的有：

1. 线性光学方案[5,6]。利用光子的极化态作为量子比特编码。优势在于绝大多数操作都可在室温下完成，光子与环境相互作用弱，相于性非常好等。

2. 离子井方案 [7,8]。

3. 核磁共振方案 [9]。

4. NV色芯方案。这是一种利用自旋编码的方案。在金刚石晶体中掺入氮原子，氮空位上就会有多余的电子就会表现出自旋。NV色芯实现单个量子比特的效果非常好，因为其周围的自旋背景干扰非常小，所以消相干时间非常长，被认为是一种非常有潜力的量子计算体系。NV色芯的自旋可以通过激光和微波实现操作和测量。多个NV色芯之间的纠缠实现也在进一步研究之中。

5. 超导约瑟夫森结方案[10-12]。超导约瑟夫森结是由“超导体-绝缘体-超导体”组成的“三明治”结构，超导电子岛通过约瑟夫森结与外界相连，就构成了 Copper-pair box。约瑟夫森结两侧超导体的相位差与超导电子岛中额外的 Copper-pair 数相共轭，使其构成了一个良好的量子系统。随着超导约瑟夫森结充电能和耦合能的不同，可将量子比特编码在不同的物理量上，分别是电荷量子比特，磁通量子比特和相位量子比特。单个量子比特操作通过微波脉冲来实现，量子比特之间通过直接的电容耦合或微波谐振腔相互作用，就可实现两比特逻辑操作。随着 transmon 这一创造性结构的提出和腔量子电动力学的发展，超导量子比特的退相干时间得到很大的提升，各种复杂的量子操作也得以实现，如Telepotation操作等。这是目前发展较完善的固态量子计算体系。

6. 量子点方案。量子点是指人工制造的电子孤岛结构。由于电子在三维空间上的运动受到限制，量子点内部形成了分立的能级结构，体现出量子特性。量子比特通常编码在电荷或电子自旋上。另一种方案是采用电子自旋来编码。单个量子点的操作可通过微波脉冲来实现，多个量子点之间的也可通过直接电容或微波谐振腔来耦合。目前的实验瓶颈主要在于量子点与环境耦合较强，退相干时间短，很难实现复杂的量子操作。

本人研究生期间的工作主要集中在门控型量子点上展开的，因此下面着重讨论一下量子点体系的一些基本结构和研究方法。

## 1.1.1 基本结构

半导体异质结中存有二维电子气层。以 $\mathsf { G a } \mathsf { A } s / \mathsf { A l } _ { \mathsf { x } } \mathsf { G a } _ { 1 - \mathsf { x } } \mathsf { A } s$ 为例，如图1.1所示。GaAs导带和价带之间的能量差为1.42eV， $\lambda \lambda _ { x } G a _ { 1 - x } A s$ 导带和价带之间的能量差为1.79eV(x=0.3时)，因此在两种材料的交界面出会出现能量不匹配的现象，造成能级扭曲。此时若材料中由于注入离子而产生多余的电子，则自由电子就会聚集在异质结结合处形成的势阱中。这层电子只能在平行于交界面的平面内自由移动，而不能穿过势阱沿垂直方向移动，故称为二维电子气[14]。如果将二维电子气层中自由移动的电子通过某种结构在空间上束缚到很小的范围内，就可以形成量子点。这种阻碍电子移动的结构被称为隧穿势垒，约束在量子点中的电子通过量子隧穿效应可穿过隧穿势垒进入或跳出外界电子库，电子进出的电子库分别称作源极和漏极。从电子隧穿的方向上分，量子点可大致分为纵向结构和横向结构两种，如图1.2所示。纵向量子点是指材料生长时在二维电子气层上下两侧用绝缘层隔开形成势垒，再将刻蚀成孤岛结构，就可以在三个方向上约束电子的运动形成量子点。这样源极和漏极分别在二维电子气上下两侧，电子需要纵向穿过绝缘层才能形成电流，故称为纵向量子点[16]。另一种结构是在二维电子气层上方制作表面电极，通过施加负电压局域地将电极下方的二维电子气排空，形成隧穿势垒。由于此时源极、漏极和量子点都在同一层二维电子气中，所以称为横向量子点[17]。由于横向量子点在加工制备和测量上都简单于纵向量子点，并且可调节性强，因此我们都是选用横向量子点作为研究工作对象。

## 1.1.2 单量子点的性质

通常量子点结构中还有一个或多个门电极，门电极通过电容耦合的方式作用于量子点中电子能级。改变门电极电压，量子点中电子的能级会随之抬高或降低。当电子能级高于（或低于）源/漏电极中的静电势时，就会发生电子跳出（或跳进）量子点的隧穿现象。因此可以通过调节门电极电压可以控制量子点中电子的进出。更一般地，可以将量子点看作是一个充放电子的孤岛，用常相互作用模型来分析电子的行为[18]。

常相互作用模型主要基于两个基本假设：

1. 量子点中电子与各个电极之间的库伦相互作用以及量子点中电子之间的库伦相互作用都是电容性质的，而且所有电容都可以简单地视为常数。

2. 量子点的能级为量子点中量子化能和它与源、漏、门电极之间的库伦相互作用能之和。它不受电子间相互作用的影响，即能级不随电子数量的变化而变化。

考虑最简单的单量子点的情况，量子点对外界总的电容C可以表示成量子点与源电极、漏电极和门电极之间的电容 $\complement _ { s } , \complement _ { \mathbf { d } }$ 与 $\complement _ { 9 }$ 之和：

$$
\mathsf C _ { \Sigma } = \mathsf C _ { s } + \mathsf C _ { \mathbf d } + \mathsf C _ { \mathbf g }\tag{1.1}
$$

当源电极电压为 $v _ { s }$ ，漏电极电压为 $\mathsf { v } _ { \mathsf { d } }$ ，门电极电压为 $\boldsymbol { \cdot } \boldsymbol { v } _ { \mathfrak { g } }$ 时，量子点上诱导出来的感应电荷为 $\mathsf { Q } = \mathsf { C } _ { s } \mathsf { V } _ { s } + \mathsf { C } _ { d } \mathsf { V } _ { d } + \mathsf { C } _ { g } \mathsf { V } _ { \mathsf { g } }$ 。因此对有N个电子的量子点体系，其总能量可以表示成为：

$$
\mathsf { U } ( \mathsf { N } ) = \frac { 1 } { 2 C _ { \Sigma } } [ - | e | \left( \mathsf { N } - \mathsf { N } _ { 0 } \right) + C _ { s } \mathsf { V } _ { s } + \mathsf { C } _ { \mathsf { d } } \mathsf { V } _ { \mathsf { d } } + C _ { g } \mathsf { V } _ { g } ] ^ { 2 } + \sum _ { \mathfrak { n } = 1 } ^ { \mathsf { N } } \mathsf { E } _ { \mathfrak { n } } ( \mathsf { B } )\tag{1.2}
$$

![](images/9021006289cc9f7e854fcd9418f06e8a89c389ac9f6bc0c240a18478bdf89dac.jpg)

其中 $\mathsf { N } _ { 0 }$ 是门电极电压为零时量子点内的电子数目， $\mathtt { E } _ { \mathfrak { n } }$ 为第n个电子的单电子能级，它由束缚势阱的性质所决定，B表示单电子能级还和外加磁场有关。

为了更好的描述量子点的输运性质，通常引入电化学势的概念。量子点的电化学势定义为在量子点中加入第N个电子时所需要的最小能量，它可以看作是量子点中的能级：

$$
\begin{array} { l } { { \displaystyle { \bf { \boldsymbol { \mu } } } ( { \bf N } ) = { \bf { \boldsymbol { \mu } } } ( { \bf N } ) - { \bf { \boldsymbol { \mu } } } ( { \bf N } - { \bf { \boldsymbol { \mu } } } ) } \ ~ } \\ { { \displaystyle ~ = ( { \bf N } - { \bf { \boldsymbol { \mu } } } _ { 0 } - \frac { 1 } { 2 } ) { \mathbb E } _ { { \bf { c } } } - \frac { { \mathbb E } _ { { \bf c } } } { e } ( { \mathbb C } _ { s } { \bf V } _ { s } + { \mathbb C } _ { \bf d } { \bf V } _ { \bf d } + { \mathbb C } _ { 9 } { \bf V } _ { 9 } ) + { \mathbb E } _ { \bf N } } } \end{array}\tag{1.3}
$$

从上式可以看到，电化学势直接受到门电极电压的影响，通过调节门电压可以改变量子点中的能级结构。相邻两个能级的能量差被称为增加能：

$$
\mathsf { E } _ { \mathsf { a d d } } = \mathsf { \mu ( N ) } - \mathsf { \mu ( N - 1 ) } = \mathsf { E } _ { \mathsf { c } } + \Delta \mathsf { E } ( \mathsf { N } )\tag{1.4}
$$

上式由两项组成，一项是量子点内单电子能级的能量差 $\Delta \mathsf { E } ( \mathsf { N } ) = \mathsf { E } _ { \mathsf { N } } - \mathsf { E } _ { \mathsf { N } - 1 }$ 与电子具体的量子态形式有关。另一项为量子点上单电子电荷能 $\mathsf E _ { \mathsf C } = { \mathsf e } ^ { 2 } / { \mathsf C } _ { \Sigma }$ 是由经典的库伦相互作用所引起的，称之为量子点的充电能。通常量子点的尺寸非常小，因此C也特别小，充电能很大（约为几个到十几个meV)，远远大于量子点本身的单电子能级能量差。因此量子点能级差主要由充电能所决定，可以近似认为是等间隔的，不依赖与电子数目和电极电压。

在了解量子点内电子的能级分布后，我们进一步讨论电子的隧穿输运过程。量子点能级示意图如图1.3所示。左右两边分别是源漏电极，电子在其中按费米分布填充，费米能级分别为 $\mu _ { s }$ 和 $\mu _ { \mathsf { d } }$ 。中间分立的竖线表示量子点能级，两两间隔为 $\mathtt { E _ { a d d } }$ 。在其两侧的竖线表示量子点与源漏之间的势垒，电子可以通过量子隧穿效应穿过势垒进入源漏中形成电流。我们通常考虑两种不同的输运条件：

## 1. 量子点源漏的直流偏压很小或为零

此时源漏费米能级差 $\mu _ { s } - \mu _ { d } \approx 0$ ，左右费米面在同一条直线上。显然，所有量子点内能量低于费米面的能级都已经被电子填充，源漏电子不能隧穿到其上形成电流；所有能量高于费米面的能级虽然未被填充，但由于能量差的原因亦不能形成隧穿电流，量子点处于阻塞状态，称为库伦阻塞。库伦阻塞必须在低温环境下才能观察到，这是因为温度会造成费米分布的展宽，若源漏电极电子的费米展宽与量子点能级间隔相当，则电子还是有一定几率隧穿过量子点形成电流的。因此量子点工作时要求电子温度足够低，对应热涨落要远小于量子点充电能：

$$
{ \sf k T } _ { e } \ll { \sf E } _ { C } = e ^ { 2 } / { \sf C }\tag{1.5}
$$

另一方面，假设此时的等效电阻为R，则电子隧穿过量子点所需时间为 $\mathbf { t } \sim \mathbf { R } \mathbf { C }$ 对应能量的不确定度为 $\mathsf { E } \sim \mathsf { h } / \mathsf { t } \sim \mathsf { h } / \mathsf { R C }$ ，这个能量也要求远小于量子点充电能$h / R C < < e ^ { 2 } / C$ ，因此量子点的隧穿电阻应远大于标准电阻

$$
R > > R _ { 0 } = { \ h } / { e ^ { 2 } }\tag{1.6}
$$

通过改变控制门电极电压，我们可以线性的影响量子点内的能级位置，使其上下移动。当量子点的第N个能级恰好与源漏费米面平齐时，源电极上的电子隧穿进入第N个能级，再由第N个能级隧穿进入漏电极，形成单电子隧穿电流。由于量子点能级是近似等间隔的，所以不断地改变电压，我们就可在电压等间隔的位置上观察到一个个电流信号，这种周期性的电流信号被称为库伦振荡[18]。如图1.4所示。

## 1.1.3 双量子点的性质

双量子点的性质也可以用常相互作用模型来描述[20-24]。如图1.6所示，串联双量子点中每个量子点通过图示电容分别与门电极，源漏电极以及量子点之间相互作用。电路平衡条件为：

$$
\left( \begin{array} { c c } { { \mathrm { Q } _ { 1 } + \mathrm { C } _ { \mathrm { L } } \mathrm { V } _ { \mathrm { L } } + \mathrm { C } _ { { \mathrm { g } 1 } } \mathrm { V } _ { { \mathrm { g } 1 } } } } \\ { { \mathrm { Q } _ { 2 } + \mathrm { C } _ { \mathrm { R } } \mathrm { V } _ { \mathrm { R } } + \mathrm { C } _ { { \mathrm { g } 2 } } \mathrm { V } _ { { \mathrm { g } 2 } } } } \end{array} \right) = \left( \begin{array} { c c } { { \mathrm { C } _ { 1 } } } & { { - \mathrm { C } _ { \mathrm { m } } } } \\ { { - \mathrm { C } _ { \mathrm { m } } } } & { { \mathrm { C } _ { 2 } } } \end{array} \right) \left( \begin{array} { c c } { { \mathrm { V } _ { 1 } } } \\ { { \mathrm { V } _ { 2 } } } \end{array} \right)\tag{1.7}
$$

体系的总能量为：

$$
\mathsf { E } = \frac { 1 } { 2 } \sum _ { \mathrm { i } = 1 , 2 } \mathsf { V } _ { \mathrm { i } } \mathsf { Q } _ { \mathrm { i } }\tag{1.8}
$$

使用前面单量子点讨论中类似的方法，可以定义两个量子点的电化学势分别为：

$$
\begin{array} { r l } & { \mathfrak { u } _ { 1 } ( { \mathsf { N } } _ { 1 } , { \mathsf { N } } _ { 2 } ) = ( \mathsf { N } _ { 1 } - \frac { 1 } { 2 } ) \mathsf { E } _ { \mathsf { C } _ { 1 } } + \mathsf { N } _ { 2 } \mathsf { E } _ { \mathsf { C } _ { \mathsf { m } } } - \frac { 1 } { | e | } ( \mathsf { C } _ { 9 1 } \mathsf { V } _ { 9 1 } \mathsf { E } _ { \mathsf { C } _ { 1 } } + \mathsf { C } _ { 9 2 } \mathsf { V } _ { 9 2 } \mathsf { E } _ { \mathsf { C } _ { \mathsf { m } } } ) } \\ & { \mathfrak { u } _ { 2 } ( { \mathsf { N } } _ { 1 } , { \mathsf { N } } _ { 2 } ) = ( \mathsf { N } _ { 2 } - \frac { 1 } { 2 } ) \mathsf { E } _ { \mathsf { C } _ { 2 } } + \mathsf { N } _ { 1 } \mathsf { E } _ { \mathsf { C } _ { \mathsf { m } } } - \frac { 1 } { | e | } ( \mathsf { C } _ { 9 2 } \mathsf { V } _ { 9 2 } \mathsf { E } _ { \mathsf { C } _ { 2 } } + \mathsf { C } _ { 9 1 } \mathsf { V } _ { 9 1 } \mathsf { E } _ { \mathsf { C } _ { \mathsf { m } } } ) } \end{array}\tag{1.9}
$$

其中：

$$
\mathsf { E } _ { \mathsf { C } _ { 1 } } = e ^ { 2 } \frac { \mathsf { C } _ { 2 } } { \mathsf { C } _ { 1 } \mathsf { C } _ { 2 } - \mathsf { C } _ { \mathsf { m } } ^ { 2 } } , \mathsf { E } _ { \mathsf { C } _ { 2 } } = e ^ { 2 } \frac { \mathsf { C } _ { 1 } } { \mathsf { C } _ { 1 } \mathsf { C } _ { 2 } - \mathsf { C } _ { \mathsf { m } } ^ { 2 } } , \mathsf { E } _ { \mathsf { C } _ { \mathsf { m } } } = e ^ { 2 } \frac { \mathsf { C } _ { \mathsf { m } } } { \mathsf { C } _ { 1 } \mathsf { C } _ { 2 } - \mathsf { C } _ { \mathsf { m } } ^ { 2 } }\tag{1.10}
$$

## 1.2 量子点中的电荷量子比特编码

下面参照Divincenzo判据，讨论量子点中使用电子电荷作为量子比特编码方案。

1. 量子比特实现。处于能量的考虑，通常采用双量子点作为一个电荷量子比特。当量子点中的电子被排空到仅剩一个时，电子在左点和在右点就可以定义两个不同的态。若双量子点之间存在耦合，则整个双量子点可以用以下的哈密顿量描述：

$$
\mathsf { H } = \frac { 1 } { 2 } \varepsilon \sigma _ { z } + \Delta \sigma _ { \mathsf { x } }\tag{1.13}
$$

很自然地，可以将量子比特的0和1编码到由上式所定义的二能级体系的两个本征态上，也可以用Bloch波矢来表示，如图1.9所示。

2. 量子比特操作。单比特量子操作主要是实现量子非操作，这可以通过Rabi振荡来实现[26,27]。如图1.10所示。在量子点的表面电极上加上一个能量匹配的高频脉冲，就可以使电子在bloch球上以x轴为轴线发生旋转。选择合适的旋转时间，使其相位恰好增加π，就可以实现量子非操作。这方面的实验工作已由Petta等人完成。两比特量子操作的关键是实现控制非门[28]，目前基于电荷量子比特编码的实验工作还没有完成，我们小组正在积极开展这方面的研究。

3. 量子比特测量。由于电荷量子比特的状态直接与电荷的分布情况有关，所以测量电荷量子比特是相对简单的。通常会采用QPC结构[29,30]，即在量子点附近形成一个很窄的电流通道。由于库伦相互作用，量子点中的电子会对QPC 中的电子产生排斥作用。量子点中电子多时 QPC电流小，电子少时QPC 电流大。因此通过测量QPC中电流的大小就可以推测出量子点中的电荷分布，进而得到电荷量子比特的状态[31]。

4. 退相干时间。退相干一直是量子点量子计算系统中非常严重的问题。对电荷量子比特编码来说，GaAs半导体上的退相干时间在百皮秒量级，远远达不到实现复杂量子操作的要求。对此，采用自旋量子比特编码可能是比较好的解决方案，目前在GeSi量子点上的自旋量子比特相干时间已经达到了几十微妙量级。使用Echo技术可以延长量子比特的退相干时间[26]，如图1.12所示。假设原本处在0态的 qubit 受到外界影响，沿x轴发生偏转。

![](images/105dfe911962645b0998c24b2136ddda7108af1ee1ea143f6c92866f3f949276.jpg)  
图 1.12 Echo 技术中 Bloch 波矢的演化 [26]

这时我们迅速地将 qubit沿z轴旋转 π角度，则 qubit 受到外界影响继续发生偏转，但方向已于原来相反，在经过相同时间后又会重新回到0态。

5. 比特数目扩展。这也是量子点量子计算系统中比较受关注的问题。传统的方案是将临近的量子比特两两之间靠电容耦合起来。但这向多比特系统推广是有困难的。例如，电极的几何排列会变得非常复杂，处于中间位置的量子点很可能没有相应的OPC探测结构，两比特之间的门操作保真度会受到其他量子比特状态的影响[32]等。另一种可能的办法是仿照超导约瑟夫森结量子计算体系中借助微波谐振腔来实现量子比特之间的信息交换[33-39]。固态微波谐振腔可以将相隔距离较远的量子点耦合起来，每个量子点又可以保留原有的结构设计，是非常有希望的解决方案。这也是本文研究的出发点。

## 第二章 量子点的制备和基本性质表征

在本章中，我们将介绍微纳米加工工艺的一些基础知识，讨论门控量子点的制作工艺，以及基本的低温测量技术。

## 2.1 半导体量子点的制作工艺

量子现象通常在很小的尺度上才能体现出来。因此对于固态量子体系，微纳加工技术是制备样品的必须手段。实际上，随着科研条件技术的进步和实验仪器制作的发展，微纳加工技术已经成为固态体系研究中的标准技术，一流的物理研究单位都会配备微纳加工实验室。另一方面，我们实验中所使用的微纳加工技术和现在工业上使用的半导体加工工艺是完全兼容的。如果基于半导体量子点实现的量子计算方案能够发展成为主流的量子计算体系，那么现代半导体产业几乎不需要做大的改变就可以将其工业化生产，这是非常吸引人的。

在我们的样品制备过程中，主要用到的仪器设备包括紫外曝光机，电子束曝光机和蒸发镀膜设备等。下面我们将简要介绍这些设备的原理和使用。

紫外光学曝光机 紫外光学曝光与照相技术类似，利用了光刻胶对特定波长的紫外光线照射的敏感性。当紫外光透过设计好图形的掩模板照射到光刻胶后，照到光的部分和未照到光的部分性质变得不同。在显影步骤时，可以选择性地去除曝光或未曝光的部分后，于是就将掩模板上的图形结构转移为光刻胶的图形结构。

根据曝光部分和保留部分的不同，光刻胶的使用可以分为正胶和反胶两种，分别如图2.1所示。一般定义正胶为曝光部分被显影液洗掉，未曝光部分得以保留；反胶定义为未曝光部分被洗掉，曝光部分得以保留。正胶和反胶的效用没有本质区别，但在实际实验中，我们一般希望光刻掩模板大部分是透光的，这样便于在光镜下找到样品和对准光刻标记。但最终希望的到的光刻机图形不一定与掩模板阴影部分一致，因此需要配合光刻掩膜的设计来选择正胶或反胶工艺。由于光学曝光技术原理简单，操作方便，便于批量生产，所以我们在精度允许的范围内，总是优先使用光学曝光技术。我们实验室中使用的紫外光学曝光机型号为MJB3，如图2.2所示，实际可控的精度可以达到5微米。

成功的光学曝光需要注意以下几点：

1. 曝光参数的选择，包括甩胶转速和时间、烤胶时间、曝光时间和显影时间等。这些参数随着实验环境和仪器状态的不同而不同，合适的参数是经过大量试验总结积累得到的，需要非常细致的工作.

2. 掩模板的设计。光学曝光工艺比较流程化，关键的技术就在掩模板设计上。由于衍射效应，曝光后的得到的图形不是和掩模板上设计的图形完全一致的，尤其是在线宽比较细边缘区域，畸变较为严重。如果特别在意曝光后图形的形状，应在设计掩模板时予以补偿。另外，通常需要多次光学曝光才能完成样品的制作，两次曝光之间需要对齐位置，因此在设计相关掩模板时要留有对准标记和最外围的边线标记，以方便样品加工。

电子束曝光机 电子束曝光可以看作是光学曝光的提升。受到衍射极限的限制，光学曝光的精度只能与光的波长相当。即使使用波长较短的紫外光，一般实验室中使用的光学曝光机的精度仅为百纳米量级，在此长度之下的加工就要用到电子束曝光。通过高压电场，可以将电子加速到很高的能量，相应的德布罗意波长很短，因此就能达到更高的精度。

![](images/8d16341c39e02974a0d80e133ef7d11ba342a682cf25757ec927b82c2ef8e83b.jpg)  
图 2.3 电子束曝光平台

我们实验中使用的电子束曝光设备为一台美国FEI公司的 SEM（扫描电子显微镜）加上 Nanometer Pattern Generation System（NPGS）控制插件得到的简易系统。SEM 最高加速电压为 30kV，5 档光圈，7 档 spot size 可选。如图2.3所示与光学曝光类似，电子束曝光是利用了电子束曝光胶（如PMMA）对与电子照射的敏感性。PMMA受到电子照射后，分子链结构会发生变化，变得和未照射部分不同。在显影步骤时，将曝光部分溶解掉，就可以在PMMA胶层上制作出想要的图形。但与光学曝光不同，曝光结构不是由掩模板决定的，而是由电子束扫描路径决定的。在我们的仪器中，这项工作是由NPGS模块完成的。NPGS主要系统是一块数模转换卡，用于控制SEM中电子束的偏转，和一套控制软件，用于配置各种曝光参数。曝光图形的设计工作主要在装有NPGS插件的 DesignCAD 中完成。

与光学曝光相比，电子束曝光的操作较为复杂，注意事项多，且每个样品都需要单独加工，制作时间长。但电子束曝光的图形结构是直接在DesignCAD中设计的，更改很方便。通常可以用光学曝光技术批量制作好外围的电极结构，每次再根据实验目标和结构调整内部电子束曝光的设计图案。

成功的电子束曝光需要注意以下几点：

1. 曝光参数的选择，包括加速电压、光阑大小、spot size、曝光剂量、显影时间等。这些参数都是经过大量试验总结积累得到的，是非常细致的工作。受电子散射的影响，对于精细图形结构曝光剂量还会有差异，具体制作时还需进一步测试

![](images/ec9f002ab1a748b4523f2594b3dd6a3645f96b681c04164f0468048ca45fe053.jpg)  
图 2.4 镀膜和 lift off 示意图

2. 曝光图形的设计。电子束在偏移中难免会出现误差，因此在曝光时，最好让电子束从内到外，沿一个方向逐渐扫描，避免大范围的移动。在NPGS中，电子束移动的顺序是由设计图形的层次和顺序决定的。因此在DesignCAD软件中画好图形后，一定要一一检查每块图形的曝光方向和曝光顺序并模拟曝光，看是否和设想一致。

蒸发镀膜 前面的步骤只是将我们想要的图形结构制作到了光刻胶/电子束曝光胶层上，要将结构制作到样品表面，还需要经过金属蒸镀环节。在带图案的光刻胶上均匀蒸镀一层金属，光刻胶空隙处的金属就会直接吸附在样品表面。再经过溶胶环节，光刻胶和其上的金属会一起被剥离，最终附着在样品表面的金属就会呈现出我们设计的形状。这一过程被称作Lift-off。如图2.4所示

我们实验室主要有两台蒸镀设备：电子束蒸发镀膜机CHA40和国内设计制造的热蒸发镀膜机。如图2.5所示。金属蒸镀设备都是先将金属靶材变为气体，然后金属气体遇到冷的样品沉积在其表面。不同的是电子束蒸发是利用高能电子直接轰击金属靶材使其气化或升华，而热蒸发是通过电阻丝高温加热使其气化。CHA40的设计较为简单，使用时只需注意设定蒸镀厚度和蒸镀速率即可。热蒸发机主要提供了加热和测量膜厚的装置，蒸镀厚度和蒸镀速率需要靠人工调节来实现。

## 1. 刻蚀 mesa

(a) 晶圆切割。实验中使用的掺杂型 GaAs 晶圆是通过商业渠道购买的，一般采用分子束外延工艺生长而成，尺寸为4-6英寸。我们将一块完整的晶圆甩上保护胶（光刻胶）并烘干后，会用玻璃刀将其切割成小的晶片。一般1cmx1cm大小的方块比较合适，便于用镊子手持和后续加工。特别要注意的是整块的晶圆上是有晶向标记的，我们在切割好的晶片上也要标记好晶向。

(b)超声清洗。清洗是每进行一次新的加工步骤前都必须要采用的工序，目的在于去除晶片表面各种杂质和残胶。样品表面清洁与否，是成功制作出高质量量子点的关键。具体的清洗步骤和参数详见附录

(c) 曝光 mesa 掩膜。掩膜样例如图2.7(A)

(d)刻蚀基片。二维电子气约在基片表面下方百纳米处，为保证导电层刻蚀干净，我们选择刻蚀深度为200nm。

2. 制作欧姆电极。欧姆接触电极将二维电子气连通到样品表面，方便外部电路测量。

(a) 超声清洗。

(b)曝光欧姆电极掩膜。欧姆电极必然在mesa之上，所以这一步关键是要和已做好的 mesa嵌套对准。

(c) 蒸镀金属。经过前辈的摸索发现，Ni和 GeAu的混合物在熔融状态下可以很好的渗透半导体形成良好欧姆接触。我们在实验中使用的镀膜厚度和速率依次为 10nm Ni（1A/s）,150nm GeAu（2A/s）和 20nm Ni(2A/s)。

(d) Lift-off.

(e)退火。具体的参数也是前辈多次摸索研究得到的，详见附录。

## 3. 制作表面大电极

(a) 超声清洗。

(b)曝光电极掩膜。大电极需要越过mesa 台阶，一定要选择从 mesa侧坡面较平缓的一侧接入。因此在做光刻对准时要注意电极的走向和基片的晶向，对准正确的方向。

(c) 蒸镀金属。大电极材质为 Ti 和 Au，从样品外围一直延伸到 mesa 表面上，厚度至少要为mesa厚度的一半。我们实验中使用的镀膜厚度和速率依次为 10nm Ti（1A/s）和 100nmAu（2A/s)。

(d) Lift-off。这一步的结构尺寸较大，膜厚也小，因此很容易lift-off。通常用丙酮浸泡二十分钟后用吸管轻吹，即可将金属剥离下来。目测大部分金属脱离后，要将样品保持在液体浸润状态，在光学显微镜下仔细检查各处结构的金属剥离是否成功。如果剥离不彻底则可使用超声振动辅助，功率40%，35秒即可，不宜太猛。

## 2.2 低温测量平台

低温是观察到量子点中量子效应的必要条件。由能量换算关系 $\mathsf { E } = \mathsf { k } _ { \mathsf { B } } \mathsf { T } =$ ħω可以知道，一般双量子点中的典型能级劈裂 $2 \mathrm { t } _ { \mathsf { C } } \sim 1 0 \mathsf { G } \mathsf { H } z \sim 4 8 0 \mathsf { m } \mathsf { K }$ ，因此环境温度必须降到300mK以下才能避免能级热展宽大于能级差，观察到量子效应。我们这里所说的低温是指环境温度在液氦温度4.2K以下，极低温是指300mK以下。我们绝大多数的实验都是在极低温环境下完成的。

![](images/7742a34f4145b9327af3949982f355e2a768485825e5fef4c58f65dd8c8a6e36.jpg)  
图 2.8 液氮杜瓦样品杆

我们实验室有三种不同温度的低温测量平台：

液氦杜瓦直接将样品固定在自制的样品杆上，插入液氦杜瓦中，就可以获得4.2K温度的测量环境。样品杆如图2.8所示。4K温度下的测量主要用于在正式测量前判断样品的性质，主要包括：

a欧姆接触是否良好。在液氦温度下，二维电子气迁移率增加，电阻率降低，欧姆电极应呈导通状态。我们可以通过测量欧姆电极两两之间的电阻来判断欧姆接触制作的是否正常。在正常情况下，欧姆电极之间的电阻约为1KΩ量级。

b门电极之间是否短路和门电极和欧姆接触之间是否短路。最内层使用电子束曝光的电极可能在liftoff时金属剥离不彻底而造成短路，这种情况无法用光学显微镜观察到，只能依靠测量来判断。将20μV交流激励电压加在两门电极之间，测量漏电流来判断门电极是否短路。门电极与欧姆电极之间是否短路的判断方法于此类似。

c门电极的排空效应。给门电极加上负电压后会排斥其下方的电子，造成导电通道变小，对应的欧姆电极间电阻增加，观察到电流随着门电极负压绝对值的增大而减小。需要观察这种二维电子气排空效应是否是稳定的。例如将负电压固定到某值等待一段时间，观察电流是否稳定不变。如果电流随着时间变化（通常是慢慢变小)，说明二维电子气层存在耗尽现象，样品制作有问题，不宜进一步使用。还可将负电压逐渐改变后返回到之前的某个值，观察前后电流值是否一致。如果电流变化较大，也说明二维电子气不稳定。

d门电极的可调性。通常样品结构中会有多对可将电流彻底截断的门电极。对于这样的门电极，需要截止时加在电极上的负电压是否合理。截止电压会随着基片材料、样品结构、样品制作批次的不同而不同，但变化范围不会太大，通常在-0.7V到-1.5V之间。截止电压过大或过小说明门电极对其下方的二维电子气影响不理想，这样的样品往往不容易进一步精细调节。每对门电极电压之间的对称性也是非常重要的因素。可以记录门电极电压不同情况下的电流值，得到如图2.9所示的门电极关系相图。在2.9(B)中，等电流线（电流值相等的门电极电压组合点连成的线）呈明显的直角弯曲，任意一个门电极上的负电压增大一定程度就可以将电流完全截止，这说明二维电子气通道是被单个门电极所控制的，这样的样品可调性比较差，在极低温下不容易形成可控的量子点。在图2.9(A)中，等电流线呈一条斜线，而且斜率几乎不变。这说明这对门电极比较对称，当一个电极电压增大而另一个电极电压减小时，二维电子气通道收到均匀的影响而宽度几乎不变。这样的样品可控性很好，是非常理想的。

## 2.3 门控量子点的基本测量方法

门控量子点主要是通过电学信号进行测量的。在形成量子点区域，源漏之间电阻通常很大（通常MΩ量级），而源漏之间的偏压又不能很大（通常 $\mu \nu$ 量级)，所以实际能测到电流是很小的(pA量级)。对于这种微弱信号，最常用的方法是使用锁相放大的办法进行测量。我们实验中使用的锁相放大器为美国SRS公司生产的 SR830。假设输入信号（SIGNAL INPUT）为 $\boldsymbol { e } _ { 1 } = \mathsf { E } _ { 1 } \sin ( \omega _ { 1 } \mathrm { t } + \phi _ { 1 } )$ 参考信号（REFERENCE INPUT）为 $\boldsymbol { e } _ { 2 } = \mathbb { E } _ { 2 } \sin ( \omega _ { 2 } \mathrm { t } + \Phi _ { 2 } )$ ，这两个信号通过混合器（或PSD）相乘后得到

$$
\begin{array} { l } { { \displaystyle e _ { 3 } = e _ { 1 } \times e _ { 2 } = \mathbb { E } _ { 1 } \mathbb { E } _ { 2 } \sin ( \omega _ { 1 } t + \Phi _ { 1 } ) \sin ( \omega _ { 2 } t + \Phi _ { 2 } ) } } \\ { { \displaystyle \quad = \frac { \mathbb { E } _ { 1 } \mathbb { E } _ { 2 } } { 2 } \cos [ ( \omega _ { 1 } - \omega _ { 2 } ) t + ( \Phi _ { 1 } - \Phi _ { 2 } ) ] - \frac { \mathbb { E } _ { 1 } \mathbb { E } _ { 2 } } { 2 } \cos [ ( \omega _ { 1 } + \omega _ { 2 } ) t + ( \Phi _ { 1 } + \Phi _ { 2 } ) ] } } \end{array}\tag{2.1}
$$

其中第一项为低频部分，第二项为高频部分。在通过低通滤波器后，高频部分将被过滤掉。如果输入信号和参考信号是相关的 $( \omega _ { 1 } \sim \omega _ { 2 } ) , e _ { 3 }$ 就会变为

$$
e _ { 3 } = { \frac { \mathtt { E } _ { 1 } \mathtt { E } _ { 2 } } { 2 } } \cos ( \Phi _ { 1 } - \Phi _ { 2 } )\tag{2.2}
$$

在已知参考信号 $\mathtt { E } _ { 2 }$ 的情况下，调节参考相位使得 $\cos ( \phi _ { 1 } - \phi _ { 2 } )$ 为1，我们就可以得到输入信号 $\mathtt { E } _ { 1 }$ 了。注意在上式中输入信号 $\bf { E } _ { 1 } ( t )$ 是可以随时间缓慢变化的，但只要其相位保持不变，保证参考信号和输入信号之间的相位差 $\Phi _ { 1 } - \Phi _ { 2 }$ 保持恒定，我们测量信号 $_ { e 3 }$ 的变化就是真实的信号 $\mathsf { E } _ { 1 }$ 的变化。这就是“锁相”一词的意义。

锁相放大器对输入信号测量精度上的提高主要来自于低通滤波。通常我们总会将有效的输入信号与参考信号保持同频，而干扰噪声信号则是在整个频带上分布的。经过低通滤波后的实际测量信号带宽集中在以参考信号频率为中心的一段很窄的频带范围内，这样有效的输入信号就被保留了下来，而大部分干扰噪声信号被过滤掉了，因此增强 $\daleth$ 信噪比。与直接的低通滤波相比，锁相放大器可以选择测量信号的中心频带位置，使其处于干扰噪声较弱的频段，而不是零频（通常零频附近的干扰噪声信号最强）。所以在实际使用中，我们可以尝试不同的参考信号频率，选择效果最好的频段加以测量。理论上说滤波带宽越窄则信噪比增强越明显，但滤波是需要一定积分时间的，滤波带宽越窄则所需要的积分时间越长，所以锁相放大器实质上也是一种用时间换取测量精度的仪器。

在实际的实验中，我们有三种不同的方法利用锁相放大器来测量量子点信号，分别是：

1. 通过量子点输运信号测量。这就是直接测量量子点源漏之间电流的方法。如图2.15(a)所示，将锁相放大器的激励信号加在源漏通道上，锁相放大器的输入信号则为源漏之间的电流。设激励信号为 $\pmb { e } _ { 1 } = \pmb { V } \sin ( \pmb { \omega } \mathbf { t } + \pmb { \phi } )$ ，量子点电阻为R，则输入信号为 $\begin{array} { r } { e _ { 2 } = \frac { V } { R } \sin ( \omega \mathrm { t } + \phi ) } \end{array}$ ，因此我们实际测得的就是流过量子点源漏的电流 $\begin{array} { r } { e _ { 3 } = \frac { V } { R } = { \ I _ { \circ } } } \end{array}$ 改变门电极电压，使量子点中的电子数目发生变化，电子隧穿 $\gnapprox$ 生电流信号时，我们就可以测得一个个库伦峰，如图2. ${ \bf l } \ 6 ( { \bf a } )$ 所示。直接测量电流的缺点是当电子与源漏之间的隧穿几率变小时，电流信号会进一步变小 $( < 1 { \mathfrak { p } } \mathsf { A } )$ ，这时即使用锁相方法的办法也不能测到微弱的电流信号了。但我们往往希望量子点工作在“少电子，弱源漏耦合”的区域，这时通常很难直接测量到输运信号。

2. 通过QPC输运信号测量。为了解决直接输运测量的弊端，人们提出了量子点接触QPC的概念。通过施加电压，在量子点附近形成一个狭小的二维电子气通道，就被称为 QPC，QPC输运直接测量的连接方式如图2.15(b)所示，锁相放大器的激励信号加在QPC的源漏通道上，输入信号则为QPC源漏之间的电流。显然这种测量方式测得的就是流过QPC的电流 $\tt I _ { Q P C } .$ 但QPC对周围电势场的变化非常敏感，当量子点中的电子数目发生变化时，QPC的电导也随之改变。因此当改变量子点门电极电压形成库伦振荡时，我们在库伦峰对应位置就会观察到QPC电流上出现跃变，如图2.16(b)所示。改变 QPC 控制门电极电压可以调整 QPC 灵敏度，通常要求 QPC 电流信号中的变化量要大于本底信号的5%。

3. 通过 QPC 调制信号测量。这种测量方式的连接示意图如图2.15(c)所示，锁相放大器的输入信号为QPC源漏电流，但激励信号加在量子点的控制门电极上。设激励信号为 $\pmb { e } _ { 1 } = \pmb { V } \sin ( \omega \mathbf { t } + \pmb { \phi } )$ ，门电极直流偏置电压为 $\mathsf { v _ { d } }$ o我们知道门电极上的电压会影响量子点的状态，进而影响QPC电流。通常$\boldsymbol { \mathsf { e } } _ { 1 }$ 很小，将QPC电流按正弦波近似展开，有：

$$
\begin{array} { r l } & { \mathrm { I } _ { \mathbb { Q P C } } = \mathrm { I } _ { \mathbb { Q P C } } ( \mathsf { V } _ { \mathsf { d } } + \mathsf { V } \sin ( \omega \mathsf { t } + \Phi ) ) } \\ & { \qquad \approx \mathrm { I } _ { \mathbb { Q P C } } ( \mathsf { V } _ { \bar { \mathsf { d } } } ) + \frac { \mathrm { d } \mathrm { I } _ { \mathbb { Q P C } } } { \mathrm { d } \mathsf { V } _ { \bar { \mathsf { d } } } } \mathsf { V } \sin ( \omega \mathsf { t } + \Phi ) + \cdots } \end{array}\tag{2.3}
$$

锁相放大器只测量和激励信号同频的输入信号部分，所以实际测得的信号就是 $\frac { \mathop { } \mathrm { d } \mathrm { I } _ { \mathrm { Q P C } } } { \mathop { } \mathrm { d } \mathrm { V } _ { \mathrm { d } } } \mathrm { V } _ { \circ }$ 这里的巧妙之处在于测量信号正比于 $\mathrm { d I _ { Q P C } / d V _ { d } }$ ，相当于直接在物理上实现对信号 $\boldsymbol { \mathrm { I } } _ { \boldsymbol { Q } \boldsymbol { P } \boldsymbol { C } }$ 的微分！如图2.16(c)所示，由于微分信号克服了QPC本底信号的干扰，突出了量子点信号随电极电压变化，所以这种测量方法的灵敏度是最高，可以在量子点电子隧穿率很低，量子点和QPC耦合较弱，采用前两种方法都不能探测信号的情况下，依然精确地确定量子点中电子数目发生变化的电压位置，得到量子点相图。因此我们在实验中调整量子点的位置和在少电子区进行测量时都主要采用这种方法。但这种方法中的 $\mathrm { d } \mathrm { I } _ { \mathrm { Q P C } } / \mathrm { d } \mathrm { V } _ { \mathrm { d } }$ 微分关系只是近似成立的，由此并不能给出电流信号绝对强度大小，只是对电子的跳跃敏感，因此也叫做 charge counting技术。对于参数拟合提取时需要用到信号的绝度变化量的实验，如测量双量子点耦合强度等，必须换用QPC输运信号测量方式甚至直接测量量子点输运信号。

\mathbf { q } ( \mathbf { t } ) = \mathbf { q } _ { 0 } \exp { ( \mathbf { j } ( \pmb { w } _ { 0 } + \mathbf { j } \kappa ) \mathbf { t } + \Phi ) }\tag{3.2}
$$

这是一个随时间周期性振荡的解，说明电路中存在本征的电荷振荡模式，振荡频率为 $\omega _ { 0 } = 1 / \sqrt { \mathrm { L C } }$ ，衰减速率为 $\kappa = 1 / \kappa C$

频域 并联LCR 谐振器的复输入阻抗为：

$$
Z _ { \mathrm { L C R } } ( \omega ) = \left( \mathrm { j } \omega \mathsf { C } + \frac { 1 } { \mathrm { j } \omega \mathsf { L } } + \frac { 1 } { \mathsf { R } } \right) ^ { - 1 }\tag{3.3}
$$

当复阻抗的虚部为0时，电路对外不会表现出容性或者抗性，不会存储释放能量，发生谐振。此时亦可得到谐振频率为 $\omega _ { 0 } = 1 / \sqrt { \mathrm { L C } }$

## 3.1.2 传输线谐振电路

随着谐振频率的升高，电磁振荡的波长越来越小。在微波频段，波长只有1m到1mm之间。这已经和常见的集总元件的尺度差不多了。由于微波干涉效应的影响，电路元件的工作状态显著依赖于其尺寸结构，因此必须使用分布式模型来描述整个电路。传输线理论是最常用的分布式电路模型[48]。考虑一段长度为l，特征阻抗 $\scriptstyle { Z _ { 0 } }$ ，传播常数为 $\beta$ 和衰减常数为α的低耗传输线，其终端接有负载阻抗 $z _ { \mathrm { L } }$ 。在距离负载处的输入阻抗 $z _ { i \mathfrak { n } }$ 为：

$$
Z _ { \mathrm { i n } } = Z _ { 0 } \frac { Z _ { \mathrm { L } } + Z _ { 0 } \operatorname { t a n h } ( ( \alpha + \mathrm { j } \beta ) \mathbb { 1 } ) } { Z _ { 0 } + Z _ { \mathrm { L } } \operatorname { t a n h } ( ( \alpha + \mathrm { j } \beta ) \mathbb { 1 } ) }\tag{3.13}
$$

我们考虑几种特殊的情况。

1. 终端为开路，长度1为半波长的整数倍。此时 $Z _ { \mathrm { L } }  \infty$ ，输入阻抗化为

$$
Z _ { \mathrm { i n } } = Z _ { 0 } \coth ( \alpha + \mathrm { j } \beta ) \mathbb { l } = Z _ { 0 } { \frac { \mathbb { 1 } + \mathrm { j } \tan \beta \mathbb { l } \operatorname { t a n h } \alpha \mathbb { l } } { \operatorname { t a n h } \alpha \mathbb { l } + \mathrm { j } \tan \beta \mathbb { l } } }\tag{3.14}
$$

假设在微波频率 ${ \pmb w } = { \pmb w } _ { 0 }$ 时，传输线的长度恰好为半波长 $\lfloor = \lambda / 2$ 。我们在$\omega _ { 0 }$ 处展开，有 ${ \pmb w } = { \pmb w } _ { 0 } + \Delta { \pmb w }$ , tanh αl ≈ αl,

$$
\tan \beta \mathrm { l } = \tan ( \pi + \frac { \pi \Delta \omega } { \omega _ { 0 } } ) \approx \frac { \Delta \omega } { \omega _ { 0 } }\tag{3.15}
$$

将这些结果带入式3.14，可得：

$$
Z _ { \mathrm { i n } } = \frac { Z _ { 0 } } { \alpha \mathbf { l } + \mathbf { j } ( \Delta \omega \pi / \omega _ { 0 } ) }\tag{3.16}
$$

上式与并联RLC谐振电路的输入阻抗3.10形式完全一致，说明开路半波长传输线就相当于一个并联谐振电路，各等效参数如下

$$
\begin{array} { c } { { \mathsf { R } = \displaystyle \frac { \mathsf { Z } _ { 0 } } { \alpha \mathsf { L } } } } \\ { { \mathsf { C } = \displaystyle \frac { \pi } { 2 w _ { 0 } \mathsf { Z } _ { 0 } } } } \\ { { \mathsf { L } = \displaystyle \frac { 1 } { w _ { 0 } ^ { 2 } \mathsf { C } } } } \\ { { \mathsf { Q } = \omega _ { 0 } \mathsf { R C } = \displaystyle \frac { \pi } { 2 \alpha \mathsf { L } } = \displaystyle \frac { \mathsf { \beta } } { 2 \alpha } } } \end{array}
$$

2. 负载为短路，长度为半波长的整数倍。此时 ${ \cal Z } _ { \mathrm { L } } \to 0$ ，输入阻抗化为

$$
Z _ { \mathrm { i n } } = Z _ { 0 } \frac { \operatorname { t a n h } \alpha \mathrm { l } + \mathrm { j } \tan \beta \mathrm { l } } { 1 + \mathrm { j } \tan \beta \mathrm { l } \operatorname { t a n h } \alpha \mathrm { l } }\tag{3.17}
$$

同样在 $\omega = \omega _ { 0 }$ $\updownarrow = \lambda / 2$ 处展开，我们可以得到：

$$
Z _ { \mathrm { i n } } \approx Z _ { 0 } \frac { \alpha \mathrm { l } + \mathrm { j } ( \Delta \omega \pi / \omega _ { 0 } ) } { 1 + \mathrm { j } ( \Delta \omega \pi / \omega _ { 0 } ) \alpha \mathrm { l } } \approx Z _ { 0 } ( \alpha \mathrm { l } + \mathrm { j } \frac { \Delta \omega \pi } { \omega _ { 0 } } )\tag{3.18}
$$

上式与串联RLC谐振电路的输入阻抗3.12形式完全一致，说明开路半波长传输线就相当于一个串联联谐振电路，各等效参数如下

$$
\begin{array} { c } { { \tt R = Z _ { 0 } \alpha { \alpha } { 1 } } } \\ { { { \tt L } = \displaystyle \frac { Z _ { 0 } \pi } { 2 \omega _ { 0 } } } } \\ { { { \tt C } = \displaystyle \frac { 1 } { \omega _ { 0 } ^ { 2 } \mathrm { L } } } } \\ { { { \tt Q } = \displaystyle \frac { w _ { 0 } \mathrm { L } } { \mathrm { R } } = \displaystyle \frac { \pi } { 2 \alpha { 1 } } = \displaystyle \frac { \beta } { 2 \alpha } } } \end{array}
$$

3. 负载为短路，长度为四分之一波长的奇数倍。此时 $\pmb { Z } _ { \mathrm { L } }  0$ ，输入阻抗化为

$$
Z _ { \mathrm { i n } } = Z _ { 0 } \frac { 1 - \mathrm { j } \tan \beta \mathrm { l } \operatorname { t a n h } \alpha \mathrm { l } } { \operatorname { t a n h } \alpha \mathrm { l } - \mathrm { j } \tan \beta \mathrm { l } }\tag{3.19}
$$

假设在微波频率 $\omega = \omega _ { 0 }$ 时，传输线的长度恰好为四分之一波长 $\nu = \lambda / 4$ 我们在 $\omega$ 处展开，有 $\omega = \omega _ { 0 } + \Delta \omega$ , tanh αl ≈ αl,

$$
\cot \beta \mathbb { l } = \cot ( \frac { \pi } { 2 } + \frac { \pi \Delta \omega } { 2 \omega _ { 0 } } ) \approx - \frac { \pi \Delta \omega } { 2 \omega _ { 0 } }\tag{3.20}
$$

将这些结果带入式3.19，可得

$$
Z _ { \mathrm { i n } } = Z _ { 0 } \frac { 1 + \mathrm { i } \alpha \mathrm { l } \pi \Delta \omega / 2 \omega _ { 0 } } { \mathrm { a l } + \mathrm { j } \pi \Delta \omega / 2 \omega _ { 0 } } \approx \frac { Z _ { 0 } } { \alpha \mathrm { l } + \mathrm { j } \pi \Delta \omega / 2 \omega _ { 0 } }\tag{3.21}
$$

上式与并联RLC谐振电路的输入阻抗形式3.10完全一致，说明短路四分之一波长传输线就相当于一个并联谐振电路，各等效参数如下

$$
\begin{array} { c } { { \ R = { \displaystyle \frac { { \cal Z } _ { 0 } } { \alpha \mathrm { l } } } } } \\ { { { \displaystyle \mathbb { C } = { \displaystyle \frac { \pi } { 4 \omega _ { 0 } { \cal Z } _ { 0 } } } } } } \\ { { { \displaystyle \mathrm { L } = { \displaystyle \frac { 1 } { \omega _ { 0 } ^ { 2 } \mathbb { C } } } } } } \\ { { { \displaystyle \mathrm { Q } = w _ { 0 } \mathbb { R } \mathbb { C } = { \displaystyle \frac { \pi } { 4 \alpha \mathrm { l } } } = { \displaystyle \frac { \beta } { 2 \alpha } } } } } \end{array}
$$

从上面三种情况的讨论可以看出，在微波频段，虽然没有直接等效的电容电感元件，整个电路都是分布式的，但对于传输线结构，只要终端负载为开路或短路，并且长度合适，都可以等效为一个谐振腔。这为我们制作微波谐振腔提供了极大的方便。

## 3.1.3 有载和无载 Q

前面定义的品质因子Q是假设谐振电路没有耦合外部电路，不存在负载效应，称为无载Q（内部品质因子)，它描述的是谐振电路本身的性质。但实际上谐振电路总需要与外部耦合，这通常会使总的 $\mathbf { Q }$ 值下降，此时的品质因子值称为有载 $\mathbf { Q } \cdot$ ，考虑如图所示最简单的耦合情况，并联谐振电路直接与外负载 $\ R _ { \ L }$ 相连接，总体有效的电阻为 $R R _ { \mathrm { L } } / ( R + R _ { \mathrm { L } } )$ 。如果我们定义类比于内部品质因子，定义外部品质因子 $\mathsf Q _ { e } = \mathsf R _ { \mathrm { L } } / w _ { 0 } \mathsf L$ ，则可得有载品质因子满足

$$
\frac { 1 } { \mathsf { Q } _ { \mathrm { { L } } } } = \frac { 1 } { \mathsf { Q } _ { \mathrm { { i } } } } + \frac { 1 } { \mathsf { Q } _ { e } }\tag{3.22}
$$

这个式子对于各种负载情况具有普适性。定义耦合系数为：

$$
g = \frac { \mathrm { Q _ { i } } } { \mathrm { Q _ { e } } }\tag{3.23}
$$

它描述了谐振电路与外界功率传输是否匹配。通产 ${ \mathfrak { g } } > { \mathfrak { l } }$ 称为过耦合， ${ \mathfrak { g } } < 1$ 称为欠耦合， $g = 1$ 称为临界耦合。

对于谐振腔和量子点的耦合体系，谐振腔过耦合意味着总的品质因子很低，谐振腔适于用作量子比特的快速读取。而谐振腔欠耦合意味着总的品质因子很高，光子可以在谐振腔中很长时间不泄露，谐振腔适用于做一个量子存储器件。

## 3.1.4 量子化描述

我们可以使用简谐振子模型来量子化地描述谐振电路[49]。如果不考虑电阻 R 的损耗，一个LC 振荡电路的总能量为：

$$
\mathsf { E } = \frac { 1 } { 2 } \mathsf { L I } ^ { 2 } + \frac { 1 } { 2 } \mathsf { C } \mathsf { V } ^ { 2 }\tag{3.24}
$$

因此相应的哈密顿量为：

$$
{ \sf H } = \frac { { \sf q } ^ { 2 } } { 2 { \sf C } } + \frac { \delta ^ { 2 } } { 2 \mathrm { L } }\tag{3.25}
$$

![](images/89206e3476e92744296fc7f068b9ea6bb4671e6f9b366ee328d4ad02c4a6d705.jpg)  
图 3.4 共面波导结构示意图 [49]

其中q为电容中的电量，δ=LI为电感中的磁通量。和弹簧机械振子类似，我们可以直接定义正则算符 q和 δ:

$$
{ \frac { \partial \mathsf { H } } { \partial \mathsf { q } } } = { \frac { \mathsf { q } } { \mathsf { C } } } = - \mathsf { L } { \frac { \partial \mathsf { I } } { \partial \mathsf { t } } } = - \dot { \delta }\tag{3.26}
$$

$$
\frac { \partial \mathsf { H } } { \partial \delta } = \frac { \delta } { \mathsf { L } } = \mathsf { I } = \dot { \mathsf { q } }\tag{3.27}
$$

且满足对易关系 $[ \hat { \mathsf { q } } , \hat { \boldsymbol { \delta } } ] = - \mathrm { i } \hbar$ 更进一步，式3.25还可以二次量子化为

$$
\mathsf { H } = \hbar \boldsymbol { \omega } \big ( \mathbf { a } ^ { \dagger } \mathbf { a } + 1 / 2 \big )\tag{3.28}
$$

即谐振腔可以直接用单模光场的产生湮灭算符表示。光子湮灭算符满足：

$$
\mathfrak { a } = \frac { 1 } { \sqrt { 2 \hbar L _ { \mathrm { c } } } } ( \delta + \mathrm { j } Z _ { \mathrm { c } } \mathfrak { q } )\tag{3.29}
$$

其中谐振频率 $\omega = 1 / \sqrt { \mathsf { L C } }$ ，特征阻抗 $Z _ { \mathrm { c } } = \sqrt { \mathrm { L } / \mathrm { C } }$ 。对于微波电路，特征阻抗通常为50Ω。

## 3.2.1.1 传输线实现

从上一节的讨论可以看出，只要找到低损传输线的物理实现，并截取合适的长度，就可以制作出谐振腔结构了。实验中最早实现的平面超导谐振腔采用了共面波导（CPW）结构作为传输线的实现。CPW的结构如图3.4所示，在介质基片的平面上制作出中心导体带，并在紧邻中心导体带的两侧制作出导地平面，就构成了共面波导。共面波导的性质主要由以下几个参数控制：中心导带线宽度a，中心和地平面间距b，介质基底的厚度h和介电常数e。对于具体的传输线结构，我们最关心的是如何设计参数使得特征阻抗满足50欧姆匹配。共面波导的特征阻抗的理论表达式如下[49]:

$$
Z _ { 0 } ^ { C P W } = \frac { 6 0 \pi } { \sqrt { \varepsilon _ { e f f } } } \bigg ( \frac { \mathsf { K } ( \mathsf { k } ) } { \mathsf { K } ( \mathsf { k } ^ { \prime } ) } + \frac { \mathsf { K } ( \mathsf { k } _ { 3 } ) } { \mathsf { K } ( \mathsf { k } _ { 3 } { ' } ) } \bigg ) ^ { - 1 }\tag{3.30}
$$

其中有效介电常数：

$$
\varepsilon _ { e f f } = \frac { 1 + \varepsilon _ { \tau } \tilde { \mathsf { K } } } { 1 + \tilde { \mathsf { K } } }\tag{3.31}
$$

K为第一类椭圆积分，

$$
\tilde { \mathsf { K } } = \frac { \mathsf { K } ( \mathsf { k } ^ { \prime } ) \mathsf { K } ( \mathsf { k } _ { 3 } ) } { \mathsf { K } ( \mathsf { k } ) \mathsf { K } ( \mathsf { k } _ { 3 } { ' } ) }
$$

$$
{ \bf k } _ { 3 } = \frac { \operatorname { t a n h } ( \frac { \pi \alpha } { 4 \mathrm { h } } ) } { \operatorname { t a n h } ( \frac { \pi \mathrm { b } } { 4 \mathrm { h } } ) }
$$

$$
\pmb { \mathrm { k } } ^ { \prime } = \sqrt { 1 - \pmb { \mathrm { k } } ^ { 2 } }
$$

$$
{ \bf k } _ { 3 } ^ { \prime } = \sqrt { 1 - { \bf k } _ { 3 } ^ { 2 } }
$$

显然CPW阻抗的函数关系非常复杂，受到多参数调节控制。但正是这种参数调节的复杂性，为我们的设计带来了很大的便利性。实际上在介质介电常数一定的情况下，CPW的阻抗主要和几何参数之间的比例 ${ \mathfrak { a } } / { \mathfrak { b } }$ ${ \mathfrak { a } } / { \hbar }$ $b / h$ 有关，因此对于不同尺寸大小的设计要求，这要保持好参数值之间的比例关系，就都能保持阻抗匹配一致。在实际的实验中，从毫米量级的PCB板到微米量级的谐振腔样品，尽管基板的厚度和介电常数各部相同，我们都可以在数值合理的范围内计算出a和b以满足50欧姆阻抗匹配要求。当然在实际使用中，我们不需要去计算如此复杂的公式，而是使用电磁模拟软件来设计具体的参数值。

CPW结构作为最早在实验中采用的平面传输线结构，除了设计参数可调性高的特点外，还具有以下优点：

1. 能量密度高。由于地平面离中心导带线很近并且在同一平面内，所以电场分布相对集中，真空电场强度大，能量泄漏少，可以很容易实现很高的内部Q值，非常有利于实现强耦合。

2. 高频设计。可以很容易将传输频率做到10GHz以上

## 3.2.1.2 谐振腔设计

有了CPW传输线结构，我们只要截取合适的长度就可实现谐振腔了。通常我们采用半波长终端开路的设计。谐振腔有两个主要的参数，谐振频率和Q值。谐振频率是直接由中心导带线的长度决定的， $w = \pi v _ { e f f } / 1 = \pi c / 1 \sqrt { \varepsilon _ { e f f } }$ 。外部品质因子有谐振腔和外界耦合程度所决定。为了保持开路状态，中心导带线是通过电容的形式与外界馈线耦合在一起的。电容通常采用直接的缝隙或交趾的结构，缝隙的间距和重叠程度决定了耦合电容的大小，进而影响品质因子。在谐振腔的两侧都与外界耦合，这样微波可以从一端进入另一端输出，测量谐振腔的透射频谱。这样的谐振腔结构被称作透射式传输线谐振腔（TLR）。

$$
Z \approx \frac { { \sf R } } { 1 + 2 \mathrm { j } { \sf R C } ( \omega - \omega _ { 0 } ) }\tag{3.32}
$$

无载品质因子为 $Q _ { \mathrm { i } } = \omega _ { 0 } \mathsf { R C }$ 。为了得到整个电路的有载品质因子，我们可以用诺顿变换将两侧串联的电容电阻变为并联结构并入到整个谐振电路中。假设输入输出耦合电容是对称的，有

$$
\mathsf { R } ^ { * } = \frac { 1 + \omega _ { 0 } ^ { 2 } \mathsf C _ { \mathsf { k } } ^ { 2 } \mathsf R _ { \mathrm { L } } ^ { 2 } } { w _ { 0 } ^ { 2 } \mathsf C _ { \mathsf { k } } ^ { 2 } \mathsf R _ { \mathrm { L } } }\tag{3.33}

通常耦合电容 ${ { \mathbb { C } } _ { \bf { k } } }$ 很小， $\mathfrak { q } = w _ { 0 } \mathbb { C } _ { \mathtt { k } } \mathbb { R } _ { \mathtt { L } } \ll 1$ ，变换后 $\mathbb { R } ^ { * } \approx \mathbb { R } _ { \mathrm { L } } / \mathbb { q } ^ { 2 }$ 很大，而 $C ^ { * } \approx C _ { \boldsymbol { \mathbf { k } } }$ 很小。变换后，谐振频率基本不变 $w ^ { \star } = 1 / \sqrt { \mathrm { L } ( \mathsf { C } + 2 \mathsf { C } ^ { \star } ) } \approx 1 / \sqrt { \mathrm { L C } } = w _ { 0 }$ ，总的有载品质因子为：

$$

其中：

$$
\mathsf Q _ { \mathsf Q } = w _ { 0 } \mathsf R C = \frac { \pi } { 2 \alpha \mathsf l }\tag{3.37}
$$

$$

$$

\left( \begin{array} { l l } { \mathsf { A } } & { \mathsf { B } } \\ { \mathsf { C } } & { \mathsf { D } } \end{array} \right) = \left( \begin{array} { l l } { \mathsf { A } } & { \mathsf { B } } \\ { \mathsf { C } } & { \mathsf { D } } \end{array} \right) _ { \mathsf { C } _ { \mathsf { i n } } } \left( \begin{array} { l l } { \mathsf { A } } & { \mathsf { B } } \\ { \mathsf { C } } & { \mathsf { D } } \end{array} \right) _ { \mathsf { T L } } \left( \begin{array} { l l } { \mathsf { A } } & { \mathsf { B } } \\ { \mathsf { C } } & { \mathsf { D } } \end{array} \right) _ { \mathsf { C } _ { \mathsf { o u t } } }\tag{3.41}

\begin{array} { c } { \displaystyle \mathsf { S } _ { 2 1 } = \frac { 2 } { \boldsymbol { \mathsf { A } } + \boldsymbol { \mathsf { B } } / \mathsf { R } _ { \mathrm { L } } + \boldsymbol { \mathsf { C } } \mathsf { R } _ { \mathrm { L } } + \boldsymbol { \mathsf { D } } } } \\ { \displaystyle \approx \frac { \mathsf { T } _ { 0 } } { 1 + \mathsf { j } \frac { \omega - \omega _ { 0 } } { ( \kappa _ { \mathrm { i n } } + \kappa _ { \mathrm { o u t } } ) / 2 } } } \end{array}\tag{3.42}

$$

$$

$$

## 3.2.2 制作加工

前面的理论给出了我们计算谐振腔参数的方法。在实际操作中，我们在得到参数的初步估计后，会在电磁仿真软件中画出模型进行模拟，并调整优化参数以达到最优效果。图3.9是使用HFSS软件模拟的透射式谐振腔。可以看到在谐振时，两端开路处电场强度最大，与我们的预期相符。

按上述设计订做掩膜，使用光刻技术来制作样品，最后镀铝来就可以完成透射式谐振腔的制作。在制作过程中要注意以下几点：

1. 介质基片的选择。介电损耗是透射式谐振腔最主要的能量损耗来源。因此一定要选择电阻率大的基片制作样品。高Q值的谐振腔都是在本征非掺杂硅片或蓝宝石基片上制作的。若要使用掺杂型硅片，一定要使用轻度掺杂的，并且最好在基片表面生长一层SiO2绝缘层。对于掺杂型GaAs基片，在制作谐振腔的区域一定要刻蚀掉二维电子气。

2. 光刻精度。保证金属平滑整齐，电磁损耗小，无载品质因子高。所以在紫外曝光显影时一定要使光刻胶边缘平整，尤其是较窄的中心线末端，不要有明显的畸变。

3. 蒸镀金属要干净。当蒸镀A1时要保证腔体干净，避免有其他金属的污染。

## 3.2.3 测量表征

平面谐振腔在室温下导体损耗很大，不能形成谐振，必须将其置于低温下，金属处于超导状态时，才能观察到谐振信号。原装的稀释制冷机上并没有提供相应的微波测量条件，必须对其进行改装。透射式谐振腔典型的测量路线如图3.10所示

对稀释制冷机中测量线路的改造主要包括两个部分，输入部分的滤波和输出部分的放大。最终输入到样品上的微波信号功率通常只有-110dBm以下（纳瓦量级)，这比高温时热噪声的信号还要弱。因此为了避免噪声的影响，必须将高温热噪声信号滤掉，即微波信号也要做到良好的“热沉”。热噪声是宽频带的，所以最直接的做法就是在每个温度层都加一个宽频的衰减器，将这一层的热噪声直接衰减掉。当然这样也会衰减输入信号，但最初输入的信号可以比较强，经过层层衰减，最终达到样品上的功率满足要求即可。在每一温度层滤波时，输入信号都是强于热噪声信号的。

输出线路的要求则恰好相反，要将有效的信号迅速放大到强于热噪声信号。由于热功率的限制，微波放大器最低只能安装到4K温度层。为了防止放大器的噪声对样品进行反向干扰，需要在样品和放大器之间加装一个单向导通的环形器。从样品到放大器的信号可以正常通过，反向的信号则被大大衰减（20dB以上)。通常在室温时还会在加装一级放大器以便于测量。室温放大器只是增加了微波信号的绝对强度，信噪比还是有第一级的4K温层的放大器所决定的。

![](images/03b6cae28f15967cad3e13807c4c331da2c62a7f1552988f4fb8a3aa428cdd08.jpg)  
图3.11 网络分析仪测得的透射式谐振腔振幅和相位的频谱

单纯的谐振腔比较简单，是一个标准的二端口器件，因此直接使用网络分析仪就可测量。图3.11显示了铝透射式谐振腔处于稀释制冷机base温度时的振幅和相位的频谱，与理论完全吻合。从中可以提取出谐振频率和品质因子。

超导谐振腔在极低温时才能达到最佳的工作状态，品质因子最高。随着温度的升高，超导性被破坏，金属电阻增大，谐振腔导体损耗增大，品质因子逐渐降低。当温度超过超导临界温度，谐振信号会因为电阻损耗太大而完全被破坏。因此做变温实验，观察谐振腔品质因子随温度的变化关系，是鉴别透射频谱S21中的尖峰是否是谐振腔信号的重要方法。

## 3.3.1 传输线实现

耦合微带线是另一种传输线实现。如图3.12所示，在介质基片上制作出两条相互平行的金属导带线，就构成了耦合微带线。耦合微带线的参数由以下几个参数控制：导带线的宽度w，线间距s，介质基底的厚度h和介电常数ε。实际上，耦合微带线和共面波导的金属平面是互补的，二者是对偶结构。

耦合微带线的电特性完全可以用等效电容来刻画[48]。如图3.12所示，设两个导体之间的电容为 ${ \sf C } _ { 1 2 }$ ，每个导体与地之间的电容为 $\mathsf { C } _ { 1 1 }$ 和 $C _ { 2 2 }$ 。采用奇偶模分析法来研究耦合微带线的特征阻抗。对于偶模激励，在两个导体带上的电流幅值相等，方向相同，此时电力线的分布如图3.13(a)所示。电场关于中心线偶对称，两根导体之间没有电流流过。因此等效电容网络中的 ${ \mathsf { C } } _ { 1 2 }$ 相当于开路。每根线到地的电容为

$$
{ \mathsf C } _ { e } = { \mathsf C } _ { 1 1 } = { \mathsf C } _ { 2 2 }\tag{3.45}
$$

偶模的特征阻抗为：

$$
Z _ { 0 } ^ { e } = \sqrt { \frac { \mathrm { \Delta } L } { \mathrm { \Delta } C _ { e } } }\tag{3.46}
$$

## 3.3.2 谐振腔分析

取耦合微带线的长度为设计频率波长的一半，并将微带线两端都开路，就可得到半波长开路谐振腔。通常采用缝隙将谐振腔耦合到外界电路，缝隙可近似为一个串联电容，总的等效电路如图3.14所示[48]。归一化输入阻抗为：

$$
z = \frac { Z } { Z _ { 0 } } = - \mathrm { j } \frac { 1 / \omega C + Z _ { 0 } \cot \beta \mathrm { l } } { Z _ { 0 } } = - \mathrm { j } \frac { \tan \beta \mathrm { l } + \mathrm { b } _ { c } } { \mathrm { b } _ { c } \tan \beta \mathrm { l } }\tag{3.49}
$$

其中 ${ \tt b } _ { \tt c } = Z _ { 0 } \omega { \tt C }$ 为耦合电容C的归一化电纳。在发生谐振时， $z = 0 ,$ 有

$$
\tan { \beta } \mathbf { l } + \mathbf { b } _ { c } = 0\tag{3.50}
$$

由于 ${ \sf b } _ { \sf c } \ll 1$ ，可以将 $z ( \omega )$ 在基模谐振频率 ${ \mathfrak { \beta } } { \mathfrak { l } } = \pi$ 处的谐振频率 $\omega _ { 1 }$ 展开，有

$$
\left. { \frac { \mathrm { d } z } { \mathrm { d } \omega } } \right| _ { w _ { 1 } } = { \frac { - \mathrm { j } \sec ^ { 2 } \beta \mathsf { l } } { \mathsf { b } _ { c } \tan \beta \mathsf { l } } } { \frac { \mathrm { d } ( \beta \mathsf { l } ) } { \mathrm { d } w } } = { \frac { \mathrm { j } ( 1 + \mathsf { b } _ { \mathrm { c } } ^ { 2 } ) } { \mathsf { b } _ { c } ^ { 2 } } } { \frac { 1 } { v _ { \mathsf { p } } } } \approx { \frac { \mathrm { j } } { \mathsf { b } _ { c } ^ { 2 } } } { \frac { 1 } { v _ { \mathsf { p } } } } \approx { \frac { \mathrm { j } \pi } { w _ { 1 } \mathsf { b } _ { c } ^ { 2 } } }\tag{3.51}
$$

所以归一化阻抗可展开为：

$$
z ( \omega ) \approx z ( \omega _ { 1 } ) + ( \omega - \omega _ { 1 } ) \frac { \mathrm { d } z ( \omega ) } { \mathrm { d } \omega } \bigg | _ { \omega _ { 1 } } = \frac { \mathrm { j } \pi ( \omega - \omega _ { 1 } ) } { \omega _ { 1 } \mathsf { b } _ { \mathrm { c } } ^ { 2 } }\tag{3.52}
$$

![](images/c70bd6020538f3f9681ef47f87f96db994e1625b806a69ded75050a56019fea8.jpg)

对于有损耗的情况，用复谐振频率 $\omega _ { 1 } / ( 1 + \mathrm { j } / 2 0 )$ 替换掉谐振频率 $\omega _ { 1 }$ ，可得缝隙耦合有耗谐振腔的输入阻抗可以表示为：

$$
z ( w ) = \frac { \pi } { 2 \mathrm { Q b } _ { \mathrm { c } } ^ { 2 } } + \mathrm { j } \frac { \pi ( \omega - \omega _ { 1 } ) } { \omega _ { 1 } \mathbf { b } _ { \mathrm { c } } ^ { 2 } }\tag{3.53}
$$

可以注意到，无耦合的半波长开路传输线谐振器相当于一个并联的集总LC谐振电路，但经过缝隙电容耦合后，则是相当于一个串联的集总LC谐振电路。这是因为串联耦合电容有阻抗倒相器的作用。此处使用的品质因子 $\mathbf { Q }$ 为内部品质因子。

在谐振时输入电阻 $\mathtt { R } = Z _ { 0 } z ( \omega ) = Z _ { 0 } \pi / 2 \mathrm { Q } _ { \mathrm { i } } \mathfrak { b } _ { \mathtt { c } } ^ { 2 }$ ，可得耦合系数

$$
{ \mathfrak { g } } = { \frac { \mathrm { Q } _ { \mathrm { i } } } { \mathrm { Q } _ { \mathrm { e } } } } { = } { \frac { \mathrm { Z } _ { 0 } } { \mathrm { R } } } = { \frac { 2 \mathrm { Q } _ { \mathrm { i } } \mathrm { b } _ { \mathrm { c } } ^ { 2 } } { \pi } }\tag{3.54}
$$

将上式带入式3.52，可得：

$$
z ( \omega ) = \frac { 1 } { g } ( 1 + \mathrm { j } 2 \mathbb { Q } _ { \mathrm { i } } \frac { \Delta w } { \omega _ { 1 } } )\tag{3.55}
$$

所以缝隙耦合有耗谐振腔的反射谱为：

$$
\mathsf { S } _ { 1 1 } = \frac { z ( \omega ) - 1 } { z ( \omega ) + 1 } = \frac { 1 - \mathsf { g } + \mathsf { j } 2 \mathsf { Q } _ { \mathrm { i } } \frac { \Delta \omega } { \omega _ { 1 } } } { 1 + \mathsf { g } + \mathsf { j } 2 \mathsf { Q } _ { \mathrm { i } } \frac { \Delta \omega } { \omega _ { 1 } } }\tag{3.56}

$$
\mathsf { S } = \left( \begin{array} { c c c c } { 0 } & { \frac { \sqrt { 1 - c ^ { 2 } } } { \sqrt { 1 - c ^ { 2 } } \cos \beta 1 + \mathrm { j } \sin \beta \mathrm { l } } } & { \frac { \mathrm { j } \cot \beta 1 } { \sqrt { 1 - c ^ { 2 } } + \mathrm { j } \tan \beta \mathrm { l } } } & { 0 } \\ { \frac { \sqrt { 1 - c ^ { 2 } } } { \sqrt { 1 - c ^ { 2 } } \cos \beta 1 + \mathrm { j } \sin \beta \mathrm { l } } } & { 0 } & { 0 } & { \frac { \mathrm { j } \cot \beta 1 } { \sqrt { 1 - c ^ { 2 } + \mathrm { j } \sin \beta \mathrm { l } } } } \\ { \frac { \mathrm { j } \tan \beta 1 } { \sqrt { 1 - c ^ { 2 } + \mathrm { j } \tan \beta \mathrm { l } } } } & { 0 } & { 0 } & { \frac { \sqrt { 1 - c ^ { 2 } } } { \sqrt { 1 - c ^ { 2 } } \cos \beta 1 + \mathrm { j } \sin \beta \mathrm { l } } } \\ { 0 } & { \frac { \mathrm { j } \mathrm { c u n } \beta 1 } { \sqrt { 1 - c ^ { 2 } + \mathrm { j } \tan \beta \mathrm { l } } } } & { \frac { \sqrt { 1 - c ^ { 2 } } } { \sqrt { 1 - c ^ { 2 } \cos \beta \mathrm { l } + \mathrm { j } \sin \beta \mathrm { l } } } } & { 0 } \end{array} \right)\tag{3.57}
$$

## 3.3.3 制作加工

前面的理论给出了我们设计谐振腔的方法。在实际操作中，我们在得到参数的初步估计后，会在电磁仿真软件中画出模型进行模拟，并调整优化参数以达到最优效果。使用HFSS软件模拟反射式谐振腔，可以看到在谐振时，两端开路处电场强度最大，与我们的预期相符。

在模拟检查设计无误后，就可以按照设计订做掩膜，使用光刻技术来制作样品。具体的制作过程与反射式谐振腔类似，注意事项也一致。

## 3.3.4 测量表征

与透射式谐振腔类似，也必须在低温下金属处于超导状态时，才能观察到谐振信号。但由于测量的是反射信号，所以测量电路与透射式谐振腔有所不同，如图3.17所示。除了用作热沉的衰减器和增强信号的放大器外，测量电路中还有两个关键器件：环形器和180度混合环。180度混合环为自制的。当端口1接地后，在端口4施加的输入信号会在端口2和端口3等分成两个有180度相位差的分量，即形成差分信号。反之若输入信号在端口2和端口3，则在端口4会形成输入信号的差。因此180混合环提供了将同轴线上的单边信号和耦合线谐振腔需要的差分信号相互转化的作用。环形器是单向导通的3端口器件，微波输入信号从端口1到端口2进入样品，样品反射回来的信号从端口2到端口3进入接收线路。因此环形器实现了谐振腔输入信号和输出信号的分离。具体的测量实例详见第4章。

## 3.4 3D 谐振腔

## 3.4.1 设计模拟

除了采用微纳加工工艺制作直接在晶圆上制作的平面谐振腔外，国际上最新的研究中开始采用3D结构的金属谐振腔。与平面谐振腔相比，3D谐振腔有一下点优势：

1. 3D谐振腔体积很大，完全依靠宏观的机械加工技术即可制成，可在工厂中批量加工。

2. 3D谐振强采用全封闭结构，因此辐射能量损失极小，可以获得极高的品质因子，可以更好地屏蔽电磁噪声。

3. 3D谐振腔和晶片上的量子比特系统是独立设计的，当希望二者耦合时只需要将固态量子系统放入谐振腔中即可，这样每次实验只需更换样品，谐振腔可重复利用。

## 3.4.1.1 矩形波导

矩形波导可以看作3D谐振腔中使用的传输线实现。波导结构如图3.18所示，四面为金属导体，波导中填充有介电常数为ε和磁导率为μ的材料。由于波导是由单个导体组成的，所以只能传播仅出现纵向磁场分量的TE波，或仅出现纵

向电场分量的 TM波。限于篇幅，我们值考虑最简单的TE模[48]。在电磁波传播的z方向上，有 $\mathtt { E } _ { z } = 0$ ，而 $\mathsf { H } _ { z }$ 满足：

$$
\left( \frac { \partial ^ { 2 } } { \partial \mathbf { x } ^ { 2 } } + \frac { \partial ^ { 2 } } { \partial \mathbf { y } ^ { 2 } } + \mathbf { k } _ { c } ^ { 2 } \right) \mathbf { h } _ { z } ( \mathbf { x } , \mathbf { y } ) = 0\tag{3.59}
$$

其中 $\mathsf { H } _ { z } ( \boldsymbol { \mathsf { x } } , \boldsymbol { \mathsf { y } } , z ) = \mathsf { h } _ { z } ( \boldsymbol { \mathsf { x } } , \boldsymbol { \mathsf { y } } ) e ^ { - \mathrm { j } \beta z }$ $\boldsymbol { \mathsf { k } } _ { \mathsf { c } } ^ { 2 } = \boldsymbol { \mathsf { k } } ^ { 2 } - \boldsymbol { \mathsf { \beta } } ^ { 2 }$ 为截至波数。由此可解得 ${ \mathsf { T E } } _ { \mathtt { m n } }$ 模的各电磁场分量为：

$$
\begin{array} { l } { { \displaystyle { \mathsf { H } } _ { z } = \lambda _ { \mathsf { m n } } \cos \cos \frac { \mathsf { m } \pi \pi } { \mathsf { a } } \cos \frac { \mathsf { n } \pi \mathsf { n } } { \mathsf { b } } e ^ { - \mathrm { j } \mathrm { \mathsf { s } } z } } } \\  { \displaystyle { \mathsf { E } } _ { \mathrm { x } } = \frac { \mathrm { j } \omega \mathsf { k n } \pi } { \mathsf { k } _ { c } ^ { 2 } \mathrm { b } } \boldsymbol { A } _ { \mathsf { m n } } \cos \frac { \mathsf { m } \pi \kappa } { \mathsf { a } } \sin \frac { \mathsf { n } \pi \mathsf { n } } { \mathsf { b } } e ^ { - \mathrm { j } \mathrm { \mathsf { s } } z } } \\  { \displaystyle { \mathsf { E } } _ { \mathrm { y } } = \frac { - \mathrm { j } \mathsf { w l } \pi \pi } { \mathsf { k } _ { c } ^ { 2 } \mathrm { a } } \boldsymbol { A } _ { \mathsf { m n } } \sin \frac { \mathsf { m } \pi \kappa } { \mathsf { a } } \cos \frac { \mathsf { n } \pi \mathsf { n } } { \mathsf { b } } \mathrm { e } ^ { - \mathrm { j } \mathrm { \mathsf { s } } z } } \\  { \displaystyle { \mathsf { H } } _ { \mathrm { x } } = \frac { \mathrm { j } \mathrm { j } \mathsf { m } \pi } { \mathsf { k } _ { c } ^ { 2 } \mathrm { a } } \boldsymbol { A } _ { \mathsf { m n } } \sin \frac { \mathsf { m } \pi \kappa } { \mathsf { a } } \cos \frac { \mathsf { n } \pi \mathsf { n } } { \mathsf { b } } e ^ { - \mathrm { j } \mathrm { s } z } } \\  { \displaystyle { \mathsf { H } } _ { \mathrm { y } } = \frac { \mathrm { j } \mathrm { B } \pi } { \mathsf { k } _ { c } ^ { 2 } \mathrm { b } } \boldsymbol { A } _ { \mathsf { m n } } \cos \frac { \mathsf { m } \pi \kappa } { \mathsf { a } } \sin \frac { \mathsf { n } \pi \mathsf { n } } { \mathsf { b } } e ^ { - \mathrm { j } \mathrm { s } z } } \end{array}\tag{3.60}
$$

传播常数：

$$
\beta = \sqrt { \ k ^ { 2 } - \ k _ { \mathrm { c } } ^ { 2 } } = \sqrt { \ k ^ { 2 } - \displaystyle ( \frac { \ m \pi } { \alpha } ) ^ { 2 } - \displaystyle ( \frac { \ n \pi } { \mu } ) ^ { 2 } }\tag{3.61}
$$

在大多数应用中，通过选择工作频率和波导尺寸，使得只有基模 $T E _ { 1 0 }$ 可以传播。$T E _ { 1 0 }$ 的具体参数如下：

$$
\begin{array} { l } { { \displaystyle { \mathbb { H } } _ { z } = { \mathsf { A } } _ { 1 0 } \cos { \frac { \pi x } { \mathbf { a } } } e ^ { - \mathrm { i } \beta z } } } \\ { { \displaystyle { \mathbb { E } } _ { \mathbf { y } } = \frac { - \mathrm { j } w \mathrm { j } \mathbf { a } } { \pi } { \mathsf { A } } _ { 1 0 } \sin { \frac { \pi x } { \mathbf { a } } } e ^ { - \mathrm { j } \mathrm { \beta } z } } } \\ { { \displaystyle { \mathbb { H } } _ { \mathbf { x } } = \frac { \mathrm { j } \beta \mathbf { a } } { \pi } { \mathsf { A } } _ { 1 0 } \sin { \frac { \pi x } { \mathbf { a } } } e ^ { - \mathrm { j } \mathrm { \beta } z } } } \\ { { \displaystyle { \mathbb { E } } _ { \mathbf { x } } = { \mathsf { E } } _ { z } = { \mathsf { H } } _ { \mathbf { y } } = 0 } } \\ { { \displaystyle { \mathsf { \beta } } = \sqrt { \mathbf { k } ^ { 2 } - ( \pi / \mathbf { a } ) ^ { 2 } } } } \end{array}\tag{3.62}

## 3.4.2 模拟

根据以上理论，我们设计一个基模频率在9.5GHz附近的3D矩形谐振腔，并使用HFSS软件进行了模拟。如图3.21所示，对于基模谐振频率，波导传播方向为x方向，谐振电场方向垂直于yz平面。我们在平行于 $\mathbf { y } \mathbf { z }$ 平面的金属面上开了两个圆形小孔，作为谐振腔的输入输出，阻抗线方向为从圆形中心到其边缘。从透射谱 $S _ { 2 } 1$ 可以看出，在频率 $\mathsf { f } = 9 . 4 5 \mathsf { G } \mathsf { H } z$ 处确实能形成谐振，谐振处最大透射率较低，这是因为波导谐振腔是单导体结构，只能传播TE模或TM模，所以从TEM模的波端口向TE模的矩形谐振腔传播时会有一定的失配，能量传递效率低。

在进一步的实验中，我们希望能够实现3D谐振腔和量子点结构的耦合。但是量子点体系需要很多的控制门电极，需要有直流导线进出3D谐振腔。因此，除了上面讨论的全密封结构，我们还仔细研究了3D谐振腔壁上开洞，并考虑了引入直流引线的各种可能方案。我们使用HFSS软件，分别模拟了在3D谐振腔的侧壁和后壁上开槽的结构，如图3.22所示。从电磁场分布图可以看出，在平行与谐振电场方向的平面上开槽（如xz平面或xy平面)，并不会造成谐振腔能量的泄漏，对谐振状态的影响很小。

## 第四章 二维电子气对谐振腔调谐性质研究

前一章中我们介绍了微波谐振腔的基本知识和各种不同类型的谐振腔。可以注意到谐振腔的性质主要是由其结构决定的，一旦结构固定了，谐振腔的性质也就确定了。但在实际应用中，我们总是希望能够即时地对谐振腔的结构进行调整。本章中，我们将讨论一个利用二维电子气浓度的变化调谐谐振腔的实验。通过调节控制电极电压，我们可以将谐振腔的Q值在2700到600之间大范围的变动。我们认为这种直接通过电压调制谐振腔的技术有着广泛的应用前景。

## 4.1 实验动机

基于平面波导结构（CPW）实现的超导传输线谐振腔在 Circuit QED量子计算架构中扮演了重要的角色[51-54]。在超导约瑟夫森结量子比特方案中，它已经成功地被用于单量子比特控制[55,56]，非破坏性量子比特读取[57,58]，以及作为量子总线耦合多个量子比特[59-61]。传输线谐振腔与门控量子点[62-65]之间的耦合也被实现[66,67]。但是，门控量子点的结构较为复杂，需要多个门电极加以控制，这些门电极在几何上需要占据大量面积。但是透射式传输线谐振腔中心信号线两侧完全是由地平面覆盖的，为了将量子点与中心线耦合，控制电极会大面积地占据谐振腔地平面，破坏其完整性造成了额外的能量泄漏。因此在和量子点系统耦合的方案中，我们认为使用无地平面的谐振腔是比较理想的选择。

在本章中，我们将讨论一个在GaAs衬底上实现的反射式谐振腔的具体结构和性质。并且通过控制反射式谐振腔下方的二维电子气，我们实现了对谐振腔的大范围调谐。UCBerkeley的实验小组曾提出了四分之一波长的反射式谐振腔结构[68,69]，四分之一波长谐振腔需要在谐振腔的一端生长一层绝缘的氧化层，并在其上覆盖设计好尺寸的金属层以实现射频短路。我们实验中采用的是半波长谐振腔方案。相比于UC Berkeley的设计方案，我们采用的结构只需要蒸镀一层金属，无需额外的氧化层，所以易于制作加工。而且半波长谐振腔两端都采用开路设计，都可用于连接其他量子系统，可以实现将多个量子比特耦合在一起，扩展性更高。

我们使用网络分析仪测量了样品的反射频谱。样品被置于稀释制冷机中，base温度20mK。测量电路如图4.1(a)所示。这里用到的两个核心器件是环形器和180度混合环。环形器利用了晶体的不对称性制成，是一种单向导通的射频元件，微波信号在环形器的3个端口只能沿某方向单向循环传播，反方向则不行。由网络分析仪发出的输入微波信号经过环形器后进入样品，样品反射回来的信号则再次经过环形器后进入输出线路被HEMT放大。环形器在这里主要作用将微波输入信号和样品反射回来的信号隔离开来。反射信号通常较微波输入信号很弱，直接使用同一线路测量很容易收到干扰，而且反射信号被分开的可以用射频放大器HEMT进一步放大，提高了信号强度。但是HEMT放大器本底噪声温度约为4K，远高于样品所处温度，直接将二者连接起来会造成HEMT本底热噪声对样品的反向干扰。使用了环形器，就可以避免HEMT本身的噪声反向传输到样品。耦合微带线属于对称结构，在激励时要用振幅相等但方向相反的差分信号。180度混合环的作用是将单端的输入微波信号变为相位相差180度的差分信号，并将耦合微带线谐振腔反射回来的差分信号再合成单端信号。最终反射回来的信号还需要经过液氦温区增益为32dB的放大器和室温增益为35dB的放大器二级放大，才能有效地被网络分析仪接收到。为了避免引起加热效应和非线性效应，我们控制加在谐振腔样品上的微波功率在-110dBm以下。

## 4.3 结果讨论

最终我们测量到的反射谱如图4.2所示。和开路半波长谐振腔的理论预期一样，我们可以观察到在谐振位置反射频谱的振幅会有一个吸收峰，而相位会反生反转。使用公式

$$
\mathsf { S } _ { 2 1 } = \frac { 1 - 9 + \mathbf { j } \times 2 \mathsf { Q } _ { \mathrm { i n t } } \frac { \Delta \omega } { \omega _ { 0 } } } { 1 + 9 + \mathbf { j } \times 2 \mathsf { Q } _ { \mathrm { i n t } } \frac { \Delta \omega } { \omega _ { 0 } } }\tag{4.1}
$$

对数据进行拟合，我们可以得到样品的内部品质因子 $\mathrm { Q } _ { \mathrm { i n t } } \approx 2 7 2 5$ ，外部品质因子为 $\mathrm { Q _ { e x t } } \approx 4 8 4 7$ 。注意到对于反射式谐振腔，通过一次拟合就可以同时得到内部品质因子 $\mathbf { Q _ { i n t } }$ 和外部品质因子 $\sf { Q } _ { e x t }$ 。但在透射式谐振腔的实验中，需要多批不同耦合电容的样品进行比较，才能将二者确定下来[70]。

内部品质因子和外部品质因子分别描述了谐振腔内部和外接电路上的能量损耗。内部损耗是由样品本身的性质决定的，主要包括导体电阻损耗，辐射损耗和介电损耗三个因素。我们的样品由金属A1制成，在低温下已处于超导状态，所以导体电阻损耗是很小的。在我们的样品中，电磁场主要分布于耦合微带线的两臂之间，由于样品的结构尺寸很小，耦合微带线距离很近，所以辐射损耗也不是谐振腔能量泄漏的主要原因。因此，介电损耗才是影响内部品质因子的主要因素。这是而对于都是采用本征硅片或蓝宝石基片作为衬底的。

## 4.4 可调谐谐振腔

在base温度下，我们研究了透射式谐振腔的性质与控制电极电压的关系。当在控制电极电压VT的绝对值很大，无论是正向电压还是负电压，我们都可以观察到很好的谐振信号，而且信号几乎不随电极电压变化而变化。但是，在VT较小的区间（-1.7V到3.2V)，谐振信号的强弱明显受到控制电极电压的影响。特别是在-0.9到2.4V的区间，谐振信号变得很弱，完全探测不到了。

为此，在从不同的控制电极电压下，我们仔细地记录了谐振腔的频谱信号，并进行数据拟合提取了内部品质因子和外部品质因子。图4.3(c)显示了品质因子随电极电压变化的情况。我们可以看住，这幅图可大致被分为了三个区域：A稳定区、B可调谐区和C消失区。在稳定区，外部品质因子和内部品质因子都不随门电极电压变化而变化。在可调谐区，内部品质因子快速地从2700左右跌至600左右，而外部品质因子的变化与之相反，有些轻微的增加。在消失区，已经无法观察到谐振信号，所以也就无从提取品质因子了。

我们认为图4.3(c)所示的现象与mesa中二维电子气的存在有关。二维电子气层相当于一层导电层，它处在谐振腔下方百纳米处，距离远小于耦合微带线间距，所以会极大地增加谐振腔的介质损耗，导致微波能量被吸收，无法形成谐振。当控制电压VT是足够大的负电压时，谐振腔下方的二维电子气都已被排空，不会吸收微波信号对谐振腔的性质造成影响。所以此时可以观察到较强的谐振，而且内部和外部品质因子都不随控制电压变化而变化。当控制电压VT是足够大的正电压时，大量的电子被吸附上来，我们猜测此时GaAs异质结的导带基本被填满，二维电子气层也没有自由的电子可以吸收微波能量的光子，所以也形成了微波能量不发生损耗的稳定区。

当控制电压小到超过某个阈值时，GaAs异质结的导带处于半满状态，电子气浓度开始受到控制电压的调制。随着电压的变化，mesa中二维电子层的电阻率发生改变，相应的介质损耗也发生变化，由此引起谐振腔能量泄漏的变化，内部品质因子随之改变。外部品质因子主要由外部电路的性质所决定，因此在控制电压改变时变化不大。

图4.3(d)所示的数据有力的支持了我们的猜测。我们采用同样的GaAs晶圆，制作了一块带有顶部控制电极的Hallbar样品，并在不同的控制电极电压下测定了二维电子气浓度。如图所示，随着控制电极电压由负变正，二维电子气载流子浓度逐渐从完全排空的状态变为饱和的状态，与上方图例所示的区域相对应。当然我们可以注意到图4.3(d)中控制电压的变化范围要比图4.3(c)中电压的变化范围小得多。这主要是由样品结构造成的。我们的谐振腔结构中有一层额外的过暴PMMA做作为绝缘层，用于隔离顶部控制电极和谐振腔，这导致控制电极的lever arm变小，因此需要更大的电压变化范围才能得到相同的结果。

## 4.5 本章小结

本章主要描述了一个在砷化镓基片上制作的反射式谐振腔的实例，并且研究了二维电子气对谐振腔的调制作用。我们用标准的开路半波长谐振腔模型解释了观察到的反射频谱，并直接从中同时提取了内部Q值和外部Q值。相比于传输线谐振腔，由我们设计改进的反射式谐振腔结构简单，金属占用面积少，可在基片上留出大量空间以便于耦合其他系统。实际上，我们实验室已经开始开展了使用这种类型的谐振腔同时耦合4个量子比特的实验。

当在谐振腔的中部位置制作一个二维电子气结构后，我们发现通过顶部电极电压就可以影响到谐振腔频率和品质因子。这种通过电信号实时改变谐振腔性质的能量为谐振腔在量子信息技术中的应用提供了额外的想象空间。由于二维电子气可以很方面地和其他类型的固态谐振腔体系耦合起来，我们期望这种电极调制现象能够在固态量子计算或其他平面谐振腔应用中发挥出潜在的应用作用。

## 第五章 谐振腔测量量子点导纳性质

在本章中，我们测量了一块反射式谐振腔和Graphene量子点的耦合结构。石墨烯量子点与源漏之间的通道被刻蚀的很窄，隧穿率很低，无法通过输运直接测量信号。但是借助于高品质因子的谐振腔，我们依然能够通过谐振腔反射频谱振幅和相位的移动测的石墨烯双量子点稳态电荷分布相图。更进一步，通过电路模型分析，我们还能提出量子点的复导纳和电子隧穿率。我们展示的这项技术提供了一种新的灵敏探测孤立量子点的方法。

## 5.1 实验动机

由于潜在的消相干时间比较长，碳基材料在固态量子信息研究中得到了关注，特别是仅有单层碳原子构成的石墨烯[71-73]，更是被广泛研究。作为一种备选的量子比特方案，石墨烯量子点的性质也已经得到深入的研究[74-77]。量子点的消相干主要来源于各种电噪声干扰，其中包括量子点源漏的电荷抖动噪声。如果能将量子点与源漏隔离起来，做成孤立系统，则可进一步延长消相干时间[78–80]。但孤立系统的测量本身就是一个问题。最近，量子点的复导纳在理论[81]和实验[82-84,84]上得到了广泛的关注。在本章中，我们将展示一个利用片上谐振腔测量近似孤立的石墨烯双量子点复导纳的实验。有赖于片上谐振腔的高品质因子，我们可以很好的测量出近似孤立量子点的极大电阻和和极小的电容。这项技术提供了一种新的灵敏探测孤立量子点的方法，而且相比于QPC 等结构，更易于加工和设计[85,86]。

## 5.2 样品结构和测量

样品结构如图5.1(a)所示，由制作在同一基片上的石墨烯量子点和反射式谐振腔耦合而成[87]。石墨烯量子点采用刻蚀法制成：先用机械剥离的方法在硅片衬底上得到单层石墨烯，然后使用感应等离子体（ICP）将其刻蚀成双量子点的形状。量子点周围的电极使用电子束曝光工艺制作，由3nm的金属Ti和20nm的金属Au蒸镀而成。最外面的金属谐振腔使用光刻工艺制作，材质为Al，厚度300nm。如图5.1(b)所示，反射式谐振腔耦合微带线的两臂分别连接到量子点的源漏电极上。

$$

上式也只包含描述光子和描述原子的两项，但光子能量保存不变，而原子的能级由于相互作用的影响发生了改变。原子跃迁频率的移动包括两项，其中依赖于光子数的频移 $2 n g ^ { 2 } / \Delta$ 被称作 Stark频移，另一项由真空能量涨落引起的 ${ \mathfrak { g } } ^ { 2 } / \Delta$ 被称作Lamb频移。同样这个性质也可用于量子非破坏性测量，通过原子跃迁能级的改变来判断光子数。实际上，式6.10和式6.11中原子能级和光子能级的相互影响是对偶的，可以看作是海森堡不确定性原理的体现。

JC哈密顿量只是描述了光与原子作用的相干行为，在实际的体系中，非相干行为也非常重要。消相干主要来自3个方面：谐振腔中光子的泄漏或吸收，这通常用光子衰减速率 $\kappa = 0 / \omega$ 来表示；原子的非辐射衰减速率 $\pmb { \gamma } _ { \pmb { \mathrm { i } } }$ 以及原子在谐振腔中停留的时间 $\mathsf { T } _ { \mathtt { t r a n s } }$ 。对于固态体系中的“人工”原子来说， $\mathsf { T } _ { \mathtt { t r a n s } }$ 是无限长的，可以不予考虑。谐振腔中光子衰减κ是测量必须的，它意味着一部分光子能够从谐振腔中泄漏出来，进而被探测电路检测到。原子的衰减可分为辐射和非辐射两部分，辐射衰减意味着有光子放出，完全可以等价为原子与谐振腔中光子的相干相互作用以及光子从谐振腔中的泄漏。原子的非辐射衰减是固态体系中最主要的退相干因素，它受到材料和结构多方面的限制。

体系的行为与耦合强度和消相干速率的相对强弱密切相关。在耦合很强而退相干很弱的情况下，处在谐振腔中的原子就相干地吸收或者发射光子，产生真空Rabi振荡。如果Rabi振荡频率大于体系的消相干速率，在原子退相干或光子泄漏之前就可以观察到多次Rabi振荡，这时我们称体系到达强耦合极限 $( { \mathfrak { g } } > \gamma , \kappa )$ 。在强耦合情况下，系统总的衰减速率是原子和光子二者的平均$\Gamma _ { e f f } = ( \gamma + \kappa ) / 2$ 。当 $\kappa \gg \gamma$ 时，谐振腔会加速原子的衰减，这种现象被称为Purcell效应。Purcell效应提供了一个将不可控的非辐射损耗变为可控的辐射损耗的方法。

## 6.1.2 量子点与腔的耦合

上一节我们讨论了腔与原子相互作用的一般理论。但在我们的实验中，并不是直接使用原子，而是用双量子点来“模拟”一个二能级的原子。本节我们将仔细讨论双量子点是如何与谐振腔相互作用的[90]。如图6.4所示，我们考虑只有一个电子的双量子点，标记电子处于左点和右点的状态分别标记为L)和R)，两点之间的隧穿耦合率为T。量子点的右点通过电极与谐振腔电容耦合，其余部分通过电容耦合至地。对双量子点来说，由于存在隧穿耦合，左点和右点的波

函数相干叠加，可得新的本征态为：

$$
\begin{array} { c } { { \left| + \right. = \sin \Phi \left| \mathrm { L } \right. + \cos \Phi \left| \mathrm { R } \right. } } \\ { { \left| - \right. = \cos \Phi \left| \mathrm { L } \right. - \sin \Phi \left| \mathrm { R } \right. } } \end{array}\tag{6.12}
$$

其中极化角 $\tan { \phi } = - 2 \mathsf { T } / ( \Omega + \Delta ) , \Omega = \sqrt { 4 \mathsf { T } ^ { 2 } + \Delta ^ { 2 } }$ 为|+)和|一)态之间的能量差，为据中心简并点的能量差。对应的能级写成pauli矩阵形式，有

$$
\begin{array} { l } { { \Sigma _ { Z } = \left| + \right. \left. + \right| - \left| - \right. \left. - \right| } } \\ { { \Sigma _ { + } = \Sigma _ { - } ^ { \dagger } = \left| + \right. \left. - \right| } } \end{array}\tag{6.13}
$$

我们假设量子点与谐振腔的波长相比很小，因此静电分析就可以得出二者之间的相互作用强度。若量子点右点与谐振腔之间的电容为 $\mathsf C _ { 1 }$ ，右点到地的电容为${ \mathsf { C } } _ { 2 }$ ，则当谐振腔中的电压为V时，加在量子点上的有效电压为vV，其中分压比$\pmb { \mathrm { v } } = \mathsf { C } _ { 1 } / ( \mathsf { C } _ { 1 } + \mathsf { C } _ { 2 } )$ 。因此相互作用的哈密顿量为：

$$
\mathsf { H } _ { \mathrm { i n t } } = \mathsf { e v } \hat { \mathsf { V } } | \mathbb { R } \rangle \langle \mathbb { R } |\tag{6.14}
$$

其中 $\hat { \boldsymbol { v } }$ 为谐振腔电场算符。若谐振腔的特征阻抗为 ${ \bf { Z } } _ { 0 }$ ，长度为L，单位长度电容为 $\complement _ { 0 }$ ，则谐振频率应为 ${ \omega _ { \mathrm { n } } } = { \epsilon _ { \mathrm { n } } } / { \Sigma _ { 0 } } Z _ { 0 }$ ，其中 $\pmb { \ k _ { \mathrm { { n } } } }$ 满足 ${ \bf k } _ { \mathbf { n } } = ( { \bf n } + 1 ) \pi / 1$ 。按正则量子化的方法，可以将电压算符表示为产生湮灭算符的形式：

$$
\hat { \nabla } = \sum _ { n } \sqrt { \frac { \hbar \omega _ { n } } { \mathbb { C } _ { 0 } } } ( \mathbf { a } _ { n } + \mathbf { a } _ { n } ^ { \dag } )\tag{6.15}
$$

整理可得整个体系的哈密顿量为：

$$
\mathsf { H } = \frac { \hbar \Omega } { 2 } \Sigma _ { z } + \sum _ { \mathfrak { n } } \hbar w _ { \mathfrak { n } } \mathsf { a } _ { \mathfrak { n } } ^ { \dagger } \mathsf { a } _ { \mathfrak { n } } + \hbar \big ( \mathsf { g } _ { z } ^ { \mathfrak { n } } \Sigma _ { z } + \mathsf { g } _ { x } ^ { \mathfrak { n } } \Sigma _ { x } \big ) \big ( \mathsf { a } _ { \mathfrak { n } } + \mathsf { a } _ { \mathfrak { n } } ^ { + } \big )\tag{6.16}
$$

其中耦合强度：

$$
\begin{array} { l } { g _ { z } ^ { n } = { 9 } { 0 } \displaystyle \frac { \mathsf { T } } { \Omega } \sqrt { \frac { \omega _ { n } } { \omega _ { 0 } } } } \\ { { \mathsf { g } } _ { x } ^ { n } = { 9 } { 0 } \displaystyle \frac { \Delta } { 2 \Omega } \sqrt { \frac { \omega _ { n } } { \omega _ { 0 } } } } \\ { { \mathsf { g } } _ { 0 } = { \omega _ { 0 } } { \mathsf { v } } \sqrt { \frac { 2 Z _ { 0 } } { \mathsf { R } _ { \mathrm { Q } } } } } \end{array}\tag{6.17}
$$

考虑到能量匹配，量子点只与谐振腔最低阶模发生耦合，并采用旋波近似，我们可以将哈密顿量化简为：

$$
\mathsf { H } \approx \mathsf { H } _ { \mathrm { J C } } = \frac { \hbar \Omega } { 2 } \Sigma _ { z } + \hbar \omega _ { 0 } \mathsf { a } ^ { \dagger } \mathsf { a } + \hbar \mathsf { g } _ { 0 } \frac { \mathsf { T } } { \Omega } \big ( \mathsf { a } \Sigma _ { + } + \mathsf { a } ^ { + } \Sigma _ { - } \big )\tag{6.18}
$$

这就是 JC 哈密顿量的形式！

值得注意的是，在腔与量子点的耦合体系中，耦合强度是直接与腔的谐振频率ω、分压比v，以及量子点的能级位置T/Ω相关的量。若要增强耦合强度，提高腔的谐振频率是非常有效的方法，但过高的谐振频率在实验上并不容易测量实现。分压比与量子点同外界的耦合电容有关，要提高分压比就要尽量是量子点只与谐振腔耦合，而减少其他对地耦合。但量子点的设计往往需要多个电极来调节，这些电极会增加量子点地的耦合。若腔的谐振频率为 $6 6 { \mathsf { H } } z ;$ ，分压比$\pmb { \nu } = 0 . 3$ ，在 $\Delta = 0$ 时T/Ω最大为1，可得耦合强度 ${ \mathfrak { g } } \approx { \mathfrak { 8 0 } } M { \mathsf { H } } z$ 。这与超导约瑟夫结体系的耦合强度在一个数量级，但对于量子点体系，通常退相于比较严重(<200ns)，因此很难实现强耦合。

## 6.2 实验样品结构

我们实验中使用的是 Graphene双量子点和谐振腔的耦合结构。样品结构如图6.5所示，石墨烯量子点采用刻蚀法加工而成。首先，我们使用机械剥离的方法在硅片上得到单层石墨，用电子束曝光技术在石墨上制作出量子点形状的掩膜，并用等离子体刻蚀掉多余的石墨得到石墨烯量子点。在这个实验中，我们还在量子点旁边一同制作了石墨烯QPC结构，用于量子点的灵敏测量。其后，我们在量子点和 QPC 周围制作了源漏电极和控制门电极，电极材质为 5nm Ti 和45nmAu。最后，我们使用光刻技术制作谐振腔，并将谐振腔和石墨烯量子点电极连接起来。谐振腔依然采用的是半波长的耦合微带线反射式谐振腔，材质为300nm厚的金属Al。本次实验与上一章的所使用的样品结构类似，关键是连接方式不同。本次实验是为了研究腔与量子点之间的耦合，量子点在谐振腔电场中等效为一个电偶极子，不需要直接与谐振腔导通，所以谐振腔耦合微带线的两臂连接的是量子点的控制门电极。而在上一章中，谐振腔是作为一个高灵敏度的探测器用以研究量子点复电导的性质，所以谐振腔耦合微带线的两臂连接的是量子点的源漏电极。

测量电路也如图6.5所示。谐振腔通过180度混合环和环形器与外界测量电路连接，网络分析仪输出的微波信号经过两级各30dB的衰减以做到良好热接触，谐振腔的反射频谱经过液氮温度和室温两级放大，最终被网络分析仪测的。整个样品被置于稀释制冷机（base温度约为26mK）中，并做了很好的热屏蔽以杜绝外界热辐射的影响。

## 6.3 结果分析

上述观察到的现象可以用主方程模型解释[25]：

量子点与谐振腔通过偶极相互作用耦合可以用如下的哈密顿量来描述：

$$
\mathsf { H } = \hbar \Delta _ { 0 } \mathsf { a } ^ { + } \mathsf { a } + \frac { \hbar \Delta } { 2 } \sigma _ { z } + \hbar g _ { e f f } \left( \sigma _ { + } \mathsf { a } + \sigma _ { - } \mathsf { a } ^ { + } \right)\tag{6.20}
$$

其中 $\omega _ { 0 }$ 为谐振腔本身的谐振频率， $\omega _ { \mathsf { R } }$ 为探测微波的频率， $\Omega = \sqrt { \left( 2 \mathrm { t } _ { \mathrm { c } } \right) ^ { 2 } + \varepsilon ^ { 2 } }$ 为量子点上下能态的能级差。在探测微波能量的基准下， $\Delta _ { 0 } = \omega _ { 0 } - \omega _ { \mathrm { R } }$ $\Delta = \Omega - \omega _ { \mathrm { R } }$ 。有效耦合强度 $g _ { e f f } = { \bf g } _ { 0 } \cdot 2 \mathbf { t } _ { \mathrm { c } } / \Omega$

对于整个系统来说，能量耗散主要包括微波谐振腔内部本身的能量损耗 $\kappa _ { \mathrm { i n } }$ ，谐振腔向外界电路泄漏的能量 $\pmb { \kappa } _ { \pmb { \sigma } \pmb { u } \pmb { t } }$ ，量子点比特的退相干 $\boldsymbol { \mathsf { \pmb { \gamma } } }$ 。可以用主方程描述真个系统的演化：

$$
\begin{array} { r } { \dot { \boldsymbol { \rho } } = - \mathsf { i } [ \mathsf { H } , \mathsf { \rho } ] + \mathsf { \kappa D } [ \mathbf { a } ] \mathsf { \rho } + \gamma \mathsf { D } [ \sigma _ { - } ] \mathsf { \rho } } \end{array}\tag{6.21}
$$

其中 ${ \begin{array} { r } { \mathrm { D } [ \mathbf { a } ] \mathbf { \rho } = \mathbf { a } \mathbf { \rho a } ^ { + } - \frac { 1 } { 2 } \mathbf { a } ^ { + } \mathbf { a } \mathbf { \rho } - \frac { 1 } { 2 } \mathbf { \rho a } ^ { + } \mathbf { a } } \end{array} }$ 为 Lindblad 算子， $\kappa = \kappa _ { \mathrm { i n } } + \kappa _ { \mathrm { o u t } }$ 为谐振腔总的能量泄漏率。相应的算符演化方程为：

$$
\begin{array} { r } { \dot { \mathbf { a } } = - \mathrm { i } \Delta _ { 0 } \mathbf { a } - \mathrm { i } 9 _ { e ^ { \dagger \dagger } } \boldsymbol { \sigma } _ { - } - \cfrac { 1 } { 2 } \kappa \mathbf { a } + \sqrt { \kappa _ { e } } \mathbf { a } _ { \mathrm { i n } } } \\ { \dot { \mathbf { \sigma } } _ { - } = - \mathrm { i } \Delta \boldsymbol { \sigma } _ { - } + \mathrm { i } 9 _ { e ^ { \dagger \dagger } } \mathbf { a } \boldsymbol { \sigma } _ { z } - \cfrac { 1 } { 2 } \gamma \boldsymbol { \sigma } _ { - } } \end{array}\tag{6.22}
$$

在我们的测量中，控制门电极电压的变化速率远小于量子点能量弛豫的速率，量子点始终处于基态，所以有 $\sigma _ { z }  - 1$ 。将其代入上式，并有旋波近似$\dot { \mathfrak { a } } = - \mathfrak { i } ( \omega - \omega _ { \mathtt { R } } ) \mathfrak { a }$ ，我们可以得到：

$$
\begin{array} { r l } & { \quad - \mathrm { i } ( \omega - \omega _ { \mathsf { R } } ) \mathsf { a } = - \mathrm { i } \Delta _ { 0 } \mathsf { a } - \mathrm { i } 9 _ { e ^ { \mathsf { f } } \mathsf { f } } \sigma _ { - } - \displaystyle \frac { 1 } { 2 } \kappa \mathsf { a } + \sqrt { \kappa _ { e } } \mathsf { a } _ { \mathsf { i n } } } \\ & { \quad - \mathrm { i } ( \omega - \omega _ { \mathsf { R } } ) \sigma _ { - } = - \mathrm { i } \Delta \sigma _ { - } + \mathrm { i } g _ { e ^ { \mathsf { f } } \mathsf { f } } \mathsf { a } \sigma _ { z } - \displaystyle \frac { 1 } { 2 } \gamma \sigma _ { - } } \end{array}\tag{6.23}
$$

反射式谐振腔是单端泄漏的，根据谐振腔输入输出理论，有输入输出约束条件$\mathtt { a _ { i n } } + \mathtt { a _ { o u t } } = \sqrt { \kappa _ { e } } \mathtt { a }$ ，代入上式中，我们可以得到：

$$
\mathsf { S } _ { 1 1 } = \frac { \mathsf { a } _ { \mathsf { o u t } } } { \mathsf { a } _ { \mathsf { i n } } } = - \frac { \mathsf { i } ( \omega _ { 0 } - \omega ) + \mathsf { g } _ { e f f } \chi + \frac { \kappa _ { \mathrm { i } } - \kappa _ { e } } { 2 } } { \mathsf { i } ( \omega _ { 0 } - \omega ) + \mathsf { g } _ { e f f } \chi + \frac { \kappa _ { \mathrm { i } } + \kappa _ { e } } { 2 } }\tag{6.24}
$$
