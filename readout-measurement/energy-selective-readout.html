能量选择性读出

能量选择性读出

2026年9月08日16分钟阅读

能量选择性读出（energy-selective readout，Elzerman readout）通过把源漏费米面调到单电子塞曼两个能级之间，让激发态电子隧穿出量子点而基态电子留下，把单自旋映射为一次可被电荷传感器检测的电荷跳变。

物理图像

在二维电子气或硅基 MOS 量子点中，最简单的一比特单自旋量子比特编码在塞曼劈裂后的两个电子自旋态 ∣↑⟩（激发态）与 ∣↓⟩（基态）上，二者能量差为塞曼能 EZ​=gμB​B。直接测量自旋极难，但若让两个自旋态对应到不同的电荷占据，电荷跳变就可以被紧邻的QPC或单电子晶体管（SET）读取——这正是自旋–电荷转换的核心思想。

能量选择性读出的实现方式是：把源漏费米面调到 ∣↑⟩ 与 ∣↓⟩ 两个自旋能级之间。

  • ∣↑⟩ 电子的电化学势 μ↑​ 高于源漏费米面 EF​，该电子被”能量允许”隧穿到源漏，把空位让出；
  • ∣↓⟩ 电子的 μ↓​ 低于 EF​，无法隧穿，留在量子点中。

随后源漏以 ∣↓⟩ 速率回填一个低能电子，把量子点重新占据为基态。这一”激发态先出、基态后入”的单次事件，在传感器上产生一个特征的高电平脉冲（blip）；如果电子本来就处于 ∣↓⟩，信号一直保持低电平。两种轨迹一一对应，电子自旋被转换为可由阈值判定的电荷跳变）。

读出窗口（readout window）由塞曼能 EZ​ 决定。窗口越宽，塞曼能级对热涨落越不敏感，但需要的驱动频率也越高：硅中 g≈2，1 T 磁场对应的拉莫尔频率约 28 GHz。这是单自旋比特实验中微波驱动与读出窗口之间的”高频代价”。

与泡利自旋阻塞的对比

半导体自旋量子比特的单发读出主要依赖两条自旋–电荷转换路径：

  • 能量选择性读出：把电子自旋映射到”是否跳出量子点”，读出窗口 = 塞曼能 EZ​；
  • 泡利自旋阻塞（Pauli spin blockade，PSB）：把单态 S 与三重态 T 映射到双量子点不同电荷构型，读出窗口 = 单量子点内的单态–三重态能隙 EST​。

理论模型

单电子塞曼哈密顿量

单电子在外磁场 B 下的最低两个能级由电化学势的塞曼分裂描述：

μσ​=μ0​+σEZ​/2,EZ​=gμB​B,σ=±1 (对应 ↑,↓).

把费米面调到 EF​∈(μ↓​,μ↑​)，隧穿选择定则为：只有 μ↑​>EF​ 的电子能从量子点隧穿到源漏，隧穿速率为 Γ↑out​。

速率方程模型

读出阶段的动力学涉及三个状态——“激发态未被排出” P↑​、“基态未被排出” P↓​、“量子点已被排出过” P0​——状态矢量 P=(P↑​,P↓​,P0​)T 满足 dP/dt=QP，转移矩阵为：

Q=​−W−Γ↑out​WΓ↑out​​0−Γ↓out​Γ↓out​​0Γ↓in​−Γ↓in​​​

其中 W=1/T1​ 是自旋弛豫速率，Γ↑out​ 与 Γ↓out​ 分别是激发态、基态电子的隧穿出速率，Γ↓in​ 是基态电子从源漏回填的速率。Q 不含时，解为 P(t)=eQtP(0)。t 时刻量子点已被排空的概率为

P0​(t)=Γ↓tot​Γ↓out​​(1−e−tΓ↓tot​)+P↑I​W+Γ↑out​−Γ↓tot​Γ↑out​−Γ↓out​​(e−tΓ↓tot​−e−t(W+Γ↑out​))

其中 Γ↓tot​=Γ↓out​+Γ↓in​。第一项与 P↑I​ 无关，是基态电子来回隧穿构成的”本底鼓包”；第二项与 P↑I​ 成正比，是平均信号上”自旋鼓包”（spin bump）的来源，实验上把这条曲线拟合即可提取三个隧穿速率）。

自旋–电荷转换可见度

若只关心时间窗口 tr​ 内电子是否跳出过——即忽略回填通道（Γ↓in​=0），自旋–电荷转换可见度的解析式为

VSTC(t)=F↑STC​(t)+F↓STC​(t)−1=W+Γ↑out​−Γ↓out​Γ↑out​−Γ↓out​​(e−tΓ↓out​−e−t(W+Γ↑out​))

最佳时间窗口取导数零点：

toptSTC​=W+Γ↑out​−Γ↓out​1​lnΓ↓out​W+Γ↑out​​Γ↑out​≫W​Γ↑out​−Γ↓out​1​lnΓ↓out​Γ↑out​​.

物理上这是一场赛跑：窗口太短激发态来不及跳出，太长基态也开始跳出，最优值由两隧穿速率之比的对数决定。

读出可见度的因子化

完整的读取可见度严格满足因子化关系

VR=VSTC×VE

其中 VSTC 是时间窗口选取决定的”映射”段，VE 是阈值选取决定的”获取+判决”段，VE 没有解析解，需要用 Monte-Carlo 方法模拟得到。分解后两段可分别优化：VSTC 的最大值只与隧穿速率有关，VE 主要受传感器和放大链硬件（噪声、低通滤波）影响。

实验特征

E–W–R 三段脉冲序列

硅量子点单发读出的典型时间序列由三段方波组成）：

  1. E（Empty，排空）：把 RP 电压调到远离电荷跃迁线的位置，强制把量子点电子排空到源漏；
  2. W（Load，载入）：等待时间 twait​ 内把 RP 电压推到 (0,1) 区，单个电子以随机自旋进入量子点；
  3. R（Readout，读出）：RP 电压调到自旋两能级之间的输运线上，激发态电子跳出、基态电子留下，由紧邻 SET 监测。

把 twait​ 从短到长扫描，可以得到自旋激发态概率的指数衰减曲线 P↑M​(twait​)=ρe−twait​/T1​+α，振幅 ρ 是初始激发态概率、暗计数 α 来自基态误判。

读出位置标定与 spin-bump

并非任意读出位置都能实现自旋选择性读出：电压太高时两自旋态都能跳出，电压太低时两自旋态都不跳出。标定方法：用 E–W–R 序列固定 Empty/Load 电压而扫描 Readout 高度，再跟两个连续的 Load–Read 作为监视位（无论第一位读出结果如何，后面两位的电子状态必然回到 ∣↓⟩，因此监视位的”高电平比例” >0.2 即说明暗计数过多，需重新标定）。合适的读出位置会出现 50:50 的高低电平分布，平均信号 x(t) 呈”自旋鼓包”（spin bump）形状——这是 Elzerman 读出的指纹特征。

单发读出的速率方程拟合流程

完整模拟分三步：

  1. GMM 拟合：用二维高斯混合模型（Gaussian mixture model）拟合原始信号的概率密度分布，得到高低电平的均值 μ1​,μ2​；
  2. 速率方程拟合：用 P0​(t) 解析式拟合平均信号，提取 Γ↑out​,Γ↓out​,Γ↓in​；
  3. Monte-Carlo 复现：用拟合参数生成无噪声的高低电平信号，加白噪声，经 8 阶贝塞尔低通滤波（10 kHz 截止）模拟实验线路，对窗口 tr​ 内取最大值并与电压阈值 xt​ 比较，得到 F↑​,F↓​,VR。

射频反射放大与 RF-SET

直流 SET 测量的带宽受直流线缆寄生电容与锁相积分时间限制，仅数十 kHz 量级，不足以追踪 Elzerman 读出中 ∼ ms 量级的隧穿事件细节。把 SET 接入阻抗匹配谐振电路，以射频反射方式读出，构成 RF-SET，把带宽推到 MHz–百 MHz 量级，可逐次追踪单次隧穿事件。

硅基 SiMOS 中典型 RF-SET 设计：贴片电感 L 与寄生电容 Cp​ 组成谐振电路，把 SET 的高电阻（RSET​∼625 kΩ）匹配到 50 Ω 传输线；通过劈裂栅极（split-gate）方法在累积栅极 AL1 上连接射频端口，把 Cg​ 从”泄漏通道”转化为”耦合通道”，阻抗匹配的 Cg​ 范围扩大到 0.1–5 pF。

与泡利自旋阻塞的扩展联合

在 GaAs 双量子点的 (1,3)–(0,4) 区附近，等人发现一种非阻塞区读出机制：把三重态 T(1,3) 的弛豫路径引导到比单态少一个电子的中间亚稳态 (0,3)，从而把单态映射为 (0,4)、三重态映射为 (0,3)。(0,3)–(0,4) 的电荷差通过 QPC 传感后是 (1,3)–(0,4) 的 1.6 倍，这种”信号放大”把读出信号增强到自旋阻塞方案的 2 倍左右。尽管这条机制仍以电荷占据作为媒介，但其核心思想——通过控制弛豫路径放大自旋–电荷转换效率——是能量选择性读出思想的多电子区推广。

多比特联合与读出时间代价

Elzerman 读出与自旋穿梭（spin-shuttle）结合可推广到两比特体系：右比特 QR​ 不直接与源漏电子库耦合，而是先把电子隧穿到左比特 QL​，再在 QL​ 端与源漏费米面交换完成读出。这种”左点代理”读出牺牲读出时间换取结构兼容性，整体单发读出时间约 28 ms（1000 次平均）。

与其他概念的关系

  • 自旋–电荷转换的两条主要路径——能量选择性读出与泡利自旋阻塞——共享”把不可直接测量的自旋映射到电荷跳变”的核心思想，差别在窗口大小与适用比特类型。
  • 单发读出的三环节（映射 → 获取 → 判决）中，能量选择性读出属于第一步”映射”环节；后续由QPC / SET获取、放大、分类。
  • 阈值无关读出以能量选择性读出为载体，把可见度 VR 的下降显式反推回 P↑I​，把 ∣P↑E​/P↑I​−1∣<1% 的参数空间扩大约 60 倍。
  • 射频反射测量与栅极射频传感是从直流 SET 出发、对 Elzerman 读出隧穿事件的硬件加速，把带宽推到 MHz 量级。
  • 色散读出在超导量子比特中扮演类似角色——它也是把量子态映射到腔频/相位变化，是 Elzerman 思想在微波频段的延伸。
  • 电荷噪声通过调制势垒高度影响 Γ↑out​,Γ↓out​，是限制能量选择性读出保真度的关键环境扰动。
  • 单自旋量子比特是能量选择性读出的天然载体；单态–三重态量子比特与空穴自旋量子比特则更倾向 PSB 或色散读出。
  • 在多电子编码与二维扩展的趋势下，Elzerman 读出逐渐被 PSB + RF-reflectometry 取代），但在初始化、低温基准测量、远距离自旋搬运等场景仍是首选。
