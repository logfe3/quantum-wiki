CNOT 门

CNOT 门

2026年9月08日22分钟阅读

CNOT 是条件逻辑：目标比特是否翻转取决于控制比特状态。与任意单比特旋转组合后，它构成通用量子门集；半导体量子点的两类典型实现分别基于电荷比特的强电容耦合（条件频移抑制）与自旋比特的常开交换（共振条件频率 + 虚拟相位补偿）。

定义与逻辑结构

CNOT（controlled-NOT，受控非门）作用在两个比特上：控制比特 c 与目标比特 t。当 c=∣1⟩ 时目标比特翻转，否则保持不变：

∣ct⟩⟶∣ct⊕c⟩.

写成计算基 {∣00⟩,∣01⟩,∣10⟩,∣11⟩} 上的 4×4 矩阵，它只在中间两个基矢之间交换：

UCNOT​=​1000​0100​0001​0010​​.

CNOT 自身不是通用门（只靠它无法生成任意酉变换），但与任意单比特旋转组合即构成通用量子门集：UCNOT​ 加上 Bloch 球上绕任意轴的旋转可以构造任意两比特酉变换（由 Solovay–Kitaev 定理，任意单比特旋转可用有限长度的 Hadamard + T 序列逼近）。在硅基自旋比特体系中常用的另一组等价分解是 CZ（控制 Z）加两路单比特 π/2；后者源自受控相位累积 UCPhase​(πℏ/J)=diag(1,1,1,−1)，再以单比特 Z(−π/2) 改写矩阵形式即为 CZ，进而由 CZ 与单比特门合成 CNOT。

半导体中的两类基本机理

在量子点体系中，“控制比特是否决定目标比特翻转”通常由两条不同的物理机理承担：

  1. 条件频移抑制（capacitive-coupling CNOT）：两个电荷量子比特被强电容耦合，控制比特处于 ∣1⟩ 时通过库仑相互作用把目标比特的失谐平衡点整体平移一个耦合能 J。事先把目标比特的脉冲高度调到”控制比特 ∣0⟩ 时恰好把目标送到平衡点”——控制比特翻转到 ∣1⟩ 后同一脉冲不再到达平衡点，拉莫振荡被抑制，目标比特保持不变。条件频移的强度 J 直接决定”关”态抑制的彻底程度。
  2. 常开交换 + 共振条件驱动（resonantly driven CNOT）：两个单自旋比特的交换相互作用 J 始终保持有限（J≪ΔEZ​，ΔEZ​ 为两点塞曼能差）。由于反平行态能级下移 J/2，一个比特的拉莫尔频率依赖于另一个比特的状态，形成四个条件频率 f1↓​、f1↑​、f2↓​、f2↑​。在 fi↑​ 上驱动目标比特，则只有当控制比特为 ∣↑⟩ 时才发生拉比翻转——这就是受控旋转（CROT）门。

两条路线在 与 的论文中分别做了完整演示：前者用 GaAs/AlGaAs 强电容耦合双电荷比特实现了脉冲振幅控制的 CNOT，并测得 68% 的真值表保真度；后者在 Si-MOS 双量子点中把交换相互作用保持常开，用微波驱动条件频率实现 CROT，经相位补偿后合成 CNOT，并经门集层析（GST）测得约 64% 的保真度。

理论模型（一）：GaAs 强电容耦合双电荷比特

双比特哈密顿量

把每个电荷量子比特视为一个双量子点，单电子编码为 ∣L⟩、R⟩；比特自身哈密顿量为

Hq​=2εq​σz​+Δq​σx​​

其中失谐 εq​ 控制左右能级差，Δq​=2tc​ 为点内隧穿耦合。上下两组双量子点通过垂直方向的两个水平电极 H1​、H2​ 之间的几何间隙发生电容（偶极–偶极）耦合。设上比特能级差 ε1​、下比特能级差 ε2​，两组量子点间的电容耦合能为 J，则四能级哈密顿量为

H2q​=i=1∑2​21​(εi​σz(i)​+Δi​σx(i)​)+4J​(I−σz(1)​)⊗(I−σz(2)​)

其中耦合项 ∝(I−σz(1)​)(I−σz(2)​)/4 来自 ∣R⟩R​⟩D​ 组合下的电容能修正（σz​ 取 +1 对应 ∣L⟩）。在直积基 {∣LR⟩,∣RR⟩,∣LL⟩,∣RL⟩} 下改写为矩阵：

H2q​=21​​ε1​+ε2​+J/2Δ1​Δ2​0​Δ1​−ε1​−ε2​+J/20Δ2​​Δ2​0ε1​−ε2​−J/2Δ1​​0Δ2​Δ1​−ε1​+ε2​−J/2​​.

论文对比了 Fujisawa 小组（完全对称四量子点）与改进的”上下不对称 + H 电极在中间分开为 H1​、H2​“两种结构，前者的耦合项为 σz(1)​σz(2)​/4 形式，后者为 (I−σz(1)​)(I−σz(2)​)/4 形式。差异来自两个失谐运动的电子在两种几何中的相对位置不同：不结构使得控制比特的状态几乎不影响目标比特的失谐平衡点，从而方便构造动态受控逻辑门。

CROT 条件与 CNOT 是其特例

把目标比特置于 ε1​=J/2 处，并假设两组点内隧穿耦合相同 Δ1​=Δ2​=Δ，可解析求出四个本征态。在 ∣R⟩R​⟩D​ 与 ∣L⟩R​⟩D​ 之间能级差 Δ 的条件下（即 Δ/J≈1 且 ∣ε22​−J2∣/2Δ≫1），对下比特为 ∣R⟩D​ 时上比特发生拉莫振荡、为 ∣L⟩D​ 时振荡被抑制——这就是 CROT 门。CNOT 是 CROT 旋转角取 π 的特例。

理论模型（二）：Si-MOS 常开交换 + 共振驱动

海森堡模型与能谱

把电子放在硅基双量子点中、两点各通过微磁体引入磁场梯度，双电子自旋系统在磁场沿 z、忽略横向分量贡献的近似下由海森堡哈密顿量描述：

H=JS1​⋅S2​+gμB​(B1​S1z​+B2​S2z​).

在直积基 {∣↑↑⟩,∣↑↓⟩,∣↓↑⟩,∣↓↓⟩} 下（∣σi​⟩ 为第 i 点电子自旋沿 z 投影）写为

H=​EˉZ​000​0−J/2+ΔEZ​J/20​0J/2−J/2−ΔEZ​0​000−EˉZ​​​

其中 EˉZ​=(EZ1​+EZ2​)/2、ΔEZ​=EZ1​−EZ2​。

当 J≪ΔEZ​ 时（本征态近似为自旋直积态），打开 J 把反平行态 ∣↑↓⟩ 与 ∣↓↑⟩ 的能量整体下移 J/2，于是目标比特的拉莫尔频率依赖于控制比特的状态：

f2↓​≡fQ2​,f2↑​≡fQ2​−J.

在 f2↑​ 上驱动目标比特，只在控制比特为 ∣↑⟩ 时翻转——这就是 CROT。实验中（论文）失谐 ε=0 处测得 J=4.8(4) MHz，两点拉莫尔差 ΔEZ​=55.4 MHz，比例 J/ΔEZ​≈0.087，正好处于”J 常开 + 共振条件驱动”工作区。

在本征基下做旋波近似

为定量给出 CROT 的演化算符，需把哈密顿量转到系统本征基。引入把直积基映射到本征基的变换 V0​，并施加一个沿 x 方向幅度为 AR​、相位为 ϕ 的微波驱动，旋转坐标系下的有效哈密顿量（5.4 节）为

HR​=2J​λI​+2J​λZ​+2AR​​(cosθcosϕ)λX​+2AR​​(cosθsinϕ)λY​+2AR​​(cosθcosϕ)κX​+2AR​​(cosθsinϕ)κY​

其中 λI,X,Y,Z​ 与 κI,X,Y,Z​ 分别是两个独立子空间（λ 子空间与 κ 子空间）内的泡利算符，θ=arctan[2Δ/(ε2+4Δ2​−ε)] 是混合角。演化算符可因式分解为三项

UR​(t)=exp[−2i​J2/4+ΔEZ2​​tZI]⋅exp[−2i​Ωλ​tnλ​⋅λ]⋅exp[−2i​Ωκ​tnκ​⋅κ]

其中 Ωλ​=AR2​cos2θ+J2​、Ωκ​=AR​cosθ。要实现真正的 CNOT 门必须同时满足三个条件：

  1. 微波相位 ϕ=0；
  2. λ 子空间旋转 Ωλ​t=2mπ，把控制比特在 λ 子空间中的相位带回原位；
  3. κ 子空间旋转 Ωκ​t=(2n−1)π，让目标比特完成 π 翻转。

由于 Ωκ​=AR​cosθ 而 Ωλ​ 还含 J，两条件对应不同的微波持续时间：分别解得 tλ​=2mπ/Ωλ​ 与 tκ​=(2n−1)π/Ωκ​，合成一个完整 CNOT 的总时长 ttot​=4π/J，比单独满足 κ 子空间的 15π/J 多出 3%。这段多余时间就是控制比特 λ 子空间的相位累积，也是虚拟相位补偿的对象。

虚拟 Z 与虚拟相位补偿

CROT 与 ZCROT 之间的相位相差 180∘，后者的额外相位可通过控制比特上的虚拟 Z 旋转（直接调节后续 AWG 脉冲相位）一次性补齐；剩下 3% 的 λ 子空间相位来自 J 常开下微波对相邻频率的”非共振驱动”，需要按门逐个补偿。论文给出的解析关系把每个受控旋转门 fm,σ​ 在四个直积基 {∣↓↓⟩,∣↓↑⟩,∣↑↓⟩,∣↑↑⟩} 上累积的相位列成相位误差补偿表，对后续每个脉冲在物理施加前先减去表中的累积相位。实验中从四种校准序列的 Ramsey 拟合得到相位偏移

(θCNOT12​,θCNOT21​,θZCNOT12​,θZCNOT21​)=(0.166π,0.207π,−0.139π,−0.129π)

由此反推出非共振哈密顿相位误差

(ϕ1↑​,ϕ2↑​,ϕ1↓​,ϕ2↓​)=(−0.0517π,−0.0415π,0.0198π,0.0248π).

完成这些校准后，可通过 CROT 与 ZCROT 合成 CNOT 与 ZCNOT，整个两比特 Clifford 群都建立在同一时长（约 400 ns）的 CROT 单元之上。

真值表测量与门保真度

CNOT 门的实验验证通常分两步：先用过程层析或随机基准测出完整的 4×4 矩阵并报告保真度；再用四种输入态 ∣00⟩、01⟩、10⟩、11⟩ 各做一次 CNOT 后的输出概率分布给出一目了然的真值表。

（GaAs/AlGaAs 电容耦合）：把两个电荷比特都调到少电子区，取 J=119 μeV≈29 GHz、ΔU​≈6.2 GHz、ΔL​≈6.0 GHz。先制备输入态（控制比特 3π=360 ps 的非绝热脉冲，目标比特同幅度的 π 或 3π 脉冲），然后做 CNOT 操作并用 QPC 通道测量上下比特处于 ∣0⟩ 的概率。实验测得传输矩阵

Tmeasured​=​0.090.870.060.02​0.890.120.020.07​0.0020.010.740.23​0.020.0020.180.68​​

对照理想矩阵可由式 F=1−∑i=j​∣Tij​∣ 得出真值表保真度约 68%。论文还指出 ∣11⟩ 输入态制备需要把脉冲高度调整为原幅度加耦合能补偿（条件频移），这是电容耦合 CNOT 在多比特工作时的典型边界条件。

（Si-MOS 常开交换）：论文对两个单比特分别做 GST 测试，得到 QL​ 比特单比特门保真度 I=93.3%、X=97.0%、Y=97.2%，QR​ 比特 I=92.4%、X=99.5%、Y=99.6%；两个比特的 T2​≈400 ns，样品中 T2∗​ 也仅数百纳秒。在此基础上对 CNOT 做 GST 测得保真度约 64%，论文明确指出主要限制来自极短的相干时间。叠加波形的畸变、AWG 幅度校准、非共振驱动相位补偿等步骤虽然已经完成，仍无法突破相干时间的硬上限。

（Si/SiGe 一维四量子点）：采用先做 CZ（CPhase 演化时间 t=πℏ/J）再合成 CNOT 的路线。在对称操作点（失谐零点 ε=0）J≈6.25 MHz、演化时间 80 ns；为抑制电荷噪声引入 Hahn echo 波形标定 ΔEZ​ 偏移并精确校准相位。论文给出 X、Y 单比特门（83 ns）保真度超过 99%，并用 IRB 方法量化比特间串扰。两比特 RB 给出 CZ 门保真度 FCZ​=90.96±7.48%，CZ 与单比特门合成即得 CNOT。

实验特征与读出

条件频移的真值表指纹。电容耦合 CNOT 在 QPC 通道上的特征是”目标比特振荡是否出现”完全由控制比特态决定：固定控制比特 θL​=π（∣0⟩L​→∣1⟩L​）后扫描目标比特矩形脉冲宽度，P0U​(θL​=0) 给出完整拉莫振荡、P0U​(θL​=π) 几乎恒为 1——后者的抑制程度就是关态保真度的直接度量。

四个条件频率的能谱测量。J 常开方案的核心标定是四个条件频率 f1↓​、f1↑​、f2↓​、f2↑​ 的逐一测量。固定控制比特初态、对目标比特扫描拉莫尔频率得到两条共振线（取决于控制比特态），交换两条线的角色重复一次即可画出四个频率。从线间距可直接读出 ΔEZ​ 与 J（J=f1↑​−f1↓​=f2↑​−f2↓​）。

拉比频率非均匀与功率校准。fi↓​ 与 fi↑​ 的驱动拉比频率在相同微波功率下不一定相等，原因是控制比特不同自旋态下目标比特的 Rabi 振荡振幅不同。实验通过调节 AWG 幅度（而非微波源功率）使 f1↓​ 与 f2↓​ 同步，并把另外两个 ZCROT 的幅度按比例校准。幅度比例不是常量，需在工作点漂移或电压整体偏移时重新标定。

CROT 与 ZCROT 的相位差。CROT 使目标比特 π 旋转、控制比特绕 z 转 π，因此 CROT 与 ZCROT 之间存在 180∘ 相位差，对控制比特做一次虚拟 Z 即可在两个门之间切换，这是 J 常开方案能合成全部两比特 Clifford 群的关键。

对称工作点抑制电荷噪声。CPhase/CZ 路线中，J(ε) 在 ε=0 处对失谐一阶不敏感（dJ/dε∣ε=0​=0），是首选工作点；该点需要先用 Hahn echo 型波形结合傅里叶变换精标，再固定脉冲宽度改变 J 或固定 J 改变宽度。论文给出 J(ε)=2tU/(U2−ε2) 形式，并在对称点附近观察到振荡图案关于失谐对称分布。

适用边界与推广

  • 三比特推广：把同样的条件频移思想推广到Toffoli 门：三电荷比特中目标比特失谐平衡点由两个控制比特状态相加地决定，∣11⟩ 态对应 J12​+J13​、∣10⟩ 或 ∣01⟩ 对应单一耦合、∣00⟩ 不偏移，因此仅在两控制比特同时为 ∣1⟩ 时目标比特才完成拉莫振荡翻转——这是 Toffoli 的静态演示版本。J 常开方案中，论文明确把 CNOT 视为”Toffoli 等多比特受控旋转的基础”。
  • SWAP​ 路线：当 J≫ΔEZ​ 时系统本征态变为单态-三重态基，调控 J 可直接实现 SWAP​ 门，再结合单比特 π 旋转合成 CNOT。这是 Hubbard 极限下的等价表达，论文中由 J=4t2/U 主导。
  • CPhase/CZ 路线：交换作用只作为条件相位来源，演化 t=πℏ/J 给出 diag(1,1,1,−1) 即 CZ 矩阵，再以两路单比特 Z(−π/2) 改写即得 CNOT。优势是无需微波、波形简单；代价是门时长直接由 J 决定，J 越小门越长，受退相干约束更大。
  • 动态解耦 CNOT：在 CPhase 演化中间插入解耦序列可同时抑制电荷与核自旋噪声，论文在 Si-MOS 上演示了非绝热 DCZ 门作为补充方案。
  • 几何门与复合脉冲：当 CNOT 中的旋转误差（功率失配、过冲、上升沿）成为主要错误源时，可借助几何量子门或分段复合脉冲把残留误差压到二阶，硅基与超导体系都已有报告把单比特门推到 99.9% 以上。

与其他概念的关系

  • 电荷量子比特：电容耦合 CNOT 的”两个比特 + 强偶极–偶极耦合”模型即两电荷量子比特的直接推广；本词条中的 J(ε) 曲线与条件频移机理贯穿、两篇论文。
  • 交换相互作用：自旋比特 CNOT 的耦合源——J 常开方案以有限 J 为前提，CPhase/CZ 方案把 J 用作条件相位源；Hubbard 极限下 J=4tc2​/U 是双比特门速率的标尺。
  • 单自旋量子比特：J 常开 CNOT 需要每个比特独立可寻址的拉莫尔频率，磁场梯度（微磁体）与 ESDR（电偶极自旋共振）共同提供这一前提；单比特保真度是 CNOT 误差的下界。
  • 单态–三重态量子比特：S–T0​ 比特的 z 轴（交换轴）与 x 轴（磁场梯度轴）组合也可实现两比特条件门，是另一族以交换为核心的两比特门路线。
  • Toffoli 门：CNOT 的三比特推广既可由 CNOT 与单比特门串联构造，也可直接由三比特条件频移静态演示，本词条的条件抑制机理即其基础。
  • 动力学解耦：用于 CPhase/CZ 演化中抑制电荷噪声与核自旋噪声，论文中明确把它与非绝热 CZ 结合形成 DCZ。
  • 单发读出：CNOT 真值表测量依赖输入态制备与输出态单发读出；QPC 与射频反射读出都是当前的主流接口。
  • 电荷噪声与GaAs/AlGaAs、Si-MOS：前者决定 CNOT 的最大允许门时长，后者决定 T2∗​ 与典型 J 调谐能力——电容耦合 GaAs 路线受短 T2∗​ 拖累（保真度 68%），常开 Si-MOS 路线则受短 T2∗​ 与微波校准误差双重影响（保真度 64%）。
