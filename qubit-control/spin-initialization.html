自旋初始化

2026年9月08日24分钟阅读

自旋初始化指在每次量子线路开始前把量子点中载流子的自旋自由度制备到已知纯态（通常为塞曼基态 $|\downarrow\rangle$）的过程；它与读出共用同一条自旋–电荷通道，是单发测量同时完成初始化的物理基础。

物理图像与 DiVincenzo 判据

可扩展量子计算要求每次线路开始时量子比特都处于一个确定的纯态，而不是与环境的混合。DiVincenzo 判据第二条把这一要求量化为两点：保真度足够高、能被反复调用；同时初始化必须是确定性的，而不是简单地依赖自发弛豫——因为 T1​ 是个很慢的过程（半导体量子点中通常为 ms 量级甚至更长），等待自然弛豫会浪费绝大部分时钟周期（论文第 1 章对 DiVincenzo 判据的逐条叙述）。

对单自旋量子比特而言，“制备到已知态”在能量选择读出（Elzerman 读出）结束时刻自然完成：测量结束后 ∣↑⟩ 电子必已隧穿出点并被一个 ∣↓⟩ 电子替代，系统被无成本地”重置”成 ∣↓⟩；因此在硅、锗单自旋实验中”读出即初始化”是一条普遍原则（论文 §1.3.3；论文 §1.3.2）。这一原则不依赖材料或温度，是所有 Elzerman 类方案共享的便利。

对多电子编码（如 S–T0​ 比特、三量子点比特）而言，初始化无法靠读出”顺手完成”，需要在每次操控前单独执行：把系统脉冲到 (0,2) 区等待自旋弛豫到基态 S(0,2)，再快速绝热移到 (1,1) 区即得 ∣S⟩（论文 §2.5；论文 §5）；或者把系统置于一个高阶三重态阻塞窗口中等待向 T−​ 弛豫（论文 §2.3.2 与 §5.2.3）。两种”基态等待”路径都用同一物理机制：只要把自旋自由度放在比环境更低的能量极小处，热弛豫即被定向。

理论模型

能量选择隧穿：保真度的基本限制

单点电化学势在外磁场 B 下被塞曼能 EZ​=gμB​B 分裂为 μ↑​ 与 μ↓​（μ↑​>μ↓​）。初始化位置选在 μ↓​<μreservoir​<μ↑​，即源漏电子库的费米面夹在两个自旋能级之间。在与库的耦合强度 Γ 下，库中的随机自旋电子有概率隧穿入量子点：占据 ∣↓⟩ 的概率为

P↓​=Γ↑in​+Γ↓in​Γ↓in​​⋅1+exp[(μreservoir​−μ↑​)/kB​Te​]1​≈1−exp[−EZ​/(kB​Te​)].

理想情况下，若电子温度 Te​ 远低于塞曼温度 EZ​/kB​，占据 ∣↑⟩ 的概率按玻尔兹曼因子被压低。实测可见度（visibility）则还要乘以隧穿速率与读出窗口的匹配程度。论文给出的单发可见度条件为 EZ​/Te​>13、T1​⋅Γ↑out​>100、Γs​/Γ↓in​>12；其样品在 B=1.5T、Te​≈180mK 下 Γ↑out​=6.0kHz、Γ↓out​=27Hz、1/T1​=112±6s−1，受限于 EZ​/Te​≈11.2<13 而未达到 >99% 的判据（论文 §3）。

这一玻尔兹曼表达式同样决定了初始化保真度的温度上限。在低温端 Te​≲100mK、EZ​≈21μeV（硅 g=2，B=0.72T）下，理论热极化率 ≳99.9%，但实际数据中读出窗口、隧穿速率匹配、电子升温、电荷跳变等系统效应会把保真度拖到 99% 量级；这就是为什么硅自旋单发测量常报 99.5%–99.9% 的初始化/读出保真度。论文报道 Si-MOS 单发读出保真度达 99.86%（射频反射测量结构）；论文样品在阈值无关分类后达到 >99%。

弛豫热点：自旋–轨道–谷混合加速的定向弛豫

在双量子点的 (1,0)–(0,1) 反交叉附近，自旋态、谷能级与轨道自由度可以强混合。基础图像是：当失谐 ε 与谷能级劈裂 EVS​ 满足 ε≃EVS​ 时，∣↑,−⟩ 与 ∣↓,+⟩ 在免交叉点附近杂化，自旋不再是好的量子数，T1​ 局域下降两到三个数量级（典型从 ms 量级跌到 μs 量级）。把系统短时停在这一”弛豫热点”上，∣↑⟩ 态被快速弛豫到 ∣↓⟩，从而以远低于 T1​ 的等待时间完成初始化。

论文 §1.3.3 把它列为硅自旋比特的第三种初始化机制：与前两种 Elzerman 类方法不同，弛豫热点不受源漏费米面热展宽或绝热移动条件限制，可在纳秒到微秒量级完成；但缺点是它只能清理两个量子点中的一个，另一个比特仍需借助能量选择隧穿或 (0,2)→(1,1) 分离脉冲。论文 §5 在 Si-MOS 双比特波形中保留了 H 步骤（即经过 (2,1)–(3,0) 反交叉的热点），实测”在实际操控中起到的作用并不大”，但仍是控制序列的标准组件；论文 §3.2 把同一思想用于自然硅四量子点阵列：在 (1,0)–(0,1) 隧穿线附近的 b 点对 Q1 完成热点初始化，再把 c 点调到 Q2 的隧穿线对 Q2 完成能量选择初始化——两个比特先后被重置为 ∣↓↓⟩。

双量子点的基态等待：S(0,2) 与 T−​

对 S–T0​ 比特，初始化只能在 (0,2) 区完成：S(0,2) 与 T(0,2) 的能级差 EST​ 约数百 μeV（GaAs 典型 400μeV），三重态因泡利不相容原理必须占据激发轨道。把系统停留在 (0,2) 区等待 twait​≫T1​，所有态弛豫到 S(0,2)；再用一个快速绝热脉冲把系统搬到 (1,1) 区即得 ∣S⟩。绝热分离需满足”快于核场混合、慢于隧穿劈裂”，是 S–T0​ 实验的基准时序（论文 §2.5；论文 §5）。

对泡利自旋阻塞（PSB）读取体系，初始化利用三重态阻塞的反向：把系统停在与读出点相同的位置（偏压三角形内的阻塞区），外磁场下三重态中 T−​ 是基态，系统经若干次失败的隧穿尝试后稳定在 T−​；延长 (1,1) 区等待时间 twait​≫T1​ 即可把任意初始态洗到 T−​（论文 §2.3.2 与 §5.2.3）。在锗空穴双量子点中 T−​(1,1) 弛豫时间约 10–100 μs（实测随样品而异），与读出时间同量级，因此初始化与读出可合并在同一波形中完成。

自旋轨道矩（SOT）磁化翻转的”外场初始化”

论文提出的 SOT 翻转方案里，自旋的”初态”由 SOT 自由层磁化方向决定：在测量前对 SOT 器件施加一段沿某一方向的恒定外磁场，使磁化平行排列，撤去外场后磁化保持稳定；沿 x 方向的磁化分量产生沿 x 方向的杂散场，与外磁场 Bext​ 的 x 分量之和定义自旋量化轴——初始化方向因此由”准备阶段”的磁场方向选定（论文 §2.3）。这是一种与能量选择隧穿完全不同的物理路径：它不依赖电子温度与隧穿速率，而是把宏观磁矩的磁化方向当作自旋初始化的”参考零”，适合做反复确定性制备；缺点是 SOT 翻转所需电流较大、与传统栅控线路兼容性是论文重点讨论的对象。

速率方程与初始化时间

把量子点与电子库视为一个两态热库系统：量子点能级 {μ↑​,μ↓​}，电子库占据数服从费米–狄拉克分布 f(μ)=1/(e(μ−μF​)/kB​Te​+1)。在固定偏压下，系统占据 σ={↑,↓} 态的速率方程为

dtdPσ​​=Γσin​[1−Pσ​−Pσˉ​]f(μF​−μσ​)−Γσout​Pσ​[1−f(μF​−μσ​)]−Γrelσˉ→σ​Pσˉ​+Γrelσ→σˉ​Pσ​.

稳态时 μF​ 落在 μ↑​ 与 μ↓​ 之间且 kB​Te​≪EZ​，末项自旋反转弛豫 Γrel​≪Γin/out 可忽略，得到

P↓ss​≈Γ↓in​+Γ↑in​Γ↓in​​[1+exp(−EZ​/kB​Te​)]−1

即 ∼99% 量级初始化保真度。在论文样品上，Γ↑out​=6.0kHz、Γ↓out​=27Hz，代入得到稳态时间 τinit​∼1/(Γ↓in​+Γ↑in​) 约 ms 量级，与实测读出时间常数同量级。

对双量子点的基态等待路径，速率方程退化为单粒子弛豫

PS​(t)=PS​(∞)+[PS​(0)−PS​(∞)]e−t/T1​

其中 T1​ 是 (0,2) 区从高能态向 S(0,2) 的弛豫时间。twait​=5T1​ 通常就能把初态洗到 1−e−5≈99.3% 的保真度。

弛豫热点的哈密顿量与 T1​ 谷

在硅双量子点 (1,0)–(0,1) 反交叉附近，谷能级与自旋–轨道耦合共同压低 T1​。最低阶有效哈密顿量在 {∣L,↑,−⟩,∣L,↓,+⟩,∣R,↑,−⟩,∣R,↓,+⟩} 基矢下形如

Hhs​=​−2ε​−2EZ​​tsv​tc​0​tsv​−2ε​+2EZ​−ΔEVS​​0tc​​tc​0+2ε​−2EZ​​tsv​​0tc​tsv​+2ε​+2EZ​−ΔEVS​​​​

其中 tsv​ 是自旋–谷耦合矩阵元（由界面粗糙度、声子或微磁体梯度提供），ΔEVS​ 是单点谷劈裂。失谐满足 ε≃ΔEVS​ 时 ∣↑,−⟩ 与 ∣↓,+⟩ 在免交叉点附近形成强杂化，自旋–谷不再是守恒量，T1​ 局域下降两到三个数量级。该机制对单点 T1​ 不重要（单点中 ε=0 只有一个谷与自旋态耦合），但在双点初始化波形中成为关键工具。

PSB 读出与初始化的”对称窗口”

在 PSB 路径里，初始化点与测量点都选在偏压三角形的阻塞三角内（∣ε∣<EST​/2）。两电子四态能量在磁场 B 下为 ES​=0、ET−​​=−EZ​、ET0​​=0、ET+​​=+EZ​；当双点能级满足 EST​>∣EZ​∣ 时，S(0,2) 是绝对基态而 T(0,2) 不可达——这就是阻塞窗口。在 μL​,μR​ 调到此窗口时，(1,1) 区的任何随机自旋态只能通过 (a) 自旋翻转弛豫到 T−​、(b) 隧穿到 S(0,2) 这两条路径演化，前者慢（∼T1​）但确定地把系统洗到 T−​。这一”读出位置 = 初始化位置”的设计把测量序列和初始化序列合并，是 PSB 相对 Elzerman 的根本优势。

实验特征

单发读出即初始化：论文 Si-MOS 样品的标准波形是”控制 (10 ms) — 读出 (10 ms)“两段：在控制段把比特用微波脉冲翻到 ∣↑⟩，进入读出段后 ∣↑⟩ 电子隧穿出点、随即从库隧入一个 ∣↓⟩ 电子，测量结束时电子必然处于 ∣↓⟩，因此下次循环无需重复一个独立的初始化步骤（论文 §4.2）。这一”读出 = 初始化”的等式是 Elzerman 路线在硅、锗体系中都被广泛采用的根本原因。

两比特串行初始化与弛豫热点切换：论文 §3.2 给出一个 1D 四量子点阵列的标准初始化–操控–读出波形序列：先在 Q2 边（a 点）装入一个电子 → 借 (1,0)–(0,1) 反交叉附近的弛豫热点在 b 点完成 Q1 的快速初始化 → 把 c 点调到 Q2 的隧穿线借助能量选择隧穿完成 Q2 的初始化 → 移到 (1,1) 区中心 d 点做单/两比特门 → 在 e 点先读出 Q2、再用点间隧穿把 Q1 转到 Q2 后读出。Q1 初始化时间约 3 ms、Q2 约 5 ms、读出时间均 3 ms，整体波形周期约 28 ms。论文 §5 在 Si-MOS 双比特波形里也保留了 H 步骤（穿过 (2,1)–(3,0) 反交叉），但实际操控中弛豫热点起的作用不大；论文中明确说”为了加快测量速率，我们将这个 H 点省去了”。

热点与能量选择的接力：论文与论文在两比特初始化时都有一个隐含的接力关系——弛豫热点只清一个比特，第二个比特必须依赖能量选择隧穿或 (0,2)–(1,1) 分离脉冲。这意味着当比特数扩展到 N 时，纯热点的串行成本是 N⋅thotspot​；纯 Elzerman 的成本是 N⋅tE​，而 tE​≫thotspot​。因此大规模阵列的初始化策略倾向于”热点先行 + Elzerman 兜底”。

PSB 读出与初始化共用阻塞窗口：论文 §2.3.2 指出，在 PSB 输运测量下，量子比特的初始化在泡利自旋阻塞区完成：在 B 场下随机自旋的双量子点会以较大概率落在 T−​，延长 (1,1) 区等待时间可把任意态洗到 T−​。E–S–M 三段波形中 S 段（停留 (1,1) 区足够长的时间）兼作初始化和读出的准备阶段；测量时把系统脉冲到 M 点（(2,0) 内的阻塞三角形），由 SET 电流判别末态是 S 还是 T。这一”读出位置 = 初始化位置”的对称设计是 PSB 体系的关键简化，也是为什么锗空穴（无微磁体、Rabi 频率 11.6 MHz）能把两比特门时间压到 ns 量级。

谷能级与弛豫热点的竞争：硅导带六重简并在界面处劈裂为两对谷能级，剩余 EVS​（典型几十到几百 μeV）与 EZ​ 同量级。当 ∣ε∣∼EVS​ 时自旋–谷–轨道混合既制造弛豫热点（用于加速初始化）也压缩 T1​（降低读出保真度），二者构成同一个能级图的对偶——这一权衡在论文 §3.4 关于谷能级标定与论文关于四量子点初始化波形的设计中都被反复讨论。

标定与表征

初始化保真度的提取：实验上常把 RB（随机基准测试）曲线 F(N)=21​+ApN 的振幅 A 与态制备/读出保真度联系起来：

A=(Finit​+Fread​−1)(1−2ϵ)

其中 ϵ 是基态错误率（论文 §4 与 §5 给出 RB 拟合公式；论文 §3 也使用同一形式）。把 Finit​ 与 Fread​ 拆开需要辅以独立的”无操作”基态概率测量：在 Elzerman 读出里，“无操作”下测到的 ∣↑⟩ 比例即 1−Finit​，“翻转后”测到的 ∣↑⟩ 比例即 Fread​，两者之积给出联合保真度的下界（论文 §3 的处理方式）。

热极化曲线的标定：扫描初始化脉冲时长 tinit​ 与温度 Te​ 拟合 P↑​(tinit​)=Ae−tinit​/T1​+B，可同时提取初始化时间常数与残余极化率；外推到 tinit​→∞ 给出热力学极限的初始化保真度，与玻尔兹曼公式 P↑th​=e−EZ​/kB​Te​ 比较即可校准 Te​（论文 §3；论文 §3.3）。

弛豫热点的位置标定：在固定磁场 B 下沿 (1,0)–(0,1) 反交叉线扫描失谐 ε，测量单点的 T1​(ε) 曲线：在 ε≃EVS​ 处出现一个 T1​ 的深谷，谷值与峰值的比可达 102–103。把这一深谷的中心定为”热点”位置，是双比特初始化波形选择 b 点的依据（论文 §3.2）。

PSB 阻塞三角形的几何标定：在 Vε​–Vbarrier​ 平面上测量 (0,2) 区跃迁线的位置，阻塞三角形由三条电荷跃迁线围成；其内 QPC 信号介于 (1,1) 与 (0,2) 之间，给出 PSB 工作窗口（论文 §3.2）。

各材料体系的初始化对比

  • GaAs（GaAs/AlGaAs）：g≈−0.44，核自旋浓度高（∼106/电子），T2∗​∼10ns；但 EST​∼400μeV 大、PSB 阻塞窗口稳健。早期工作主要使用 (0,2) 区 S(0,2) 等待或 PSB 阻塞三角形内的 T−​ 弛豫完成初始化（论文、论文）。
  • Si/SiGe（Si/SiGe）：g≈2、EVS​ 可调（数十到数百 μeV）、T2∗​∼1–20μs（同位素纯化 28Si 后），主要靠 Elzerman 或弛豫热点；PSB 同样适用但谷能级可能压缩 EST​ 窗口（论文、论文）。
  • Si-MOS（Si-MOS）：与 Si/SiGe 类似，但电荷噪声略大、EVS​ 较大；论文展示了微磁体合成自旋轨道耦合场下的 Elzerman 初始化波形，并在双比特波形中保留了弛豫热点作为工程选项（论文 §4、§5）。
  • 应变锗空穴（应变锗）：重空穴 g 因子强各向异性、T2∗​ 较短但 Rabi 速率可达 11.6 MHz；初始化主要靠 Elzerman 或 PSB 的 T−​ 等待（论文 §2.3 与 §5.2.3）。
  • SOT 磁化翻转体系（半导体量子点+SOT 自由层）：自旋初始化方向由 SOT 自由层磁化方向决定，通过外磁场”准备阶段”选定；适合反复确定性制备，与传统栅控线路兼容性是论文重点研究对象（论文 §2.3）。

与其他概念的关系

  • 单自旋量子比特：Elzerman 能量选择隧穿是单自旋比特的标准初始化路径，读出与初始化共享 SET 电流信号。
  • 单态–三重态量子比特：使用 (0,2) 区等待 S(0,2) 弛豫或 (1,1) 区等待 T−​ 弛豫两类基态等待方案；前者对应 PSB 的能量窗口，后者对应 PSB 的阻塞窗口。
  • 空穴自旋量子比特：锗空穴的强自旋轨道耦合使 EDSR 速率达 11.6 MHz，单发读出保真度可达 99.99%（Veldhorst 2024）；初始化主要靠 Elzerman 或 PSB，弛豫热点同样适用。
  • 单发读出：Elzerman 与 PSB 两条主线的读出与初始化几乎不可分。
  • 射频反射读出：射频读出把 Elzerman 时间常数从 ms 压到 μs，使初始化时间同步缩短，是论文 Si-MOS 读出保真度 99.86% 的硬件基础。
  • 电荷稳定图：初始化点的选取完全由稳定图决定——(1,0)、(0,1)、(1,1)、(0,2) 四点的失谐顺序决定”排空→加载→等待→读出”的脉冲轨迹。
  • Si/SiGe、Si-MOS、应变锗、GaAs/AlGaAs：四种主流材料体系中初始化方案的选择主要由 g 因子、谷能级、核自旋浓度共同决定。
  • 双量子点：弛豫热点、(0,2) 区基态等待、PSB 三条路径都需要双量子点能级图，是初始化与读出的共同载体。
  • 量子比特快速复位：超导侧的主动初始化对应物——不靠等待弛豫而用工程化耗散通道在几十纳秒内把比特抽运回基态，与本文的被动/测量基初始化构成两个平台的初始化方案对照。
